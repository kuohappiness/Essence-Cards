## 使用與測試備忘

共通的工具備忘（doctype、本機伺服器、Edge 無頭截圖、並排 iframe）見[試作場說明](../README.md#ai-怎麼測)。這兩份樣式稿另外要注意：

- 給使用者在 iPhone 上看：發布成私人 Artifact。
- entry-and-reveal 的控制列可以切換 iPhone／電腦、平常／考前 3 天；一頁並排的 iframe 要用網址參數的點擊步驟設定狀態，同時用 localStorage 會互相干擾。
- Edge 無頭模式在 Windows 上 `--dump-dom` 沒有輸出，測試結果改在內建瀏覽器用 JavaScript 讀。
- 樣式稿已拿掉顯示答案 B、C1、C2 與入口 B 的切換，程式裡的分支還在；這些是沒採用的方案，不是 T2 的要求。

## T1 複習畫面樣式

- 第一版有紙卡、安靜、明亮三種樣式（在 git 歷史 `d2d724c`）。和舊外掛的複習視窗相比：粗體與圖片正常顯示；改成全螢幕，按鈕放在拇指按得到的下方；路徑不顯示 `#`，也不顯示英文卡片類型；加上進度條；背面附出處連結。
- 結果：2026-10-12 使用者選「安靜」，自評按鈕不顯示間隔（[D-070](../../docs/decisions.md#d-070-複習畫面採用安靜樣式)）。[樣式稿](review-styles.html)只留安靜樣式，並加上中→英拼字卡（D-066）、理解題重點的標示（D-068）、新卡的「新」標籤（D-069），完成畫面改成「今天複習了 N 張」。使用者看過後：黃色螢光筆太花，改成粗體加紫色細底線；路徑加上年級（科目 › 年級 › 單元）。
- AI 已測（2026-10-12，寬 375px）：深淺色 × 中英文 × 5 張卡的正反面與完成畫面，流程、文字對比（WCAG AA）、版面都正常；拼字比對不分大小寫、忽略前後空白，能標出漏打、打錯、多打的字母；點拼字卡本身不會翻面，Enter 可確認；畫面上沒有「答錯」「失敗」。
- 待補進樣式稿：完成畫面改成「今天的份完成了！」加「再複習一些」（D-071）；加上「復原上一張」（D-074）。→ 2026-10-16 已補進 T5 的[入口與顯示答案樣式稿](entry-and-reveal.html)，復原照 D-084 改成回看上一張。

## T5 顯示答案的方式、入口與目錄

- 使用者 2026-10-13：喜歡舊外掛的眼睛圖示，覺得比「顯示答案」文字簡潔；另提議把答案霧化，點了才顯示；之後做幾種樣式稿挑選。
- 樣式稿比較三種：
  - A：「顯示答案」文字按鈕
  - B：眼睛圖示
  - C1：霧化真正的答案加眼睛圖示
  - C2：霧化「和答案一樣長的假文字」加眼睛圖示
- 💡 當時的共同要求（助理提案；最後選了 A，霧化方案沒採用）：
  - 觸控範圍是整個答案區，圖示只是視覺。
  - 答案區先留好位置，揭曉時按鈕不移位。
  - 字數提示可以保留：使用者 2026-10-13 認為「答案是 3 個字 → 努力想 3 個字 → 想到了 → 很開心」也是主動回想，還能強化動機。助理同意字數是一種提示下的回想。
  - 但要避免透露字形：真的答案模糊後，英文字的高低輪廓認得出來，學生是「認出來」而不是「想起來」，考試時沒有這個輪廓（原則 1）。所以比較 C1 與 C2，看 C2 是否兼顧字數提示與不透露字形。
  - 揭曉動畫用透明度淡入，不做模糊半徑的動畫。
- 效能：一張卡只模糊一小塊區域，由瀏覽器交給顯示晶片處理，對 iPhone 負擔很小。真正費力的是「模糊半徑的動畫」與「整個畫面的背景模糊」，兩者都不採用。
- 背面的「出處」（2026-10-14，D-079）：原本顯示「出處：p.45 ↗」，改成只留一個有質感的小圖示，滑鼠移過去（iPhone 上點一下）才顯示「出處」；不顯示頁碼（D-076）。使用者希望介面高雅舒適，參考[舊介面](../../docs/research/old-plugin-review-latest.webp)，目標是比它更好。圖示可以小，觸控範圍要夠大。
- 樣式稿（2026-10-16 起）：[入口與顯示答案](entry-and-reveal.html)。2026-10-19 第 16 版加上考前抽測（考前 3 天出現在入口科目列的第一列，含結果頁）與電腦版的「給家長」一區、狀態列提示（D-103），控制列可切換 iPhone／電腦、平常／考前 3 天。同一份也放了入口畫面（2026-10-16 和使用者討論後改成一科一列：科目、該科的已完成／今天總數、一顆「▶ 幾分鐘」按鈕，建議先做的排第一；做完一科的樣子比較 A 分隔線填滿與 B 按鈕外圈填滿；考試倒數可切換顯示）、目錄（今天的份用 ▶，「全部練習這個單元」收在點開的單元裡）與管理模式、設定考試範圍、英文自評按鈕、回看上一張、出處與朗讀圖示、完成畫面的「再複習一些」。
- AI 已測（2026-10-16，寬 375px）：深淺色 × 中英文 × 四種顯示方式 × 理解題、填空、中翻英打字，加上三種入口、目錄、管理、考試範圍，都沒有橫向捲動與主控台錯誤，文字對比過 WCAG AA。翻面後 0.3 秒內的自評不算；右滑回看、左滑回來，上下拖動不算；打字題點畫面不會翻面；考試範圍從入口點兩下就設好（日期選填）。
- 結果（2026-10-16～17，樣式稿第 2～15 版；過程見[討論紀錄](../../docs/archive/discussions/2026-10-16-entry-and-reveal.md)）：
  - 顯示答案選 A「顯示答案」文字按鈕；空格改成一條和題目同色的 2px 底線，翻面後答案在線上淡入、線變紫色；詳解和答案之間拉開約 20px、中間一條淡色短線（[D-096](../../docs/decisions.md#d-096-顯示答案與複習畫面的細節)）。
  - 入口一科一列：最上面「今日複習 10/50」，每一科是已完成／今天總數和「▶ 5 分鐘」外框按鈕，建議先做的排第一；進度選 A 分隔線，做完變灰綠、移到最下面；考試倒數「距離考試：12 天」，設定頁可以關掉；右下角「Essence Cards」字標（[D-095](../../docs/decisions.md#d-095-入口畫面)）。
  - 目錄依學期分組、「當日｜全部」切換；單元的數字改成卡片總數，顏色表示單元狀態；點開有「▶ 當日卡 N」「▶ 全部卡 N」；四種標籤（[D-097](../../docs/decisions.md#d-097-目錄畫面)）。
  - 考試範圍只用在大考、一次一份、日期改成考試期間（[D-098](../../docs/decisions.md#d-098-考試範圍只用在大考日期改成考試期間)）。
  - 使用者 2026-10-17 看過整份樣式稿表示滿意，所以樣式稿裡的其他細節（上方「‹」與 ✕ 的位置、翻面後 0.3 秒內的點擊不算、出處的書本圖示、完成畫面的「接著做英文」）一起寫進 D-096。
  - 英文自評按鈕 No idea／Almost／Got it／Too easy 也在 2026-10-17 確認（D-096）。
- 結果（2026-10-19，第 16 版）：使用者看過考前抽測與「給家長」一區後同意（[D-103](../../docs/decisions.md#d-103-總覽改成入口的給家長一區)、[D-107](../../docs/decisions.md#d-107-考前抽測放在入口科目列的第一列)）。
