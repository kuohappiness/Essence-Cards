# 盲評說明（第一輪：2-1、2-2）

給 Claude 與 Codex 的評分者，各自在**新的對話**照這份評分。你不知道每一份是哪一種做法，也不要去猜；這一輪要知道的是：哪一份最能幫學生答對真實段考題，以及沒幫到的地方卡在哪一個環節。結果只代表「教材與評量對齊得好不好」，不是學生成效的驗證。

## 可以讀、不能讀

以下路徑都相對於測試 vault 的 `學習目標架構/`（實際位置寫在交給你的訊息裡）。

| 可以讀 | 用途 |
|---|---|
| 這份說明 | 規格 |
| `考題/凍結.md` | 答案、核心題、不計分的題、已知的教材輸入問題 |
| 你自己那一家的標註：Claude 的評分者讀 `考題/標註-Claude.md`，Codex 的評分者讀 `考題/標註-Codex.md` | 每一題的知識要點 |
| 例外：第 13 題兩家都照 `考題/標註-Codex.md` | Claude 的標註把它歸第 1 章，沒有展開；凍結時採 Codex 的歸類 |
| `考題/考題轉錄.md`、`考題/照片/` | 看原題 |
| `材料/2-1/`、`材料/2-2/` 的 `教材.md`、`圖/`、`檢查.md` | 核對答案、出處與教材輸入缺漏 |
| `盲評/卡組/`、`盲評/架構/` | 評分對象；卡上的圖在各自的 `圖/` |

**不能讀**：另一家的標註（第 13 題除外）、`生成/`、`紀錄/`、`紀錄.json`、`考題/請求/`、`考題/核對/`、`評分/` 裡另一家的檔案。repo 裡**只讀這份說明**：這次不照 `AGENTS.md` 先讀 `docs/roadmap.md`，也不讀 `docs/`、`tasks/`、`experiments/t4/` 的其他檔案與 `Claude Codex Discussion/`。這些檔案會透露每一份是哪一種做法，或另一家的判斷。不小心讀到了，在結果檔開頭寫明讀到什麼，照常評完。

不上網、不呼叫其他模型。

## 順序與鎖定

1. **卡組**：評完 `盲評/卡組/` 的 12 份，寫成 `評分/<你>-卡組.md`（`<你>` 寫 `Claude` 或 `Codex`）。寫完就**鎖定**：之後不再改這個檔案，也還不能打開 `盲評/架構/`。
2. **架構**：評 `盲評/架構/` 的 10 份，寫成 `評分/<你>-架構.md`。寫完鎖定。
3. **缺口**：兩份都鎖定後，才把卡組和架構配對、為缺口標原因，寫成 `評分/<你>-缺口.md`。前兩步之後才發現的錯，寫在這一份的〈補記〉，不回頭改。

一份一份評，同一節的幾份互相比較沒關係，但每一份的判斷要能單獨站得住：寫出卡片或目標的原文（可以只引前十幾個字）當證據。

## 評分用的題目

只評 2-1、2-2 的計分題（`凍結.md`〈答案〉）：2-1 十題、2-2 十三題。答案、核心題照 `凍結.md`，不重新判；你認為凍結有錯，寫進〈補記〉，照凍結的評。

每一題的**知識要點**是你那一家標註裡「答對需要的知識與判斷」的每一項，連同它標的層次（①②③）。標成「教材沒有」的要點、`凍結.md`〈已知的教材輸入問題〉列的要點，照樣列出，但標「輸入」，不算任何一份的缺口。

## 1. 卡組（12 份）

卡組只有第 ① 層，是學生實際看到的題目與答案。**看卡片，不看學習目標的名稱**：名稱寫了「能判斷……」但卡片只要求背一個名詞，不算支持那個判斷。

### 1-1 逐題的支持

對每一份卡組、每一題的每一個知識要點，判一個：

- **✅ 支持**：至少有一張卡，學生要答對它，就得做出這個要點要的判斷或說出這個知識，而且答案正確、和教材一致。
- **◐ 部分**：卡片碰到了，但只涵蓋一部分（例如只問名詞、沒問判斷；只問其中一種情況），或答案有瑕疵。寫出少了什麼。
- **✗ 沒有**。
- **輸入**：上面說的教材輸入問題，不判。

第 ②、③ 層的要點：卡組本來就不負責，判了也只另外列，不算進主要統計；有卡片碰到就照實記。標註寫「閃卡以外的練習」的部分不判，但卡組最上面給家長的備註有提到要另外練習時，記一筆。

### 1-2 每一份的題目品質

逐張看過所有卡片，列出有問題的卡（引原文），每張標一種或多種：

- **洩漏**：題目本身、同一個題目池裡排在前面的卡，或圖片，就透露了答案。
- **一題多問**：一張卡要學生一次答出彼此獨立的好幾件事；列舉本身就是要記的東西（例如「物質的兩項條件」）不算。
- **錯誤**：答案錯、和教材矛盾，或題目有兩個以上合理答案而答案只收一個。
- **答案過長**：答案的關鍵要點超過三個，或學生要逐字背一大段才算答對。
- **其他**：寫明。

學習目標的邊界：

- **混池**：同一個學習目標底下的題目考的是不同的能力（應該分開排程）。
- **按例子拆**：同一個能力只因為例子不同就拆成好幾個學習目標。

### 1-3 每一份的結論

- 第 ① 層要點：✅、◐、✗ 各幾個（不含「輸入」）。
- **核心題**：每一題的 ① 要點全部 ✅ 的核心題有幾題，列題號；有 ✗ 的核心題列出來。
- 卡片總數、學習目標數、有問題的卡數與比例（照種類分）、混池與按例子拆各幾處。
- 兩三句總評：最好的地方與最大的問題。

最後每一節排一次名次（2-1 六份、2-2 六份），寫出理由。排名先看核心題的支持，再看全部 ① 要點，再看題目品質與負擔（同樣的支持，卡少、問題少的較好）。分不出高下就並列，不硬排。

## 2. 架構（10 份）

架構是規劃，不代表學生已經學會，也不代表第 ②、③ 層可以直接拿來用。

### 2-1 逐題的規劃覆蓋

對每一份架構、每一題的每一個知識要點（所有層次），判一個：

- **✅ 覆蓋**：有一個具體的目標，它的判準要求這個判斷，出處真的支持它。層次和你的標註不同沒關係，照實記下目標的層次。
- **◐ 部分**：有目標但判準太寬（看不出要做哪個判斷）、只涵蓋一部分，或出處不支持。
- **✗ 沒有**。
- **輸入**：同卡組。

### 2-2 每一份的架構品質

- **判準**：具體到能判斷答對沒有嗎？列出太寬的。
- **出處**：抽查，列出不支持判準的。
- **先備**：有沒有漏掉真的需要的、列了不需要的、跨單元的有沒有寫明。
- **第 ②、③ 層**：有沒有新增可以判斷的能力，還是換句話重複 ①、或為了湊滿三層硬加。
- **例題的觀念**、**需要其他練習**：教材的例題有沒有對到目標；放進「其他練習」的理由合不合理。
- **邊界**：混在一起的目標、按例子拆開的目標。
- 目標數，各層幾個。

### 2-3 每一份的結論與排名

- 所有要點與核心題的 ✅、◐、✗；兩三句總評。
- 每一節排一次名次（各五份），先看核心題的覆蓋，再看全部要點，再看判準與層次的品質。

## 3. 缺口（兩份都鎖定之後）

1. **配對**：架構第 ① 層的目標名稱和卡組的學習目標名稱應該一字不差。每一份架構找出配對的卡組，寫出依據（相同名稱的比例）。有一份卡組沒有架構可以配是正常的。配對拿不準就寫拿不準，不硬配。
2. **原因**：每一份卡組裡核心題的 ✗ 與 ◐ 要點，標一個原因：
   - **教材輸入缺漏**：教材轉錄沒有，或只在教師註記裡。
   - **架構漏目標**：配對的架構沒有這個目標。
   - **判準太寬**：架構有目標，但判準沒要求這個判斷。
   - **出題沒實現判準**：架構的判準有，卡片沒做到。
   - **留到加深**：架構把它放在第 ②、③ 層。
   - **需要其他練習**：架構或備註明確放進其他練習，而且理由合理。
   - **沒有架構**：卡組沒有配對的架構，原因沒辦法分。
   - **爭議**：拿不準，寫明兩種可能。

   非核心題的缺口寫在後面，不必細分。

「審查改壞」要知道哪兩份是同一條流程的前後版，盲評做不到；揭曉後由 Claude 在報告裡判斷。你在這裡**不要**猜哪兩份是前後版。

## 4. 結果檔的格式

三個檔案的開頭都寫：評分者、日期、實際讀了哪些檔案、有沒有讀到不能讀的檔案。

**`<你>-卡組.md`**

```markdown
## 2-1

### K001

| 題 | 核心 | 要點（層次） | 判定 | 證據（學習目標／卡片開頭） |
|---|---|---|---|---|
| 2 | 是 | 知道……（①） | ✅ | 「能……」／「科學上，判定……」 |

- 題目品質：……（每張問題卡一行：種類｜原文開頭｜說明）
- 邊界：……
- 結論：……

### K002 ……

### 2-1 排名

1. ……（理由）
```

**`<你>-架構.md`**：同樣的表格，證據欄寫目標代號與判準開頭；接著寫 2-2 的品質項目、結論與排名。

**`<你>-缺口.md`**：配對表；每份卡組的缺口表（題、要點、原因、說明）；〈補記〉。

## 不要做的事

- 不平均分數、不換算成總分；表格與排名就是結果。
- 不替任何一份補寫架構或卡片，不修改 `盲評/` 裡的檔案。
- 不讀另一家的結果；兩家的結果分開列，由 Claude 在揭曉後彙整。
