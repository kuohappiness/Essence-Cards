# 先畫全貌，再倒推目標

這一次照下面五個步驟做。每一步怎麼想由你判斷；要交出來的內容寫在最後的〈這一次的回應〉。

## 範圍

這一節知識全貌的邊界由你劃定：為了學到知識的本質，目標可以變多，範圍也可以適度超出教材。標準只有一個：能不能加深學生對這一節的理解。

- 這一次允許 AI 補充。教材外的內容標 [AI 補充]，並寫出理由。這一條取代上面「照教材」的「指不出來就不出」；其餘照舊：教材外的內容不能和教材衝突，教材和你知道的說法不一樣時，照教材出題，寫在給家長的備註。
- 份量由軟體控制：第一次以第 ① 層為主，每天的複習有時間上限。你只判斷值不值得學，不用壓數量，也不湊數。
- 要替之前單元的知識補一個目標時，放在這一節，出處寫「先備：單元 內容」，例如「先備：國一自然 細胞的構造」；學生已有的目標不重複建立。

## 1. 全貌

先寫這一節希望學生能完成的核心判斷，再劃定相關的範圍。

- 知識塊之間的關係，要寫出條件與意思：在什麼情況下、哪一塊怎樣影響或區分另一塊。不只列名詞或畫箭頭。
- 每一塊標出來源：教材、先備（之前的單元或別科）、AI 補充。你沒有學生的資料，先備只是從教材判斷的假設，不寫成學生已經會或不會。
- 判斷底層夠不夠：理解核心判斷需要的基礎，教材有沒有交代夠。常見的情形有三種：用到卻沒教的先備；一條規則只給一個例子或一句結論，分不出它在什麼條件下成立；給了結論，沒給讓它說得通的「為什麼」。這只是提醒，不是符合就一定要補；也不要沿著「為什麼」一路往下追。

## 2. 檢查全貌的基本測試

照全貌出一份這一節的基本測試。目的是檢查全貌有沒有漏，不是猜中老師的題目。

- 覆蓋重要的能力與關係，不用每一塊各一題。一題可以提供好幾項證據，但要拆開寫出答對各部分要做的判斷。
- 短答、讀圖表的題目都可以。需要區辨時才用選擇題，並寫出錯誤選項，例如兩個知識塊的交界、教材有對照、容易混淆的觀念。你自己編的錯答，不稱為學生常見的迷思。
- 這份測試只留在全貌段，不做成卡。

## 3. 倒推目標

從答對這些題目需要的能力，倒推學習目標與判準；不從題目數倒推。

- 不同情境、同一個判準的，共用一個目標。
- 容易混淆時，照上面的〈判斷邊界〉寫邊界。
- 底層不夠的，補強第 ① 層的目標，並寫出不補會卡在哪個核心判斷。
- 每個目標寫一句理由：它幫哪個核心理解。這是把你的判斷記下來，不是要通過的門檻。
- **放在哪裡**：學生要在看不到解說時自己完成的判斷，才另立目標；已有目標的判準已經包含、只是題目沒測到的，改同一池的問法或多加一題；只幫助理解原答案的說明，寫在那一題底下的「詳解：」。

## 4. 進展

- 「區分 → 關係 → 連結 → 整合」只是參考，不是每一節都要走的階梯。
- 層次照回應格式的定義，由你判斷。核心判斷要用到、一句話就能判斷的基本觀念，就算跨兩個知識塊，也可以在第 ① 層；要把兩個以上的知識連起來推理的，是第 ② 層。
- 能用一個判準檢查的連結，可以是目標；要多步運算、實作或完整解題的，才列「需要其他練習」，並寫出背後的觀念出在哪個目標。

## 5. 雙向核對

- 回到原教材核對：課本列的學習目標、正文、圖表、例題，不能只核對自己寫的全貌與測試。
- 全貌裡每一項重要能力都有人承接：哪個目標、哪種其他練習，或放在詳解、暫不展開。
- 每個目標都有測試裡的題目支持。
- 每個題目池維持同一個判準；沒有重複的目標，沒有沒人承接的必要能力，也沒有為了湊數或湊層次加的目標。

依附件教材，照上面五步做，交「全貌」「架構」「卡組」三段：


**全貌段**：代號只在這一份回應裡互相引用。

```markdown
## 核心判斷

- ……

## 知識塊與關係

- K1｜教材｜……｜承接：T01、T02
- K2｜先備｜……｜承接：T05
- K3｜AI 補充｜……；理由：……｜承接：T03 第 2 題的詳解
- K1 × K2：在……時，……｜承接：T04
- 底層：……（教材交代得夠，或哪裡不夠、怎麼補）

## 基本測試

- Q1｜短答｜……
    - 判斷：……（K1）；出處：p.……｜目標：T01
- Q2｜選擇｜……（A）……（B）……（C）……
    - 判斷：正解……，因為……；（B）錯在……（K1 × K2）｜目標：T04
```

**架構段**：照回應格式，但「知識塊」「學完要能做到」已經寫在全貌段，這裡從「學習目標」開始。每個目標多寫兩行「理由」與「依據」；需要時加「邊界」。教材外的目標，出處寫 `[AI 補充]`。

```markdown
- T05｜①｜能……
    - 判準：……
    - 理由：幫……；補強：不補，會卡在……
    - 依據：Q3、Q6
    - 出處：p.……
    - 先備：國一自然 細胞的構造
```

**卡組段**：照回應格式。教材外的目標，出處那一行寫 `[AI 補充]`；答案或詳解用到教材外的內容，也標 [AI 補充]。詳解寫在題目底下的子項目：

```markdown
    - 題目 :: 答案
        - 詳解：……
```
