# 回應格式

你的回應分成幾段，每一段前面單獨一行寫標記。標記照抄，標記之外不要加開場白、說明或結語。這一次要交哪幾段，寫在最後的任務說明裡；沒有特別說明時，交「架構」與「卡組」兩段：

```
<<<架構>>>
（這一節的學習目標架構）
<<<卡組>>>
（第 ① 層的卡組）
```

下面的例子取自密度的單元，只示範格式，內容與數量照你的教材決定。

## 架構段

```markdown
## 知識塊

- 密度的意義：質量和體積的比值，代表物質的一種特性；是判斷浮沉的基礎
- 體積的測量：規則物體用公式算，不規則物體用排水法

## 學完要能做到

- 給一個物體的質量和量體積的過程，求出密度，並判斷它在水中的浮沉

## 學習目標

- T01｜①｜能說出密度的意義與單位
    - 判準：能說出密度是質量除以體積，並寫出常用單位 g/cm³
    - 出處：p.20
    - 先備：無
- T03｜①｜能用排水法測量不規則物體的體積
    - 判準：說得出要看上升的水的體積，並說出理由是物體排開了和自己一樣多的水
    - 出處：p.21、圖 1-12
    - 先備：無
- T06｜②｜能用密度判斷物體在水中的浮沉
    - 判準：給物體與液體的密度，判斷浮或沉，並說出比較的是哪兩個密度
    - 出處：p.24
    - 先備：T01

## 例題的觀念

- 例題 1-4：計算前要先用排開的水量求出石頭的體積 → T03

## 需要其他練習

- 例題 1-4 的密度計算：多步驟的運算，閃卡做不到
```

- **代號**：T01、T02……依序編，只在這一份回應裡用來互相引用。
- **層次**：① 基礎：名詞、定義、公式與單位、例題背後要先判斷的觀念，加上這一節最核心的幾個「為什麼」；② 連結：把這一節兩個以上的知識連起來；③ 應用：用到課本沒寫的情境，或和之前的單元比較。第 ②、③ 層是**加深候選**：先規劃好，這次不做成卡。
- **判準**要具體：寫出在什麼條件下、要做出哪個判斷，以及答案要有哪些要點才算會。「能理解密度」不算判準。
- **出處**要能支持這個判準，不能只是出現相近的字。
- **先備**只列真的需要的目標代號；需要之前單元的知識時，寫單元與內容，例如「國一數學 比例式」。沒有就寫「無」。
- 沒有例題、沒有需要其他練習的，該段寫「無」。
- **架構和卡組要一致**：每一個第 ① 層目標，卡組裡都要有一個名稱一字不差的學習目標；卡組裡不能有架構沒有的目標。

## 卡組段

卡組段會直接存成學生複習用的卡組筆記：

```markdown
> [!note] 給家長的備註
> - 建議另外練習：例題 1-4 的密度計算；背後的觀念「不規則物體的體積可以用排開的水量來量」出在「能用排水法測量不規則物體的體積」

## 3 密度

- 能用排水法測量不規則物體的體積
    - 出處：p.21、圖 1-12
    - 一顆形狀不規則的石頭，要怎麼量出它的體積？為什麼可以這樣量？ :: 放進裝水的量筒，**上升的水的體積**就是石頭的體積；因為石頭**排開了和自己一樣多的水**
        - ![[國二上自然 1-3 圖1-12.png]]
```

- 用教材的小標題分組，照課本的層級：最上層寫成 `##`，底下的小標題寫成 `###`。
- 清單最上層的每一項是一個**學習目標**，用「能……」開頭，只寫名稱，不寫代號。
- 學習目標底下第一行寫出處，例如 `p.44`、`圖 2-14`、`例題 2-4`。
- 再來是這個學習目標的**題目池**，一行一題，寫成 `題目 :: 答案`，`::` 前後各空一格；第一題是基本問法。同一個題目池的題目共用一個複習排程。
- 題目底下縮排的子項目是這一題的背面補充，例如幫助記憶的圖。
- 給家長的備註放在最上面；沒有要寫的就整段省略。
