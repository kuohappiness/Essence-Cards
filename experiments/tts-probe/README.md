# T6 系統語音朗讀試作外掛

要回答的問題與目前結論見[試作場說明](../README.md#t6-系統語音朗讀進行中)；這裡放使用方式和過程。

## 使用與驗證

- 兩個檔案（`main.js`、`manifest.json`），不用編譯。裝法：複製到測試 vault 的 `.obsidian/plugins/essence-tts-probe/`（目前已裝好），在 Obsidian 啟用。
- 兩張卡：英翻中（題目旁有喇叭）、中翻英（打字確認後才有喇叭）；可以選語音、切換慢速，也能自己輸入字句試念。選單會標出「加強版／高品質」，下方顯示正在用的語音。
- Windows：使用者的電腦原本只有三個中文（台灣）語音，沒有英文語音，會用中文口音念；要在 Windows 設定 → 時間與語言 → 語音 → 新增語音，安裝 English (United States)。
- iPhone：可以另外下載加強版的英文語音（設定 → 輔助使用 → 朗讀內容 → 聲音）。Obsidian 的語音清單只開放內建的標準語音，看不到下載的語音；要用下載的語音，先把朗讀內容的預設英文語音設成它，再在外掛選「系統預設（不指定語音）」。
- 驗證系統預設語音：換了 iPhone 的預設英文語音後，選「系統預設」念一次，聽是不是新的語音。
- 誰測：使用者在 iPhone 上聽（AI 聽不到聲音，也不能操作手機）。

## 結果紀錄

- 2026-10-14：使用者在 iPhone 上聽了覺得音質很好，v1 用系統語音朗讀，音檔暫停（[D-082](../../docs/decisions.md#d-082-英文卡組與朗讀)）。使用者下載了加強版英文語音，但聽起來一樣：可能是測試頁還在用原本的語音。0.0.2 版在選單標出「加強版／高品質」，並在下方顯示正在用的語音。
- 2026-10-15：Obsidian 的語音清單沒有使用者下載的 Ava（只開放內建的標準語音）。0.0.3 加上「系統預設（不指定語音）」：把 iPhone 朗讀內容的預設英文語音設成 Ava 後，選系統預設就念出 Ava。結論：外掛預設不指定語音，說明書教家長換預設語音（D-082）。
