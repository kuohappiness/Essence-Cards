# 試作外掛（T2＋T3）

回答[試作場](../README.md)的 T2（複習畫面原型），並替 T3（實機驗證）做好自動量測，讓 iPhone 只測一次（[D-065](../../docs/decisions.md#d-065-試作場)）。程式規格見[任務說明](TASK.md)，由 Codex 撰寫；這份說明由 Claude 維護。

狀態：**iPhone 測了一半**：離線連續複習與同步做完；開啟時間、手勢、自動量測、讀全部紀錄還沒做（2026-10-19）。

## 要回答什麼

| 問題 | 怎麼量 | 💡 通過門檻（助理提案，看到 iPhone 結果再和使用者確認） |
|---|---|---|
| React 還是 Preact（D-051） | 外掛載入時間、打開複習畫面到第一張卡畫出來 | iPhone 上 Obsidian 啟動後第一次打開 ≤ 1 秒，之後 ≤ 0.4 秒。React 過關就用 React；React 沒過、Preact 過了才換 Preact |
| 翻面與換卡的動畫順不順 | 每段動畫的每一格間隔 | 掉格（超過中位數 1.5 倍）≤ 5%，沒有超過 0.1 秒的一格；使用者手感沒問題 |
| 能不能藏起 Obsidian 的上下欄 | 全螢幕層的大小、五點 `elementFromPoint`、鍵盤彈出後的可視範圍 | 全螢幕層蓋滿畫面、看不到 Obsidian 的工具列；打字題的鍵盤不擋住輸入框與按鈕 |
| 圖片、公式、音檔 | 渲染時間、載入結果 | 都顯示得出來、能播放；大圖不讓開啟超過上面的門檻 |
| 往右滑會不會打開 Obsidian 側欄、會不會和上下捲動混淆（D-084） | 每一次觸控的判斷與側欄狀態 | 畫面中間往右滑，側欄一次都沒打開；捲長答案，一次都沒換卡 |
| 連續複習 15 分鐘、每次自評立刻寫檔（T3，D-074） | 每次寫檔的耗時、動畫、讀回核對 | 寫檔中位數 ≤ 50 ms、最慢的 5% ≤ 200 ms，一行都沒少；動畫照上面的門檻 |
| 三年份紀錄讀多久（T3，D-105） | 全部讀一次、只讀當月 | 先量，不設門檻；結果決定 v1 要不要做排程快取的預先計算 |

門檻的依據：介面在 0.1 秒內回應會覺得是立即的，1 秒內不會打斷思緒（Nielsen, 1993, *Usability Engineering*）。

## 使用方式（AI）

在 `experiments/plugin/`：

```
npm install
npm test
npm run build
npm run install-vault -- <測試 vault>
npm run gen-records -- "<測試 vault>/Essence-T2/紀錄-三年"
npm run preview
```

- `install-vault` 裝兩個外掛：「Essence T2 (React)」「Essence T2 (Preact)」，可以同時啟用。命令都以「(React)」「(Preact)」開頭：建立測試資料、開始複習、自動量測、連續複習 15 分鐘、讀全部紀錄。
- 設定頁可以切換全螢幕／分頁、攔截觸控事件、連續複習的分鐘數。
- 結果寫在測試 vault 的 `Essence-T2/結果/`，一次量測一個 JSON 檔。
- `preview` 的預覽頁只看版面；放在 app 內建瀏覽器的隱藏面板時動畫會停住，畫面改在 Obsidian 裡看（見[試作場說明](../README.md#ai-怎麼測)的 Windows 版 Obsidian）。

## 結果紀錄

### Windows（2026-10-19，Claude）

Obsidian 1.14.4，視窗模擬成 375×812 加觸控。

- **開啟**：Obsidian 啟動後第一次打開 React 版 57 ms，之後兩版都是 11～19 ms。外掛載入（`onload`）React 13～32 ms、Preact 4 ms；`main.js` React 323 KB、Preact 118 KB。
- **動畫**：螢幕每格 8.3 ms。翻面、換卡、回看的掉格兩版都在 1% 以下，最長一格 19 ms。Motion 透過 Preact 相容層也正常。
- **內容**：小圖、3000×2000 的大圖、行內與區塊公式、WAV 都正常，大圖解碼 30 ms。
- **手勢**（觸控模擬）：中間往右滑回看、往左滑回來、沒有上一張時彈回、斜斜往上捲長答案都判斷正確；Windows 沒有側欄滑動手勢，側欄衝突只能在 iPhone 看。
- **連續複習**（2 分鐘短測）：11 次自評、13 行（含一次改評分的 `undo`），每次寫檔 5 ms，讀回完全一致；Wake Lock 可用。
- **三年份紀錄**：72 檔、16.8 萬行、13 MB，全部讀完 130～180 ms（讀檔約 60%、解析約 40%），只讀當月 4 ms。
- 檢查時修了三處：答案上方補回樣式稿的分隔線；填空翻面後底線縮到答案的長度；放開手指時卡片會先跳回原位再滑出，改成從放開的位置接著動。

### iPhone（2026-10-19，使用者）

Obsidian 1.14.5，畫面 402×874，螢幕每格 8 ms（120 Hz）。使用者照清單時直接跳到第 6 步，第 1～5 步還沒做，所以開啟時間、全螢幕檢查、手勢紀錄、React／Preact 的比較還沒有數字。

- **載入**：`onload` React 3 ms、Preact 2 ms，兩者幾乎一樣；外掛在頁面開始後約 250 ms 開始執行。React 的體積在 iPhone 上沒有拖慢載入。
- **離線連續複習 15 分鐘**（飛航模式，做了兩次）：每次 89 次自評、105 行；寫檔中位數 7 ms、最慢的 5% 9 ms、最慢 12 ms，讀回完全一致。動畫掉格 2.0～2.3%，最長一格 88 ms，沒有超過 0.1 秒的。圖片、公式、音檔每張都正常。Wake Lock 可用，螢幕沒有變暗。**通過。**
- **離線重開與同步**：重開後紀錄還在；關掉飛航模式後 210 行完整同步到電腦。
- **兩端同時修改**：手機離線時在 `轉錄稿.md` 加一行，電腦同時加另一行；同步後只剩手機的版本，電腦那行不見，也沒有衝突副本（iCloud 留下較晚到的那份）。複習紀錄每台裝置一個檔（D-035），不受影響。
- 使用者的感想：翻卡順、側欄沒有被滑出來、捲動沒有誤換卡。但第 2 步的手動滑動沒做，側欄這題還要再確認。
- 外掛的毛病：裝置隨機碼存在外掛設定裡，設定檔經 iCloud 同步，所以 iPhone 和 Windows 拿到同一個碼。正式外掛要存在本機（記入 [backlog](../../docs/backlog.md#其他待決)）。
- 清單的毛病：Obsidian 的檔案列表不顯示 `.jsonl`，第 7 步改用「檔案」app 看。

## iPhone 測試清單

給使用者，T2 與 T3 一次做完，約 30 分鐘（其中 15 分鐘只是放著）。AI 測不了的原因：iPhone 上的 Obsidian 只能在手機上執行；手感、側欄手勢、iCloud 同步與離線也只有實機才看得到。量測數字由外掛自動寫成檔案，經 iCloud 傳回電腦由 Claude 讀，**不用抄任何數字**。

先確認：電腦上的測試 vault 已經同步到 iPhone（`Essence-T2` 資料夾在、設定 → 社群外掛裡有兩個「Essence T2」並且開著）。

命令都從命令面板執行：在筆記畫面由上往下拉，或點底部工具列的「≡」找「命令面板」，搜尋框輸入命令名稱的一部分。

1. **React 第一次開啟**：把 Obsidian 從多工畫面完全關掉，重新打開測試 vault。叫出命令面板，執行「(React) 開始複習」。
2. **用手指複習幾張**（約 3 分鐘）：
   - 點畫面翻面、按自評；打字題用鍵盤打一個字。
   - 在畫面中間往右滑十次左右回看，再往左滑回來。
   - 從螢幕最左邊往右滑三次，看 Obsidian 的側欄會不會跑出來。
   - 到長答案那張，上下捲十次左右。
   - 按 ✕ 結束。
3. **Preact 第一次開啟**：再把 Obsidian 完全關掉、重新打開，執行「(Preact) 開始複習」，翻兩三張後按 ✕。
4. **自動量測**：執行「(React) 自動量測」，不用碰手機，約 40 秒後出現「自動量測完成」；再執行「(Preact) 自動量測」。
5. **讀全部紀錄**：執行「(React) 讀全部紀錄」，等出現「紀錄量測完成」。
6. **離線連續複習 15 分鐘**：打開飛航模式，在對話裡跟 Claude 說一聲（Claude 會在電腦改同一份筆記，測兩端同時修改）。打開 `Essence-T2/轉錄稿.md`，最後加一行「手機改的」。執行「(React) 連續複習 15 分鐘」，手機放著不要碰，等出現「連續量測完成」。如果畫面提示無法防止螢幕變暗，先到 iPhone 設定把自動鎖定改成「永不」，測完再改回來。
7. **離線重開**：仍在飛航模式，把 Obsidian 完全關掉再打開，用 iPhone 的「檔案」app 確認 `Essence-T2/紀錄/` 裡有一個 `iPhone` 開頭的檔案（Obsidian 的檔案列表不顯示 `.jsonl`）。然後關掉飛航模式，讓 iCloud 同步幾分鐘。
8. 回到對話告訴 Claude 做完了，加上三句感想：翻卡和滑動順不順？側欄有沒有被滑出來？有沒有捲動時不小心換卡？
