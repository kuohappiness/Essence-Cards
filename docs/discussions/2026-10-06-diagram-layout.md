# 架構藍圖版面與連線重排

日期：2026-10-06。形式：討論摘要。

## 使用者回饋

使用者指出部分線條本來可以直接連接，卻有不必要的轉彎，影響美觀。使用者沒有指定圖片尺寸或比例，認為美觀及能呈現軟體架構才是重點。

## 調整與理由

- 以輸入、整理、學習及回饋作為主圖的功能區，不再另外重複畫上方循環條。
- 把教材、練習、評量與學習紀錄整合於學習區，回饋區放在整理及學習的下方。
- 透過對齊位置，將來源整理、材料製作、紀錄送入回饋、筆記回寫、材料修訂及後續複習安排全部改為直線。
- 刪除繞行外框的長回路及不必要的折線；保留各箭頭的作用與回饋方向。
- 畫布依功能分組、文字量與閱讀需求安排；本次輸出尺寸是版面結果，不成為後續固定比例。

## 結果

圖版更新為概念架構 v2.0。C-010 記錄已確認的繪圖原則；實際分組是本次依需求完成的呈現方式，未新增產品功能或改變第一版範圍。
