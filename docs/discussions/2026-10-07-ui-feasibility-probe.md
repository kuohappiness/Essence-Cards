# 自訂 UI 與可丟棄的跨裝置原型

日期：2026-10-07（Asia/Taipei）｜摘要，不是逐字紀錄

使用者在繼續功能討論前提出兩個必要確認：能否將 Obsidian 當資料層、外掛當自訂前端，讓心智圖、閃卡及多媒體不受筆記版型限制；先做盡量節省 token 的極簡 Windows／iPhone 測試，原型未來可以完全推翻。

助理查核官方文件後的判斷：自訂 View 可承載網頁式 UI；仍有宿主分頁／手機導航、WebView、效能與生命週期限制。Vault 是檔案資料層，不是共享 SQL 後端。手機不得依賴 Node.js／Electron。這些是技術判斷，實際雙端結果仍待測。

依使用者要求，建立獨立原型 `experiments/obsidian-ui-probe/`，僅驗證自訂 UI、單張閃卡、固定心智圖、本機附件與一份測試 Markdown 的讀寫。沿用 iCloud，一次一端修改；沒有建立正式 schema、AI、學習事件或 Git 回復。

當時確認範圍：先做可丟棄測試、介面需可自由表現教材。當時未確認：正式 UI 技術框架、資料架構、真實裝置相容性與同步可靠性。

實作與證據界線見 [驗證文件](../obsidian-ui-probe.md)，操作見 [原型 README](../../experiments/obsidian-ui-probe/README.md)。受影響的共識與任務：C-018、T-011；保留 C-014、T-008 原本完整 P0 的驗證要求。
