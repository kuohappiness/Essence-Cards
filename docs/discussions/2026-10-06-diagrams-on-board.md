# 藍圖直接呈現在看板

日期：2026-10-06（Asia/Taipei）。討論摘要。

使用者要求 diagrams 裡的架構圖也放在看板上。原版只在「架構藍圖」分頁顯示完整圖，預設看板與自由畫板沒有直接呈現圖片。

依此要求，將知識學習架構、技術架構與 Git 設計、開發路線圖三張當前藍圖直接放在看板與自由畫板上方。圖片由既有完整藍圖取用，點開後進入對應大圖與設計重點，保留已確認／待驗證狀態。

手機純靜態閱讀版繼續直接呈現完整圖，不依賴腳本。本次調整的是討論平台的呈現方式，技術選型、Git 策略及學習工具範圍未因此改變。
