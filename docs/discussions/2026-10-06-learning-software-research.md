# 參考學習軟體初查

日期：2026-10-06（Asia/Taipei）

使用者要求：搜尋看板既有 RemNote、Memory Toast 以外的熱門學習軟體，完成 softeware.md 清單的待研究資訊。核對 repo 後，現行正式檔案是 docs/references/software.md，沿用此檔而不另建拼字相近的第二份。

執行結果：保留 R-001／R-002 並補資料；新增 R-003 至 R-012，為 Anki、Quizlet、Brainscape、Mochi、SuperMemo、Readwise Reader、NotebookLM、Recall、Knowt、StudySmarter。涵蓋常見學習平台及具有流程設計參考價值的工具，未宣稱同屬熱門排名。

本輪只讀官方網站、說明、商品頁與開發者 App Store 資料，未註冊、付費或操作產品。記錄定位、已查核功能、費用、平台、離線／同步、內容與事件匯出限制、可借鑑方向及待實測問題。來源衝突與未確認欄位保留，不推測缺失能力。

研究發現：RemNote 的筆記製卡及 Edit Later、Anki／Mochi 的內容與完整備份分工、Readwise 的來源標註與追加式匯出、NotebookLM／Recall 的答後來源解析，可帶入後續功能討論。這些為助理分析，不是使用者已採用的功能。

重要限定：Memory Toast 官網與商店對 SM-2／FSRS 及點數／Premium 描述不同；SuperMemo Windows 與語言平台分開；Knowt 同頁年價與月均數不一致；Markdown／CSV 可匯出不保證附件、排程、來源與逐次事件皆保留。

下一步（助理提案）：用同份繁體中文生物教材優先比較 RemNote、Anki、Mochi、Readwise Reader、NotebookLM、Recall；Memory Toast 另測手機拍照與複習。待實測、優先順序及是否採用仍開放討論。
