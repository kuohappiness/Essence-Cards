# 2026-10-06｜知識獲取到內化與六大流程

日期：2026-10-06（Asia/Taipei）  
形式：討論摘要，並非逐字紀錄。

## 起點與討論方向

使用者開始討論 Essence Cards。助理先建議從真實情境切入；使用者提出以工具應有哪些功能作為規劃藍圖，詢問知識從截取到牢牢記住的流程。後續依使用者方向轉為流程與功能討論。

助理最初提出八點：收集與截取、篩選與萃取、理解與澄清、組織與連結、轉成練習、主動回想與訂正、間隔複習、應用與檢驗。八點是當時提案，現行討論架構已整合為六大流程。

## 使用者五點想法

- 消化來源資料，寫成概念筆記，相似概念關聯、建立比較表。
- 根據真題、筆記與歷次錯題，出模擬考題閃卡。
- 針對錯題加強學習，寫回概念筆記。
- 複雜概念做成互動式網頁；需背誦資料做成記憶卡。
- 定期復盤，掃描每個主題學習狀況與錯誤率，安排下週學習進度。

使用者希望將以上想法與助理八點整合。

## 整合提案與結果

助理整理成：1. 獲取來源資料；2. 消化成概念筆記；3. 依學習需要製作材料；4. 出題、作答與診斷；5. 錯題補強與筆記更新；6. 定期復盤與學習安排。

使用者回應：
> 好，那我們就以上面的六大流程來做討論。

因此 C-007 確認的是六大流程作為後續討論架構。題型、評分、自動化、平台、介面與第一版範圍尚未確認。

## 助理後續設計提案與理由

- 以概念筆記為中心，來源、比較表、教材、考題與卡片保留關聯，便於回原文與錯題補強。
- 區分考題閃卡與記憶卡：前者檢驗理解與應用，後者練習回想；具體形式與排程未定。
- 互動教材可在初學或補強時製作，不將其限制為固定的第四步。
- 診斷錯因後再決定補強方式，區分不理解、混淆、忘記、讀錯題與題目有誤；保留可核對的筆記修改。
- 每週復盤安排學習方向，平日排程安排間隔複習；進度判斷不僅使用錯誤率。
- 提出今日學習、主題工作區、學習回顧三個入口；仍屬未來工具的介面提案。
- 保留來源、人工修正、版本、匯出、備份與還原。
- 完整藍圖可涵蓋六流程，先接通基本循環再深化模組；沒有工期、成本或成效承諾。

以上理由是助理的設計判斷；使用者沒有逐項採用。最初八點及演變過程留在此紀錄，不另列為畫板的有效共識。
