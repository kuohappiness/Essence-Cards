# Essence Cards｜出題語法與資料格式

更新：2026-10-16｜狀態：✅ 定稿（[D-092](decisions.md#d-092-出題語法定稿正式規範)）；標 💡 的地方是整合時補上的提案，待使用者確認

這份文件是 Essence Cards 讀寫的檔案格式的唯一規範：家長手寫照它寫，AI 照它輸出，程式照它解析。每一條的理由寫在決策紀錄，這裡只列 D-ID。

- [製卡規則](card-rules/README.md)的輸出格式必須符合這份文件；改語法時一起改。
- 這些都是公開格式（[架構 §3](architecture.md#3-模組邊界-第-5-步)）：之後只新增欄位，不改舊欄位的意思；讀取時忽略不認得的欄位與屬性。
- 例子都是自己編的，不是課本原文（[D-003](decisions.md#d-003-公開範圍)）。

狀態標示：✅ 已確認｜💬 待討論｜💡 助理提案

## 0. 總覽

| 檔案 | 位置 | 誰寫入 | 格式 |
|---|---|---|---|
| 轉錄稿 | 教材庫，位置由 Capture 設定（[D-088](decisions.md#d-088-錯題本考試範圍與系統資料夾) 補充） | Capture | [§1](#1-轉錄稿) |
| 卡組筆記 | `Essence Cards/` 裡、系統資料夾以外 | 家長；AI 的草稿；外掛（補 ID、批次修改、加入） | [§2](#2-卡組筆記) |
| 錯題本 | `Essence Cards/錯題本/` | AI 的草稿；家長；外掛（採用） | [§3](#3-錯題本) |
| 考試範圍 | `Essence Cards/考試範圍/` | 外掛（家長在目錄勾選） | [§4](#4-考試範圍) |
| 複習紀錄 | `Essence Cards/紀錄/` | 只有外掛 | [§5](#5-複習紀錄) |
| AI 輸出快照 | `Essence Cards/紀錄/AI 輸出/` | 只有外掛 | [§6](#6-ai-輸出快照) |

資料夾結構見[架構 §5](architecture.md#5-資料存放-第-6-步)。

**檔名**：整個 vault 不重複，因為連結靠檔名找筆記（[D-081](decisions.md#d-081-卡組屬性與檔名)）。外掛建立的檔案都照這個規則命名：

| 檔案 | 例子 |
|---|---|
| 轉錄稿 | `國二上自然 2-2 水溶液.md` |
| 轉錄稿的圖 | `國二上自然 2-2 圖2-14.png` |
| 卡組 | `國二上自然 2-2 水溶液（卡片）.md`、`構圖基礎（卡片）.md` |
| 錯題本 | `國二上自然 第一次段考.md` |
| 考試範圍 | `國二上 第一次段考.md` |
| 複習紀錄 | `2026-10 iPhone-7f3a.jsonl` |
| AI 輸出快照 | `2026-10-16 國二上自然 2-2 水溶液（卡片）.md` |

**共通的寫法**：

- 欄位的冒號，全形「：」、半形「:」都認得；AI 與程式寫全形。YAML 屬性照 YAML 用半形。
- 同一個欄位有好幾個值，用頓號「、」分隔；同一行有好幾個欄位，用「｜」分隔。
- 區間用「～」，也認得「~」。

## 1. 轉錄稿

Capture 把課本、講義忠實轉錄成的 Markdown，是兩個外掛唯一的接點（[D-076](decisions.md#d-076-capture-是知識入口教材轉錄成教材庫)、[D-080](decisions.md#d-080-轉錄稿的錨點與出處的寫法)）。教材庫是共用、唯讀的：Cards 只讀，不寫進任何個人的回饋（[D-093](decisions.md#d-093-教材庫共用個人回饋留在錯題本)）。

```markdown
---
來源類型: 課本
來源: 國二上自然 第二章.pdf
出版社: 翰林
版次: 114 學年度
建立日期: 2026-10-13
---

# 2-2 水溶液

p.43 ^p43

## 1 溶液

糖放進水裡，攪拌後看不見了，形成均勻的**糖水**。……

p.44 ^p44

## 2 擴散現象

……

![[國二上自然 2-2 圖2-14.png]]
*圖 2-14 黑糖在水中慢慢散開* ^fig2-14

> [!補充] 知識快遞
> ……

| 溫度（°C） | 20 | 60 |
|---|---|---|
| …… | …… | …… |

^tab2-1

**例題 2-3** ^ex2-3

……
```

**屬性**：

| 屬性 | 內容 | 必填 |
|---|---|---|
| 來源類型 | 例如 課本、講義、圖片 | 必填。Cards 只看有沒有這個屬性：有就不當成卡組，放在哪裡都一樣（D-088 補充） |
| 來源 | 原檔名或網址（[D-031](decisions.md#d-031-capture-定位與交接約定修訂)） | 必填 |
| 出版社、版次 | 例如 `翰林`、`114 學年度`；從檔名猜，家長可以改（D-080 補充） | 課本才寫 |
| 建立日期 | 轉錄的日期，用來判斷來源有沒有更新 | 必填 |

Capture 不寫年級、科目這類學生專用的資訊（D-031）；冊別與科目只出現在檔名，因為它們是課本本身的名稱。

**錨點**（只需要在同一篇轉錄稿裡不重複，連結一定帶著筆記名稱）：

| 錨點 | 寫法 | 例子 |
|---|---|---|
| 頁碼 | 看得到的一小行 `p.頁碼 ^p頁碼`，前後各空一行；頁面上看不到頁碼時寫 PDF 頁序 | `p.44 ^p44`；`PDF 第 12 頁 ^pdf12` |
| 有編號的圖 | 圖檔與圖說寫在同一段：圖檔一行，下一行是斜體圖說，ID 在圖說最後 | 圖 2-14 → `^fig2-14` |
| 沒有編號的圖 | ID 用頁碼加這一頁的第幾張 | `^p43-fig1` |
| 有編號的表 | Markdown 表格；表格之後空一行，再單獨一行寫 ID，後面也空一行（Obsidian 對表格區塊 ID 的規定） | 表 2-1 → `^tab2-1` |
| 例題 | 例題的標題寫成粗體段落，ID 在同一行最後（Obsidian 的標題不能加區塊 ID） | 例題 2-3 → `^ex2-3` |
| 段落標題 | 照課本的層級用 `#`、`##`、`###`；Obsidian 本來就能連結，不另加 ID | `## 2 擴散現象` |

**其他規則**：

- 忠實轉錄，不摘要；粗體照原樣；公式用 LaTeX，例如 `$\text{g/cm}^3$`。
- 圖檔名含冊別、科目、單元與圖號：`國二上自然 2-2 圖2-14.png`；沒有編號的用錨點，例如 `國二上自然 2-2 p43-fig1.png`。只用來裝飾的圖不截。
- 表格寫不成 Markdown 表格的（合併儲存格太多），當成圖處理。
- 「補充閱讀」這類方框寫成引言框，例如 `> [!補充] 知識快遞`；教師用書給老師看的內容寫成 `> [!教師註記]`，製卡時只當判斷重點的線索，不當課本內容出題。
- 看不清楚的字寫 `[?]`，後面括號寫最可能的字，例如 `[?]（溶）`，給家長檢查；為了讓圖表看得懂、非補不可的說明，標 `[AI 補充]`。

## 2. 卡組筆記

### 2-1 屬性

卡組的 YAML 屬性，名稱用中文（[D-081](decisions.md#d-081-卡組屬性與檔名)）：

| 屬性 | 寫法 | 沒寫時 |
|---|---|---|
| 年級學期 | 文字，例如 `國二上` | 不是學業卡組 |
| 科目 | 文字，例如 `自然` | 不是學業卡組 |
| 單元 | 「編號 名稱」寫在一欄，第一個空格前是編號：`2-2 水溶液`、`L1 Back to School`；目錄依編號自然排序（[D-033](decisions.md#d-033-教材目錄)） | 不進教材目錄 |
| 材料 | 轉錄稿或來源筆記的連結，可以有好幾個；出處靠它找到錨點 | 出處無法跳回教材 |
| 狀態 | 草稿、啟用、暫停 | 啟用（手寫的卡組不寫 YAML 也能用，[D-009](decisions.md#d-009-一般筆記可直接使用)） |
| 分類 | 清單，例如 `[醫學, 睡眠]`；家長決定，AI 只能從用過的分類挑（[D-064](decisions.md#d-064-卡組分類改用屬性)） | 無 |

- YAML 不放複習進度（[D-008](decisions.md#d-008-學習紀錄與來源修改)）。
- 卡組與卡片完全不用 Obsidian 標籤（D-064）。
- 草稿的卡組學生看不到；家長審核完改成啟用（[D-039](decisions.md#d-039-v1-範圍)）。

### 2-2 兩條規則

英文、自然、其他領域都一樣（[D-079](decisions.md#d-079-卡組筆記的結構與學習目標的資料)）：

1. **清單最上層的每一項＝一個學習目標**：這一行寫名稱，學習目標 ID 在這一行最後。底下沒有任何題目的，只是一般筆記。
2. **學習目標底下**：有 `::` 或 `==填空==` 的是題目，第一題是基本題；開頭是欄位名稱加冒號的是資料；其他是每一題共用的背面補充。**題目底下**是這一題的背面補充。

其他的都不是卡片：

- 標題只用來分組；一般段落是家長的筆記。
- 引言框（callout）與程式碼區塊裡的東西都不算，可以放家長的筆記（[D-089](decisions.md#d-089-語法的邊界規則與寫錯時的處理) 第 8 條）。AI 的備註與候選卡片就是靠這一條（[§2-9](#2-9-ai-製卡交回的草稿)）。
- 清單的上下層以 Obsidian 解析的結果為準；縮排用 Tab 或空格都可以（D-089 第 6 條）。

**自然的例子**（審核完、已啟用，也已經採用了 [§3](#3-錯題本) 的錯題本；ID 是程式補的）：

```markdown
---
年級學期: 國二上
科目: 自然
單元: 2-2 水溶液
材料:
  - "[[國二上自然 2-2 水溶液]]"
狀態: 啟用
---

## 1 溶液

- 能說出溶質與溶劑的意思 ^k3m9x2
    - 出處：p.43｜類型：定義｜錯題補強：[[國二上自然 第一次段考]]
    - 糖水裡，哪一個是溶質？哪一個是溶劑？ :: 糖是**溶質**，水是**溶劑**
    - 碘酒裡的溶劑是什麼？ :: **酒精**
- 能說明溶液的質量組成 ^h2m8qd
    - 出處：p.43｜類型：因果｜重要性：高｜錯題補強：[[國二上自然 第一次段考]]
    - 溶液的質量怎麼算？ :: **溶質**的質量加上**溶劑**的質量
    - 糖加太多、杯底有沉澱時，溶液的質量怎麼算？ :: **只算已溶解的溶質**加上**溶劑**

## 2 擴散現象

- 能用粒子運動說明擴散現象 ^p7q2w8
    - 出處：p.44、圖 2-14｜類型：因果｜重要性：高
    - 黑糖放進水裡，不攪拌也會慢慢變甜，為什麼？ :: 粒子**不停運動**，糖從**濃度高**的地方散到**濃度低**的地方
        - ![[國二上自然 2-2 圖2-14.png]]
- 能說出影響溶解快慢的因素 ^w4s8nd
    - 出處：p.45｜類型：因果
    - 水溫越==高==、顆粒越==小==、有==攪拌==，糖溶解得越快
- 老師說這一段只要看懂，不用背
- 能說明溶液靜置後不會分層 ^r5t9vb
    - 出處：2-2 p.43｜類型：因果｜錯題補強：[[國二上自然 第一次段考]]
    - 糖水放一整天，杯底會出現糖嗎？為什麼？ :: **不會**；溶解的糖粒子和水**均勻混合**，不會自己沉下去
```

逐行對照：

| 這一行 | 是什麼 | 依據 |
|---|---|---|
| `## 1 溶液` | 分組的標題，照課本的小標題 | D-079、[D-091](decisions.md#d-091-ai-製卡的輸出格式) |
| `- 能說出溶質與溶劑的意思 ^k3m9x2` | 學習目標，ID 在最後 | D-079 |
| `- 出處：p.43｜類型：定義` | 資料：一行好幾個欄位 | D-079、[§2-4](#2-4-資料欄位) |
| `- 糖水裡……？ :: 糖是**溶質**……` | 基本題 | [D-028](decisions.md#d-028-題目池) |
| `- 碘酒裡的溶劑是什麼？ :: **酒精**` | 進階題：答對基本題之後輪流出 | D-028 |
| `錯題補強：[[國二上自然 第一次段考]]` | 採用錯題本時外掛加的；「能說明溶液的質量組成」的第二題也是那時候從錯題本搬進來的 | [§3](#3-錯題本) |
| `- 能說明溶液靜置後不會分層` | 錯題本裡「卡片沒涵蓋」的新目標，採用時加在最後 | §3 |
| `- ![[國二上自然 2-2 圖2-14.png]]` | 這一題的背面補充：幫助記憶的圖 | D-091 |
| `- 水溫越==高==……` | 填空題：一行的空格一起挖，一行＝一題 | [D-049](decisions.md#d-049-一行多個填空一次全挖) |
| `- 老師說這一段只要看懂，不用背` | 底下沒有題目，是一般筆記 | D-089 第 12 條 |

**英文的例子**（[D-082](decisions.md#d-082-英文卡組與朗讀)）：

```markdown
---
年級學期: 國二上
科目: 英文
單元: L1 Back to School
材料:
  - "[[國二上英文 L1 Back to School]]"
狀態: 啟用
---

- borrow 英翻中 ^b4rw7k
    - borrow :: v. 借入、向別人借
        - 例句：Can I borrow your pen? 我可以借你的筆嗎？
- borrow 中翻英 ^c9tn3e
    - Can I ＿＿ your pen?（借） :: borrow
    - 記憶錨點：易混淆 lend（借出：把東西借給別人）
- uniform 英翻中 ^u6vf2m
    - uniform :: n. 制服
        - 例句：We wear uniforms to school. 我們穿制服上學。
```

- 「例句：」在題目底下，是那一題的背面補充；「記憶錨點：」在學習目標底下，那個方向的每一題都顯示，另一個方向不顯示（D-082）。兩者都不是資料欄位（[§2-4](#2-4-資料欄位)）。
- 沒有「發音」那一行，也不寫 KK 音標：複習畫面用系統語音直接念題目或答案裡的英文（D-082）。
- uniform 只開了英翻中：中翻英由家長決定要不要開（[英文製卡規則](card-rules/english.md)）。

### 2-3 學習目標

- **名稱**：學業的寫成「能……」，例如「能用粒子運動說明擴散現象」；英文單字寫「單字 英翻中」、「單字 中翻英」（D-082）。名稱是給家長與目錄看的；出題時只顯示題目，因為中翻英的名稱本身就是答案。
- **ID**（[D-034](decisions.md#d-034-學習目標-id)、D-079）：
  - Obsidian 原生的區塊 ID，寫在名稱那一行最後；6 碼，只用小寫英文與數字，去掉 0、o、1、l、i；整個 vault 不重複，刪除後不再使用。
  - 家長與 AI 都不寫。家長離開筆記或停止輸入後，程式一次補齊。
  - 閱讀模式由 Obsidian 隱藏，編輯模式由外掛調淡。
  - 家長自己加過的區塊 ID 直接沿用；複製造成重複時，原本那個保留，新的換一個。
  - 題目那一行的區塊 ID 不是學習目標 ID（D-089 第 9 條）。題目不加 ID，用指紋辨認（[§2-8](#2-8-題目指紋)）。
- **最上層直接寫了題目**（例如 `- borrow :: 借入`）：程式補 ID 時，在上面補一行學習目標，名稱取題目的部分；填空題取整行、拿掉 `==` 記號。家長可以改名稱（D-079）。
- **外掛畫的「目標」標籤**：每一個學習目標前面，編輯與閱讀模式都由外掛畫一個小標籤；筆記文字裡沒有標記（D-079）。
- **英文的兩個方向是同一組**：同一篇卡組裡，名稱去掉最後的「 英翻中」、「 中翻英」之後相同。英翻中變成「記得」之後才出中翻英；同一天到期只出一個（[D-069](decisions.md#d-069-新卡的開始與同一個字的兩個方向)）。
- **中翻英要打字**（[D-066](decisions.md#d-066-作答方式)）：從名稱判斷，不另寫欄位。答案只能是一個單字或片語，程式逐字比對，大小寫與前後空白不算錯；一題只有一個正確答案，有兩種拼法的字由 AI 避開或附提示（D-089 第 13 條）。

### 2-4 資料欄位

6 個欄位，都屬於整個學習目標，不屬於單一題目（D-079、D-082 刪掉「作答」）：

| 欄位 | 值 | 沒寫時 |
|---|---|---|
| 出處 | 見 [§2-5](#2-5-出處) | 卡組本身的單元 |
| 類型 | 製卡規則的知識類型，例如 定義、因果、詞彙、文法句型 | 不分類 |
| 重要性 | 高、中、低 | 中 |
| 狀態 | 暫停 | 啟用 |
| 備註 | 頓號分隔的短詞，例如 `段考一必考、老師強調`；家長寫（[D-063](decisions.md#d-063-卡片的狀態來源學習狀況與備註)） | 無 |
| 錯題補強 | 錯題本的連結；好幾次考試都錯過，用頓號列出（D-088） | 無 |

- **只認這 6 個名稱**。其他「名稱：」開頭的子項目，例如「例句：」、「記憶錨點：」，是背面補充。
- 預設值不寫出來。AI 與程式把資料寫成一行、緊接在學習目標那一行下面；家長手寫時一個欄位一行、放在其他位置也認得。
- 同一個欄位寫了兩次：出處、備註、錯題補強合併；其他欄位用第一個，並標出提示。
- 值認不得（例如「重要性：很高」）：當作沒寫、用預設值，並標出提示（D-089 第 11 條）。
- 錯題補強的日期看錯題本的「日期」，不另外記（D-088）。
- **資料不打擾學生**：複習畫面不顯示類型、重要性、狀態、備註；出處只留一個小圖示，點了打開轉錄稿的錨點（D-079）。

### 2-5 出處

D-080：家長看得懂、手寫容易，AI 不用知道檔名。

- **一項一項用頓號分隔，每一項各自獨立**：沒寫單元的那一項，是卡組本身的單元。
- 一項＝（單元）＋位置＋（說明文字）：

| 位置 | 寫法 | 程式怎麼找 |
|---|---|---|
| 頁碼 | `p.44` | 「材料」裡的轉錄稿，依序找第一個有 `^p44` 的 |
| 圖、表、例題 | `圖 2-14`、`表 2-1`、`例題 2-3` | 同上，找 `^fig2-14`、`^tab2-1`、`^ex2-3` |
| 段落標題 | `睡眠的階段` | 「材料」裡的筆記，找這個標題 |
| 其他筆記 | `[[水溶液實驗影片筆記#溶解的速度]]` | 連結本身 |

- **跨單元**：前面加單元，例如 `出處：1-3 p.20、p.44`（1-3 的 p.20 和這一篇的 p.44）。程式先找那個單元的卡組，再看它的材料。只寫單元也可以，例如 `出處：L3`。跨學期再加年級學期，例如 `國一下 L5`。
- 位置後面的文字照樣顯示，例如 `p.45 知識快遞`。
- 程式認不得的照文字顯示，不做連結（D-088），例如 `先備：國一數學 比例式`（[D-087](decisions.md#d-087-錯因加先備知識不足)）。
- 不寫「第幾段」（D-080）。
- **學習目標屬於哪些單元**：卡組本身的單元，加上出處寫到的其他單元。考試範圍、考前提高目標保持率都照這個判斷（[D-026](decisions.md#d-026-儲存範圍排程分開)、[D-078](decisions.md#d-078-目標保持率與考前提高)）。

寫的時候（D-080 補充）：課本轉錄稿寫短的；其他筆記，卡組只有這一份材料時寫段落標題，有好幾份材料時寫成連結，家長一看就知道是哪一份。

### 2-6 題目

| 寫法 | 例子 | 說明 |
|---|---|---|
| 問答 | `- 碘酒裡的溶劑是什麼？ :: **酒精**` | `::` 左邊是題目、右邊是答案 |
| 多行答案 | `- 質量和重量有什麼不同？ ::` 加上縮排的子項目 | `::` 後面沒有答案時，底下不是資料的子項目就是答案（D-089 第 4 條） |
| 填空 | `- 水溫越==高==、顆粒越==小==……` | 一行裡的空格一起挖，學生作答、自評一次（D-049） |

- 第一題是基本題，給前幾次複習；答對後輪流出其他題（D-028）。題目池裡的每一題測同一種能力、難度相近。
- `::` 前後有沒有空格都認得；AI 與程式一律寫成 ` :: `（D-089 第 1 條）。
- 同一行有 `::` 又有 `==…==`：`==` 只是螢光筆，不是填空（D-089 第 3 條）。
- 行內程式碼、公式裡的 `::`、`==` 不算（D-089 第 2 條）。
- 題目與答案可以有粗體、圖片 `![[ ]]`、公式 `$…$`、連結，複習畫面照樣呈現（D-089 第 7 條）。
- 理解題的答案寫 1～3 個重點，重點用粗體；粗體都想得出來才算記住了（[D-068](decisions.md#d-068-理解題的重點與看答案也是複習)）。
- **圖**（D-091）：只放圖檔，不放圖說（圖說常常就是答案）。題目問的就是這張圖時，放在題目那一行；只是幫助記憶時，放在題目底下。

### 2-7 複習畫面看到什麼

| 正面 | 背面 | 不顯示 |
|---|---|---|
| 題目；填空題是挖掉空格的整行 | 答案、這一題底下的補充、學習目標底下的共用補充（例如記憶錨點） | 學習目標名稱、ID、資料；出處只留圖示 |

### 2-8 題目指紋

複習紀錄的 `v`，用來輪流出題、找出總是答錯的那一題（[D-046](decisions.md#d-046-題目以內容指紋識別)）。只需要在同一個學習目標裡分得開（D-079）。

- 算進去的：題目和答案。填空題用整行；多行答案用底下的每一個子項目。
- 不算的：ID、這一題底下的背面補充（例句、圖）、學習目標的共用補充（記憶錨點）、資料。
- 先整理：拿掉清單符號與縮排，連續的空白與換行當成一個空格；只改空白不算改題。
- 實作細節：整理後的「題目＋換行＋答案」取 SHA-256，用前 8 個十六進位字元。兩台裝置一定要用同一種算法，才會算出同一個指紋。

### 2-9 AI 製卡交回的草稿

AI 交回來的文字就是卡組的本文（D-091）。外掛寫上屬性（狀態：草稿）、替每個學習目標配好 ID，存成草稿；另存一份快照（[§6](#6-ai-輸出快照)）。AI 不寫 ID 與屬性。

````markdown
> [!note] 給家長的備註
> - 例題 2-3 的濃度計算不適合做成卡，建議讓孩子做習作練習

## 2 擴散現象

- 能用粒子運動說明擴散現象
    - 出處：p.44、圖 2-14｜類型：因果｜重要性：高
    - 黑糖放進水裡，不攪拌也會慢慢變甜，為什麼？ :: 粒子**不停運動**，糖從**濃度高**的地方散到**濃度低**的地方
        - ![[國二上自然 2-2 圖2-14.png]]

> [!note] 加進已有的學習目標
> - q8z3ka 能用密度判斷物體的浮沉
>     - 出處：p.46
>     - 雞蛋在清水裡會沉，在濃鹽水裡卻浮起來，為什麼？ :: 鹽水的**密度變大**，比雞蛋**大**

> [!note]- 候選卡片
> - 能說明溫度對溶解度的影響
>     - 理由：知識快遞的內容，段考不一定考
>     - 出處：p.45 知識快遞｜類型：因果
>     - 水溫升高時，糖在水中的溶解度會怎麼變？ :: 變**大**
````

由上到下：

| 部分 | 規則 | 依據 |
|---|---|---|
| 給家長的備註 | 最上面的引言框，只寫三種事：課本和一般說法不一致、建議另外練習的計算題、課本可能印錯；沒有就整段省略。一般知識的卡組改叫「給學習者的備註」 | D-091、[D-086](decisions.md#d-086-教材和-ai-的知識不一致時照教材) |
| 學習目標 | 用課本的小標題 `##` 分組；直接附圖；數量都是上限，不湊數 | D-091 |
| 加進已有的學習目標 | 💡 教材再次出現學生已有的知識時（[D-027](decisions.md#d-027-跨課題目與重複出現的知識)），不新增學習目標，把新題目寫在這裡：每一項是已有的 ID 和名稱（例子裡的 `q8z3ka` 在 2-1 的卡組），底下是要加的出處、題目或記憶錨點。存草稿時程式把 ID 轉成連結。沒有就整段省略 | D-027 |
| 候選卡片 | 最後、預設摺起；最多 5 個，沒有值得的就不列。每個照樣寫完整的題目，第一行是一句「理由：」 | D-091 |

- **引言框裡的都不會被排程**（D-089 第 8 條）。閱讀模式每一項旁有「加入」，框上有「全部加入」：
  - 候選卡片：外掛把它移出引言框，拿掉「理由」那一行。
  - 💡 加進已有的學習目標：外掛把題目與補充搬到那個學習目標底下，再從引言框拿掉。出處合併時，沒寫單元的項目補上這一篇的單元；沒有出處那一行時，也把這一篇的單元加進去（D-027「在出處加上新的課」）。
  - 沒加入的留著也不影響任何東西。
- **候選卡片在存草稿時就配好 ID**，加入時 ID 跟著搬出來。這樣快照和卡組用同一組 ID，加入的候選不會被當成家長自己加的（[D-042](decisions.md#d-042-ai-製卡快照) 的比對）。
- 💡 **延伸**：學業卡組裡，出處只連到課本以外的筆記的學習目標，就是延伸內容（D-080 補充、[D-083](decisions.md#d-083-延伸內容也能做成卡片)）。程式從出處算出來，篩選區與濾網的「延伸」同時涵蓋這些學習目標和分類為「延伸」的卡組；不另寫欄位。

### 2-10 寫錯時

D-089 第 10 條：只跳過有問題的那個學習目標，同一篇的其他卡照常複習；編輯畫面標出問題，目錄的卡組旁顯示「2 個學習目標寫法有問題」，點了就跳過去。

| 算寫錯，跳過那個學習目標 | 不算寫錯 |
|---|---|
| `::` 左邊沒有題目 | 最上層的項目底下沒有題目：一般筆記 |
| `問題 ::` 底下沒有答案 | 欄位值認不得：用預設值並提示 |
| 中翻英的答案是多行或含有中文，程式沒辦法比對拼字 | 縮排錯一層：意思會變，但不是錯；靠編輯畫面的樣式看出來（[D-047](decisions.md#d-047-編輯畫面標示卡組結構)） |

## 3. 錯題本

一次考試一科一份，放在系統資料夾，裡面的題目在採用前不會被排程（D-088）。AI 交回來的文字就是錯題本的本文；外掛寫上屬性，存成草稿。下面是採用前的草稿；採用後的卡組見 [§2-2](#2-2-兩條規則)。

```markdown
---
年級學期: 國二上
科目: 自然
考試: 第一次段考
日期: 2026-10-20
分數: 78
班平均: 72
狀態: 草稿
---

> [!note] 給家長的備註
> - 三題都和「溶液是什麼」有關，考前可以請孩子再讀一次 2-2 的第一段

### 錯題 1：50 g 糖加進 20 g 水，杯底剩 10 g 沒溶解，溶液質量是多少？
- 學生答案：70 g
- 正確答案：60 g，未溶解的糖不算在溶液裡
- 錯因：觀念混淆
- 理由：把加進去的糖全部算成溶質。溶液只包含已經溶解、和水均勻混合的部分；杯底那 10 g 沒有溶解，不屬於溶液，所以溶液是 40 g 的糖加 20 g 的水。
- 對應：[[國二上自然 2-2 水溶液（卡片）#^h2m8qd|能說明溶液的質量組成]]
- 補強：
    - 糖加太多、杯底有沉澱時，溶液的質量怎麼算？ :: **只算已溶解的溶質**加上**溶劑**

### 錯題 2：糖水裡的溶劑是什麼？
- 學生答案：糖
- 正確答案：水
- 錯因：忘記
- 理由：溶質和溶劑記反了；拿不準是粗心還是忘記時選忘記
- 對應：[[國二上自然 2-2 水溶液（卡片）#^k3m9x2|能說出溶質與溶劑的意思]]
- 補強：提前複習

### 錯題 3：把糖水靜置一天，杯底會不會出現糖？
- 學生答案：會
- 正確答案：不會，溶液是均勻、穩定的
- 錯因：不會應用
- 理由：以為糖水放久了糖會沉下來。溶解後的糖粒子和水粒子均勻混合，而且一直在運動，放著不動也不會自己沉到杯底；會沉下去的是本來就沒溶解的部分。
- 對應：卡片沒涵蓋
- 補強：
    - 能說明溶液靜置後不會分層
        - 出處：2-2 p.43｜類型：因果
        - 糖水放一整天，杯底會出現糖嗎？為什麼？ :: **不會**；溶解的糖粒子和水**均勻混合**，不會自己沉下去
```

**屬性**：年級學期、科目、考試、日期必填；分數、班平均選填（作業的錯題沒有分數，[D-075](decisions.md#d-075-成功標準的量測方式)）；狀態是草稿或已採用。總覽拿同一科上一次的分數比較。

**每一題**一個 `###` 標題，寫題目摘要；底下固定六個欄位：

| 欄位 | 寫法 |
|---|---|
| 學生答案 | 照考卷 |
| 正確答案 | 考卷沒有答案時由 AI 解題，標 [AI 補充]（[D-061](decisions.md#d-061-錯題補強的流程)） |
| 錯因 | 全科共用六類：忘記、觀念混淆、不會應用、先備知識不足、粗心、題目或答案有誤（D-088）。家長在閱讀模式點一下就能換 |
| 理由 | AI 寫；觀念混淆、不會應用多寫兩三句，把觀念講清楚，不只寫錯在哪裡。家長可以直接改，採用前後都可以（D-093） |
| 對應 | AI 寫已有的學習目標 ID 和名稱，例如 `h2m8qd 能說明溶液的質量組成`，存草稿時程式轉成連結。沒有對應的目標時寫「卡片沒涵蓋」；先備知識還沒有卡時寫「先備知識」（D-087） |
| 補強 | 三種之一：要加進對應目標的題目；一個完整的新學習目標，寫法和卡組相同；或一段文字：`提前複習`、`無`、`建議另外練習：……` |

- **新的學習目標**：錯題本不屬於任何單元，所以出處的每一項都寫單元。外掛照 D-027 放進出處裡最晚的單元的卡組；先備知識放進這一題的科目，例如 `出處：2-2、先備：國一數學 比例式`（D-087）。
- **給家長的備註**：最上面的引言框，只寫跨題的共同模式；沒有就省略。粗心的提醒、題目有誤的疑點寫在那一題的「理由」。

**採用之後**（家長按「採用」，D-088）：

- 補強的題目搬到對應的學習目標底下，錯題本裡改成一行 `補強：已加入`，後面接連結；同一題不留兩份。新的學習目標搬進卡組，配好 ID。
- 「對應」的「卡片沒涵蓋」、「先備知識」後面接上新目標的連結，標記留著，用來算漏掉率（D-042 補充）。
- 有對應的學習目標都加上「錯題補強」欄位，值是這份錯題本的連結；錯因是忘記、沒有加題的也標上。
- 錯因是忘記，或先備知識已經有卡（照忘記處理）的，記一筆 `miss`，來源 `mistake`（[§5](#5-複習紀錄)）。
- 錯題本的狀態改成已採用，留下來當這次考試的紀錄。之後的「看錯題說明」從學習目標的「錯題補強」連到錯題本，再用「對應」找到那一題（D-093）。

## 4. 考試範圍

告訴排程這次考哪些單元、哪天考（D-088、D-078）。由外掛寫入，家長在目錄勾選，最多三步（[D-071](decisions.md#d-071-每天的複習怎麼排)）。

```markdown
---
考試日期: 2026-10-20
---
- 國二上 英文 L1～L2
- 國二上 自然 1-1～2-2｜2026-10-21
```

- **一行一科**：💡 寫成「年級學期 科目 範圍」。D-088 的例子沒有年級學期，但英文的 L1 每一學期都有、自然的 1-1 每一冊都有，少了它就分不出是哪一冊；每一行自己寫，複習考、會考跨好幾冊也寫得出來。
- **範圍**（D-033）：單一節 `2-2`；區間 `1-1～2-2`，照編號自然排序，包含兩端；整章 `2`，「2-」開頭的都算。好幾段用頓號：`1-1～1-3、2-2`。
- 💡 **分類**：一行寫 `分類：醫學`，有這個分類的卡組都算（D-064）。
- **日期**：屬性的考試日期是預設；某一科不同天時，在那一行後面用「｜」寫日期。沒有日期的考試範圍仍可用，只是不會考前提高目標保持率（D-078）。
- 學習目標屬於的單元（[§2-5](#2-5-出處)）有任何一個在範圍內就算；已暫停的不提高目標保持率。
- 同一個單元在幾份考試範圍裡，看最近的那次考試。日期都過了（清晨 4 點換日）就不再生效。

## 5. 複習紀錄

每台裝置每個月一個檔，每作答一次追加一行 JSON，不修改已寫入的紀錄（[D-035](decisions.md#d-035-複習紀錄格式)、[D-074](decisions.md#d-074-中斷與恢復)）。學生與家長不會碰到這些檔案。


| 欄位 | 內容 |
|---|---|
| `t` | 作答時間，含時區，到毫秒：同一台裝置的每一筆時間都不同，復原與合併 iCloud 衝突副本時才不會認錯 |
| `lt` | 學習目標 ID |
| `r` | 自評：`easy`／`good`／`near`／`miss`（太簡單／記住了／差一點／沒印象）；存代號不存數字，換算成 FSRS 等級由排程那一層負責（[D-062](decisions.md#d-062-自評四級與排程)） |
| `v` | 題目指紋（[§2-8](#2-8-題目指紋)） |
| `src` | 選填，來源。沒有就是一般複習；`mistake` 是採用錯題本時記的「沒記住」，沒有 `v`（D-061）；`check` 是考前抽測（D-075） |
| `undo` | 選填。值是被取消那一筆的 `t`；重算排程時跳過被取消的紀錄。復原上一張、回看時改評分（[D-084](decisions.md#d-084-回看上一張與滑動手勢)）都用它：先追加取消，再追加新的評分 |

- 檔名：`年-月 裝置名稱-隨機碼.jsonl`。每個檔案只有一台裝置在寫，iCloud 不會互相覆蓋。
- 不記作答秒數（[D-011](decisions.md#d-011-不計作答時間)）。
- 排程狀態由各裝置從全部紀錄計算，快取只存在本機；過去月份的檔案改變時，從那個月重算（D-079）。
- **題庫**（[D-090](decisions.md#d-090-題庫併入-cards變式題以題型排程)，v2）也寫同一種紀錄：每個題型有自己的學習目標 ID，`v` 是那一題變式題的指紋，格式不用改。

## 6. AI 輸出快照

每次呼叫 AI 產生草稿（製卡、錯題分析、補記憶錨點），外掛另存一份 AI 的原始輸出，用來比對家長刪改了什麼、改進製卡規則（D-042、D-093）。只寫不讀：排程、複習都不讀它；要拿掉，只要停止寫入、刪掉資料夾。

```markdown
---
日期: 2026-10-16
工作: 製卡
對象: "[[國二上自然 2-2 水溶液（卡片）]]"
規則版本: 通用 v0.7、自然 v0.3
材料:
  - "[[國二上自然 2-2 水溶液]]"
接法: API 直連
模型: GPT-5.6 Terra
---

（AI 交回的文字原樣保留，只多了外掛配的學習目標 ID）
```

- 「工作」是製卡、錯題分析或補記憶錨點；「對象」是這次產生的卡組或錯題本。教材只記連結，不存內容。
- 比對時：快照有、卡組沒有的是家長刪掉的；ID 相同、內容不同的是改過的；卡組有、快照沒有的是家長自己加的（D-042）。比對只看題目和答案，暫停不算修改（D-071）。
- 複製貼上模式要把結果貼進外掛的輸入框才會存快照；直接貼進卡組照樣能用，只是沒有快照。

## 7. 之後才定的格式

- **題庫筆記**（D-090，v2）：題目寫在題庫筆記，不混進卡組。辨認方式可以沿用轉錄稿的做法，用屬性區分，不必再加系統資料夾；複習紀錄不用改（[§5](#5-複習紀錄)）。
- **AI 往已啟用的卡組加內容**：加深（[D-077](decisions.md#d-077-循序漸進加深)）與補記憶錨點（[D-067](decisions.md#d-067-英文記憶錨點需要時才補)）也要先讓家長審核。💬 決定 D-077 要不要進 v1 時一起定；💡 可以沿用 §2-9 的引言框與「加入」，不需要新的語法。
- **心智圖**（[D-056](decisions.md#d-056-保留和心智圖外掛對接的彈性)）：用 `[[卡組#^ID]]` 連到學習目標，不需要新的語法。
