# Essence Cards｜產品定義

更新：2026-10-10｜狀態：架構釐清七步已完成；出題語法在寫程式前定稿（見[路線圖](roadmap.md#v1-開發前要做的事)）

這份文件回答「為什麼做、為誰做、做到什麼程度」。技術怎麼做見[架構](architecture.md)；每項決定的理由見[決策紀錄](decisions.md)。

狀態標示：✅ 已確認｜🔁 舊共識，待重新確認｜💬 待討論｜💡 助理提案

## 1. 北極星 ✅

> 透過程式讓知識從「獲取」到「深化」形成完美閉環，提高知識增長的效率，並幫助學生在學業表現上進步。

檢驗方式：任何功能都要能說明它如何縮短複習時間、加深記憶或提升學業表現；說明不了的不進入目前範圍（[D-001](decisions.md#d-001-北極星)）。

## 2. 成功標準 ✅（第 1 步）

2026-10-10 確認（[D-018](decisions.md#d-018-成功標準與驗證情境)）。

> 一位國中生用 Essence Cards 學習科目：每天複習 ≤ 15 分鐘，能做到「打開就複習」，考前抽測的記憶保持率 ≥ 85%，這一科的分數比上次進步。

- **定位是日常學習，不是考前衝刺**：學習深度提升，成績自然會進步；不針對某一次考試。
- **用兩科驗證兩種情境**：

| 科目 | 情境 | 學習方式 |
|---|---|---|
| 英文 | 記憶為主 | 單字閃卡；再補強記憶錨點，加深記憶 |
| 國二上自然 | 先理解，才能記憶 | 理解內容後，再透過題目鞏固 |

💡 量測方式建議：日常學習沒有固定的「考前」，記憶保持率可以直接從每天的複習紀錄計算（例如每週統計答對率），段考成績則看長期趨勢。具體方式在 v1 範圍確定時一起決定。

## 3. 使用者與情境 🔁（第 2 步）

目標使用者 ✅（[D-017](decisions.md#d-017-目標使用者)）：

- **Essence Cards**：以學生為主，國小與國中起步，希望陪學生一路用到大學考試。學業以外的知識也能用，例如攝影、醫學影片（[D-038](decisions.md#d-038-知識領域不限學業)）。
- **Essence Capture**：通用型使用者都能用，不限學生。

兩種角色 ✅（[D-019](decisions.md#d-019-使用角色與材料)）：

| 角色 | 裝置 | 做什麼 |
|---|---|---|
| 家長 | 電腦 | 製卡、審核 AI 產生的卡；原則上由家長製作，若 AI 能接手判斷學習目標並生成卡片更好 |
| 學生 | iPhone | 隨手複習 |

已知條件：

- 使用者曾自製 Obsidian 間隔重複閃卡外掛，新產品由此重構。✅
- 學生在零碎、會被打斷的時間複習：做幾張、離開、回來再繼續。✅（2026-10-09 使用者提出）

兩個驗證情境 ✅：

| 情境 | 材料 | 卡片內容 |
|---|---|---|
| 英文：記憶為主 | 課本單字 | 單字卡；**例句**（使用情境）與**發音**必備。字根字首、圖片、聯想、易混淆字等記憶錨點預留擴充，由 AI 生成 |
| 國二上自然：理解後記憶 | 課本 PDF、錯題 | 先理解再記憶的題目；錯題作為補強來源 |

其他已提出的情境：

| 情境 | 例子 | 來源 |
|---|---|---|
| 快速背誦 | 一課 30 個英文單字，明天要考 | 2026-10-09 使用者 |
| 段考範圍的理解與記憶 | 高中生物「動作電位」 | 2026-10-09 討論 |
| 跨年級螺旋加深 | 台灣史從國小到國中逐步加深 | 2026-10-09 使用者（願景） |
| 只整理來源 | 把 YouTube 或 PDF 轉成可讀筆記 | 舊共識 C-020（屬 Essence Capture） |
| 學業以外的知識 | 學生想學攝影；看了 YouTube 醫學影片，想幫助自己多吸收 | 2026-10-10 使用者（D-038） |

## 4. 產品原則 ✅（第 3 步）

2026-10-10 確認（[D-023](decisions.md#d-023-產品原則)）。任何功能提案都要通過這七條的檢驗：

| # | 原則 | 說明 |
|---|---|---|
| 1 | **提取與間隔重複是核心** | 學習靠「想出答案」，不靠重讀；功能取捨看每分鐘有效學習量 |
| 2 | **打開就能複習** | 不需要「開始讀書」的心理準備；做一張也算數，中斷不影響 |
| 3 | **好題目帶來理解** | 卡片是主要介面，但資料不鎖死在正反面；用為什麼、比較、應用題與由淺入深的題目，從背誦走向理解 |
| 4 | **少而精** | 每張卡都是未來的複習負擔，只為值得記住的內容出題 |
| 5 | **簡單在外、聰明在內** | 學生每張卡的操作越少越好，能自動記錄的就不問；複雜的判斷交給系統 |
| 6 | **AI 是加速器，不是必需品** | 沒有 AI 也能完整使用；AI 產生的卡要經家長審核 |
| 7 | **教材為依據，知識屬於使用者** | 以課本為準，AI 補充必須標明；資料存成可讀、可攜的 Markdown |

介面體驗是重點方向，值得投入時間打磨（[D-044](decisions.md#d-044-介面體驗是重點方向)）。

2026-10-09 的 12 條候選原則已併入上表；其中「檢核與排程分開、排程器可替換」屬於技術設計，見 [D-012](decisions.md#d-012-排程器可替換)。

品質目標 ✅：程式碼盡量簡潔；手機與電腦都要流暢（[D-015](decisions.md#d-015-品質目標)）。

## 5. 範圍 ✅（第 7 步）

2026-10-10 確認（[D-039](decisions.md#d-039-v1-範圍)）。

### v1：要做

一條最小閉環：筆記或 PDF → 卡組（手寫，或 AI 產生後審核）→ iPhone 複習 → 自評 → 排程 → 不會的卡可以跳回出處。

| 類別 | 功能 | 說明 | 依據 |
|---|---|---|---|
| 製卡 | 直接在 Obsidian 編輯卡組 | 在卡組筆記裡直接新增、修改卡片，外掛介面不是必經之路 | [D-036](decisions.md#d-036-直接在-obsidian-編輯卡組) |
| 製卡 | AI 製卡：複製貼上 | 外掛組好提示，貼到自己的 AI 對話並附上教材，再把結果貼回來；不需要 API 金鑰 | D-039 |
| 製卡 | AI 製卡：API 直連 | 外掛直接呼叫 AI；需要 API 金鑰，按用量付費 | D-039 |
| 製卡 | AI 卡片的審核 | 結果先存成草稿，學生看不到；在 Obsidian 修改、刪除後改成啟用。以刪除方便為優先，修改權限保留 | D-039、[D-042](decisions.md#d-042-ai-製卡快照) |
| 製卡 | AI 製卡快照 | 自動存一份 AI 原始輸出，之後可以比對家長刪改了什麼、改進製卡規則；家長不用做任何事 | [D-042](decisions.md#d-042-ai-製卡快照) |
| 製卡 | 錯題補強 | 走同一條 AI 製卡流程，換成錯題的製卡規則；不另做介面 | [D-019](decisions.md#d-019-使用角色與材料)、[D-027](decisions.md#d-027-跨課題目與重複出現的知識) |
| 製卡 | 不限學業的知識領域 | 攝影、醫學等領域的卡組不需要年級、科目、單元，用「一般知識」製卡規則 | [D-038](decisions.md#d-038-知識領域不限學業) |
| 製卡 | 編輯畫面標示結構 | 用樣式標出卡片與學習目標，縮排或格式錯誤一眼就看得出來 | [D-047](decisions.md#d-047-編輯畫面標示卡組結構) |
| 製卡 | 自由安排卡組位置 | 卡組放在 `Essence Cards/` 裡，怎麼分資料夾由使用者決定，可以隨時搬動；預設學業放 `學業/年級學期/科目/`；用 YAML 屬性與 Obsidian 標籤分類 | [D-040](decisions.md#d-040-卡組的位置)、[D-041](decisions.md#d-041-卡組的辨認與分類) |
| 複習 | 今天要複習 | iPhone 打開就出現今天的複習佇列；做一張也算數，中斷後接著做 | 原則 2 |
| 複習 | 翻面與三段自評 | 在腦中回答 → 翻面 → 忘記／模糊／記得 | [D-035](decisions.md#d-035-複習紀錄格式) |
| 複習 | 題目池輪替 | 基本題給前幾次複習，答對後輪流換進階題 | [D-028](decisions.md#d-028-題目池) |
| 複習 | 排程 | FSRS；之後可以依每個人的作答狀況調整，也可以替換演算法 | [D-043](decisions.md#d-043-排程採用-fsrs)、[D-012](decisions.md#d-012-排程器可替換) |
| 複習 | 範圍與每日上限 | 選考試範圍，優先出範圍內與最容易忘的卡；每日時間上限；整篇卡組可以暫停 | [D-026](decisions.md#d-026-儲存範圍排程分開) |
| 說明 | 使用說明書 | 完整的 HTML 說明書，特別說清楚學習目標 ID 與題目指紋 | [D-048](decisions.md#d-048-使用說明書) |
| 複習 | 跳回出處 | 不會的卡一鍵打開原筆記段落或 PDF 頁面 | [D-032](decisions.md#d-032-v1-的材料來源) |

### 之後：方向保留，暫不展開

- **增強版**（v1 之後）：英文發音朗讀，v1 的卡片仍保留發音欄位；記憶錨點的素材等。要加強什麼、用什麼做法，到時候再討論（[待討論的題目](backlog.md#增強版待討論)）
- 學習狀況儀表板：給學生與家長看的精美圖表，提升學習動機（[D-024](decisions.md#d-024-前端介面設計)）
- 外掛內的候選卡勾選介面：v1 先在卡組筆記裡審核
- 非卡片的呈現方式：圖文排序、圖片標示、心智圖
- 計算與應用題的練習形式：閃卡不適合（[架構 §7](architecture.md#7-製卡規則-)）
- Essence Capture：來源 → 可讀筆記（另一個 repo）；不提前
- AI 模型評測集（benchmark）
- FSRS 參數個人化：用學習者自己的複習紀錄調整（[D-043](decisions.md#d-043-排程採用-fsrs)）
- Concept 層、Learner Model、Target Selector、跨年級螺旋知識庫、AI 維護知識庫

詳細內容見[待決問題與點子](backlog.md)。

### 不做

- 作答計時（[D-011](decisions.md#d-011-不計作答時間)）
- 自建同步服務；同步沿用 iCloud（[D-004](decisions.md#d-004-第一版平台)）
- 修改來源筆記（[D-025](decisions.md#d-025-v1-資料實體)）
- 整合卡組（D-027）
- 帳號、伺服器：資料只存在使用者的 vault
- 一個 vault 多位學習者：一個 vault 對應一位學習者（D-038）
- 手機上的製卡介面：製卡在電腦（D-019）；手機仍可以用 Obsidian 直接改筆記
