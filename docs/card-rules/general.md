# 製卡規則｜一般知識預設 v0

> 狀態：💡 v0 草稿，尚未試用。適用於學業以外的知識領域，例如攝影、醫學與健康；搭配通用規則（common.md）使用，與通用規則衝突時，以本檔為準。通用規則裡的「學生」在這裡指學習者，可能是學生，也可能是成人。

## 你會收到

- 來源筆記：影片、文章或書的筆記，可能是自己寫的，也可能是工具整理的
- 學習者程度：年級，或「成人」
- （選填）學習目的，例如「想看懂健檢報告」、「想拍出更好的人像」
- （選填）學習者已有的卡片

## 和學業製卡不同的地方

| 通用規則 | 在一般知識中改為 |
|---|---|
| 以教材為依據 | 以**來源筆記**為依據；筆記沒寫的內容只能當 [AI 補充] |
| 用詞符合年級 | 用詞符合學習者程度；成人可以用專有名詞，但第一次出現時附一句解釋 |
| 優先考試常考的 | 優先**學習目的用得到的**、理解其他內容所必需的、容易混淆的；沒有學習目的時，優先來源強調的重點 |
| 每頁 3～6 個目標 | 一個來源原則上 **5～10 個**目標，可以調整 |
| 出處標頁碼 | 出處標**筆記的段落標題**；影片不標時間點 |

## 知識類型

| 類型 | 例子 | 出題方式 |
|---|---|---|
| 定義 | 什麼是光圈 | 「用自己的話說明……」；答案寫 2～3 個關鍵詞 |
| 因果與原理 | 為什麼睡眠不足會影響記憶 | 「為什麼……」、「如果……會怎樣？」 |
| 比較 | 光圈優先和快門優先 | 「A 和 B 有什麼不同？什麼時候用哪一個？」 |
| 步驟 | 逆光拍人像的步驟 | 「依序說出……」；只出關鍵步驟 |
| 判斷與應用 | 什麼情況該調高 ISO | 給一個情境，問該怎麼做、為什麼 |
| 數值與標準 | 成人血壓的正常範圍 | 只出來源明確寫出的數值，答案照來源寫 |

## 規則

1. **操作技能只出判斷與原理**：例如攝影，卡片可以問「逆光拍人像時，曝光補償要怎麼調？為什麼？」，但手感要靠實際練習；在「給學習者的備註」寫「建議實際練習：……」。
2. **健康與醫學內容**：只依來源出題，不加入來源沒有的建議或數值；AI 補充不能用在數值、劑量與醫療建議上。來源內容和一般認知明顯衝突時，不出題，寫在備註。
3. **意見不當成事實**：來源是個人經驗或看法時（例如某位創作者的建議），題目寫成「這部影片認為……」。

## 輸出格式

和通用規則相同。「出處」寫筆記的段落標題，例如「出處：睡眠的階段」；「類型」從上表選一個；最後的「給家長的備註」改為「給學習者的備註」。
