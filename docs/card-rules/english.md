## 1. 任務與學習地圖

為學生做國中英文的複習題：單字與片語、不規則變化、這一課的文法與詞序、容易混淆的字。閱讀、聽力、作文與口說不做卡（§11）。

學習順序（[D-123](../decisions.md#d-123-英文學習框架與先懂意思再練拼寫)）：

- **先懂中文意思、學會念，再練拼寫**：初期用英翻中建立意思與聲音的連結，不要求會拼字；英翻中記得了，軟體才開始出中翻英（D-069）。朗讀用系統語音，預設自動念（D-082、[D-186](../decisions.md#d-186-英文自動朗讀預設開)）；發音檢查列 v2 之後（D-124）。
- **會寫**是自己寫出單字或片語及需要的變化形；**會用**是換成沒背過的句子，仍能依情境選對字義、搭配與文法。背面有例句，不代表學生已經會用。
- **只學這一課需要的意思與用法**：一字多義隨教材與需要延伸，不在第一次遇到時展開全部字義。

**詞是根，句型是骨架**（使用者）：

- **詞**：一個詞（單字或片語）的一個意思是根。從它長出拼法、變化形、詞族、搭配、其他意思、容易混淆的詞。
- **句型**：一個文法點的一個用法是根，例如現在完成式的「從過去持續到現在」。名稱不寫課名，換一課、換一個年級都接著長。
- **聲音**不另立一條：英翻中的題目一出現就念，答完念例句，孩子每次複習都同時看拼法、聽發音。播過語音不算驗證了會念（D-124）。
- 兩條會交叉：enjoy 後面接 V-ing 是詞的用法，寫在詞那一邊（片語或記憶錨點）；它代表的規則（哪些動詞接 V-ing）寫在句型那一邊。

**詞的六個面向放在哪裡**（使用者列的面向）：

| 面向 | 成為目標（要考） | 寫在背面（記憶錨點，不考） |
|---|---|---|
| 會念 | 不另立，靠自動朗讀；系統驗收不了 | 拆音節（gi·raffe）、發音和拼法的對應（ph 念 f），寫在中翻英 |
| 會拼 | 中翻英，每個字都開（§3） | 同上 |
| 詞性、時態變化 | 不規則變化另立（§3）；課本正在教的詞類變化是文法目標（§5 A） | 詞族一行：`success（成功）→ successful（成功的）` |
| 同義、相反字 | 容易混淆的建比較（§5 C） | 學過的同義字、反義字一行 |
| 字根的橫向比較 | 第 ③ 層：用常見的字首字尾推敲沒學過的字 | 學過的同字根、同字首字尾的字一行（§7 的條件） |
| 語境的使用 | 同一池換句子，分三階（§6） | 常見搭配一行：`take a bus／take a photo` |

**分層**（[D-136](../decisions.md#d-136-學習地圖課本是起點加深可以超出課本)：課本是起點，加深可以超出課本）：

| 層 | 詞 | 句型 |
|---|---|---|
| ① 第一次製卡 | 單字表每個字與片語在這一課的意思與拼寫；教材正在教的不規則變化；這一課的混淆組 | 這一課的文法重點；詞序是難點的用排序 |
| ② 熟了加深 | 同一個意思換生活句、閱讀句；同一個字之後需要的其他意思（D-125）；常見搭配 | 換主詞、動詞與情境；和學過的文法對比（現在完成式和過去式） |
| ③ | 用常見的字首字尾推敲沒學過的字：說得出意思，也指得出是哪個字首或字尾 | 兩個文法用在同一句（被動語態加完成式） |
| 課外 | 2,000 字表以外、往高中的字；查得到依據的字源 | 高中才教的文法 |

- **層不是固定的難度階梯**：這一課正在教的，第一次製卡就做，例如這一課教間接問句，排序就在 ①。換句子是換材料，不代表升了一層。
- 課綱的字表（國中 1,200 字，在教育部 2,000 字參考詞彙表裡）與附錄六的國中文法句構表只是座標，不能拿來推定孩子學過哪些字或文法。

## 2. 你會收到

- 一課的單字表（單字與片語，可能附中文、詞性與變化形；可能另外列出只要認得的字，例如「認識字彙」）
- 這一課的文法重點：課本的文法說明、句型框；有習作時一起收到
- （選填）課文原句
- 學生的年級學期，例如 `國二上`
- 家長的勾選：點選填空，英文預設勾（[D-192](../decisions.md#d-192-比較點選改名點選填空英文預設也勾)）
- 這一課的字在學生已有的目標裡的：學習目標的名稱、ID 與英翻中那一題的答案（D-125），用來加題與去重
- 孩子已有的英文單字：整份清單，只有字，兩個方向只列一次。只用來挑記憶錨點的連結（§7），不用來判斷加題
- 孩子已有的英文文法、排序、比較目標：名稱、ID、第一題（§5 D）
- 或錯題：照 §10
- 或常錯單字要補記憶錨點：照 §7 最後

最後兩項清單軟體還沒做，試用時手動給，沒有就寫「無」。

## 3. 單字與片語的目標（單字篇）

**方向不同的能力是不同的學習目標**，各自排程。名稱寫「單字 方向」或「單字 變化種類」，軟體從名稱判斷（D-082）：

| 學習目標 | 名稱 | 誰有 | 題目 | 作答 |
|---|---|---|---|---|
| 英翻中：看到英文想起意思 | `borrow 英翻中` | 單字表的每個字與片語，每個要學的意思 | 單字本身（§4 A） | 翻面自評 |
| 中翻英：依題意寫出單字或片語及需要的變化形 | `borrow 中翻英` | 同上，認識字彙除外 | 例句挖空（§4 B、C） | 打字 |
| 不規則變化：寫出不規則的變化形 | `go 過去式` | 教材正在教那個變化，或這一課明列 | 例句挖空（§4 D） | 打字 |

- **每個字都開中翻英**（使用者：每個字都要會拼）；家長不要的，審草稿時刪掉。軟體等英翻中記得了才出中翻英（D-069），兩個方向不會第一天一起出。
- 本預設的知識類型是**詞彙**，片語視為一個單字；名稱已經說明是哪一種，「類型」不用寫。
- **一開始每個方向只出一題**（有會變部分的片語，中翻英例外，見 §4 C）。換不同例句的進階題，等這個字在後面的課再出現時再加，或用「加深」產生（通用規則 F、§6）。
- **認識字彙**（教材標成只要看得懂的字，例如講義的「認識字彙」框）：只出英翻中，不出中翻英（使用者 2026-11-05）。

**已學過的單字再次出現**：先比對中文意思，不只看拼字。

- **意思和收到的英翻中答案相同**：不建立新目標，用這一課的課文句子出一題進階題（已有的字出現在這一課任何地方都算：單字表、課文、閱讀、解析，通用規則 17），寫在通用規則的「加進已有的學習目標」：
  - 英翻中：把句子裡的這個字標粗體，問意思，例如 `She often **borrows** books from the library. :: 借入、向別人借`。
  - 中翻英：照 §4 B 或 C。
- **意思不同**：例如已有 `light 英翻中 :: n. 光`，這一課是 `This bag is light.`（輕的）。不要加進舊目標，否則學生熟了「光」，「輕的」也被當成熟了。建立新目標，名稱在字後面加全形括號的中文意思：

```
- light（輕的） 英翻中
    - light :: adj. 輕的
        - 例句：This bag is light. 這個包包很輕。
```

- 只是換一個搭配、意思沒變（take a bus 之後的 take a taxi）算意思相同；本身是不同片語的（take a photo）照一般片語建目標，名稱已經不同，不用括號。
- **同一課就教兩個意思**（bank：銀行；河岸）：中文意思不同、英文的用法也不同才分開，每個意思一組目標；同一個概念的兩種中文（corner 轉角；角落、ask 請求；詢問、straight 直直地；直的）是一個目標，答案寫兩個中文。分開時，單字表先列的照一般名稱，第二個起加括號（`bank（河岸） 英翻中`）。學生已有其中一個意思時，先照上面比對。
- **教材標成第二義的片語或複合名詞**（bus stop、go shopping；第二義其實是 stop、shop 的）：名稱已經和單字不同，不加括號；組成的字原本的意思可以寫進記憶錨點（`stop（停止）：公車停的地方`）。
- **教材標成第二義的單字**（take 搭乘、play 戲劇）：照「意思不同」加括號寫這一課的意思，前面的課沒給你也一樣（`play（戲劇） 英翻中`）。答案只寫、只考第二義；單字表連舊意思一起列時（fly：飛行；駕駛）也一樣，寫 `fly（駕駛）`。

**不規則變化**（D-193 第 5 點）：

- **名稱結尾寫變化種類**：過去式、過去分詞、複數、比較級、最高級，例如 `go 過去式`、`go 過去分詞`、`child 複數`、`good 比較級`。同一個字有好幾個意思時，照上面在括號寫意思：`lie（躺） 過去式` 的答案是 lay；說謊的 lie 過去式是規則的 lied，不另立。每個意思的變化都一樣時不加括號：fly 的飛行、駕駛都是 flew，寫 `fly 過去式`。一個變化一個目標：go → went、go → gone 各一個。
- **什麼時候建**：教材正在教那個變化（例如這一課教過去式），或這一課明列時。講義在字旁邊註明的一行（「過去式為 flew」「複數形為 feet」）也算明列，那個字不在單字表上也建（使用者 2026-11-05）；只在練習題用到、教材沒列的變化不建。課本附錄的整張不規則動詞表只建這一課用到的，不每課重建。
- **不另立的**：規則變化（played、studied），它是文法那邊的規則（§5 A）；拼法沒變的（cut → cut、put → put）。
- **已有同一個字、同一個意思、同一個變化的目標**：加題，不另建。
- **單字的中翻英池只放原形**：went 不出在 `go 中翻英`。片語的變化照舊放在片語的池裡（§4 C）。
- **開始**：同一篇有同一個字、同一個意思的英翻中時（名稱沒有括號的變化目標，這個字任一個意思都算），軟體等它記得了才出；沒有就照常出，所以從國二才開始用的孩子不會卡住。

**詞性變化**（D-193 第 7 點）：

- 單字表上的衍生字（success、successful 都在表上）照一般的字建英翻中、中翻英。
- 課本正在教的構造（例如修飾名詞時用形容詞）建文法目標（§5 A），括號給原形，換詞族與情境：`He is a ＿＿ (success) writer. :: successful`。
- 課本沒教的整個詞族只寫在記憶錨點（§7），不自動展開。

## 4. 單字與片語的題目

### A. 英翻中

1. **題目是單字或片語本身**；答案寫「詞性＋這一課的中文」，例如 `v. 借入、向別人借`。只寫這一課用到的意思；其他意思不寫，也不出題。
2. **例句（必備）**：寫在英翻中那一題底下，以「例句：」開頭，附中文翻譯。
   - 有課文原句就優先使用；講義字彙解析的例句也算，不受下面 12 個字的限制。
   - 自己造句時：12 個字以內，只用國中程度的單字，情境貼近學生生活，展現這個字最常見的用法。
3. **不寫發音**：不寫「發音」那一行，也不寫 KK 音標。軟體用裝置的系統語音直接念題目與答案裡的英文（D-082）。

### B. 單字的中翻英：用例句問

- 不要只給中文。只給中文常常對應好幾個英文字，例如「大的」可能是 big、large 或 huge。
- 用例句挖空，括號附這一課的中文意思：`Can I ＿＿ your pen?（借） :: borrow`。例句也讓學生練到這個字的用法，更接近考試的填空題。有課文原句就優先使用。**和英翻中的例句用不同的句子**，中翻英才不是背整句；課文只有一句時，另一個方向自己造句。
- 例句加中文還是有好幾個答案時，再給字首：`The elephant is very ＿＿.（大的）` 填 big、large、huge 都通，要改成 `The elephant is very h＿＿.（巨大的）`。字首是最後一步：先換句子或改中文提示，換不掉才給；給了字首，題目就變簡單。
- 有常見的同義字、字首也一樣時（不限單字表：around／about、bike／bicycle、motorcycle／motorbike），字首分不開，在括號寫排除的提示：`There are ＿＿ 500 students here.（大約，about 以外的說法） :: around`。
- **複合名詞**（fire station、post office、bus stop）照單字寫：例句挖空、括號附中文，答案兩個字；片語的「中文整句」寫法只用在 §4 C 的片語。
- **學生要打字**，軟體比對拼字（D-066）：答案只能是一個單字，不要出需要打整句的題目。單字一題只能有一個正確答案：有兩種拼法的字（color／colour）在括號附提示，例如「（顏色，美式拼法）」，或不出這一題。

### C. 片語的中翻英：放進句子裡打

片語是一個學習目標，名稱寫原形，例如 `make up one's mind 中翻英`。題目用「中文整句＋英文句子挖空」，學生打出空格裡的整個片語，包括變化形（D-122）：

- **基本題**用最接近原形的句子（動詞在 to、will、can 後面，或一般現在式）；one's、oneself 換成跟主詞一致的字。
- **片語裡有會變的部分**（動詞時態、one's、oneself）時，一開始就再出 1～2 題進階題，換主詞或時態，例如過去式、第三人稱單數。整個題目池測同一件事：**能依主詞與時態寫出這個片語**。
  - 沒有會變的部分（例如 in front of、be late for）只出基本題；變了跟原形一樣的（put → put）不算一題變化。
  - **只用學生學過的文法**：依年級與這一課的課文判斷；拿不準時只換主詞，或用現在式、過去式。例如國一還沒學現在完成式，不要出 `He has already ＿＿.`，否則答錯時分不出是片語不會還是文法不會。
  - 這個片語幾乎只用在一種句型時（例如 hurry up 多半是祈使句），或用學過的文法出不了自然的句子時，只出基本題，不要硬造。
- **只有一個答案**：
  - 英文句子一定要有決定時態的字（yesterday、every day、already、now、tomorrow），不能只靠中文。反例：`She ＿＿ the light before leaving.` 填 turns off、turned off 都通。有時間詞也還不夠：出完題後，連同主詞與助動詞試填其他時態、代名詞與受詞位置，例如 `Tomorrow she ＿＿ the light.` 填 will turn off、is going to turn off 都通，要把 will 寫在空格外。
  - 助動詞與 be 動詞寫在空格外，空格只放片語本身；be 開頭的片語也一樣：`She was ＿＿ school yesterday. :: late for`。
  - 中間可以放受詞的片語（turn off、cheer up），名詞受詞寫在空格外：`The teacher ＿＿ the boy yesterday. :: cheered up`；寫在空格裡（cheered the boy up）時，cheered up the boy 也對。代名詞受詞只能放中間：`The song ＿＿. :: cheered me up`。
  - 片語裡的 someone 用代名詞（me、him），something 寫在空格外：`She ＿＿ my homework yesterday. :: helped me with`。寫成名詞就有好幾種寫法，例如 helps her brother with、helps her little brother with。
  - 同一課有意思一樣的片語（take care of／look after），字數不同時軟體畫的線分得開；字數一樣時，換一個只有這個片語通的句子。
- **空格只寫一個 `＿＿`**，不寫原形、字數或括號提示：軟體依答案的字數畫線；答錯時軟體才用名稱裡的原形當提示（D-121）。
- **兩種說法都對**時，答案全部列出，用 ` | ` 分開，課本用的寫在最前面；每一種的字數要一樣，不一樣就換句子。這一題底下寫「詳解：」說明兩種說法。意思對、但沒有用到這個片語的說法（例如用 decided 代替 made up his mind）不列進答案。（通用規則的答案是一個；這是本檔的例外。）

```
- make up one's mind 中翻英
    - 你今天就得下定決心。You have to ＿＿ today. :: make up your mind
    - 他已經下定決心要出國讀書。He has already ＿＿ to study abroad. :: made up his mind | made his mind up
        - 詳解：made up his mind 和 made his mind up 都對，課本用前者
```


### D. 不規則變化

- **用例句挖空，括號附中文意思**，同 B：`Yesterday I ＿＿ to school.（去） :: went`、`There are three ＿＿ in the park.（小孩） :: children`、`I have already ＿＿ my homework.（做） :: done`。
- **句子要有決定形式的字**（yesterday、already、three、than），助動詞與 have 寫在空格外，空格只放變化形。試填原形與其他變化形，只有一個答案。
- 答錯時軟體用名稱裡的原形當第 2 步的提示（go；有括號的去掉括號，D-121）。
- 一開始只出一題，同 §3。

### E. 動詞變化（翻卡後看）

使用者 2026-11-05：中翻英的字是動詞時，翻卡後要看得到它的變化。

- 這一課的意思是動詞（詞性有 v.）或動詞片語的**中翻英**目標，以及**不規則變化**目標，在目標底下（不是題目底下）寫一行 `動詞變化：`，照原形、過去式、過去分詞的順序，用 ` - ` 隔開：`動詞變化：fly - flew - flown`、`動詞變化：give up - gave up - given up`。規則變化也寫：`動詞變化：borrow - borrowed - borrowed`。四個字以上的片語只寫動詞：get butterflies in one's stomach 寫 `動詞變化：get - got - got／gotten`。
- 過去分詞有兩種的都寫，用「／」分開：`動詞變化：get off - got off - got off／gotten off`。
- 這一行是背面補充：這個目標的每一題翻卡後都會顯示，題目上看不到（[syntax §2-4](../syntax.md#2-4-資料欄位)）；不算記憶錨點的兩行。英翻中不寫。
- 同一個字有名詞和動詞兩種詞性（hope v. n.）時照寫；只是名詞或形容詞的不寫。

## 5. 文法、排序與比較（文法篇）

### A. 文法

- **第一次製卡就做這一課的文法重點**（不再只用在錯題補強）。一個文法點的一個用法一個目標：現在完成式的「從過去持續到現在」和「經驗」判準不同，分開；同一個用法換句子是同一池。
- **名稱 `文法點（用法） 文法`**：文法點優先用課綱附錄六（國中文法句構表）的說法，用法寫簡短的中文，例如 `現在完成式（從過去持續到現在） 文法`、`被動語態（現在式） 文法`、`比較級（兩者比較） 文法`。名稱不寫課名。
- **判準是「在這種情境用對、寫對」**：題目不寫文法名稱，由句子的情境決定用哪個文法。
- **題目**：英文句子挖空，括號只給原形，空格只放這個文法要寫的部分，答案 1～4 個字。不附中文：意思由括號的原形給，中文常常直接說出要用哪個文法（被、已經）。

  ```
  - 現在完成式（從過去持續到現在） 文法
      - I ＿＿ Tom since I was six. (know) :: have known | 've known
      - She ＿＿ a cat since last year. (have) :: has had | 's had
  ```

- **只用學過的單字與文法**：錯在不認得的字，就分不出是哪裡不會（同 D-125 的變化題）。
- **答案和括號的字一樣的題目不出**（`went ＿＿ climbing. (mountain) :: mountain`、`goes to school ＿＿. (by / bus) :: by bus`）：只測「不要加 a、the、s」等於照抄，寫進記憶錨點。和單字的中翻英測同一件事時（by＋交通工具和 `by（搭乘） 中翻英`）也不另建文法目標（通用規則 2）。
- **功能字沒有原形可以給**（疑問詞 how）：不寫括號，由答句決定答案：`A: ＿＿ did you come here? B: By metro. :: How`。
- **整句改寫、合併句子、翻譯不做卡**：答案太長、對的說法太多。
- **文法重點以教材的文法單元為準**（例如講義的文法句型篇）；課文、閱讀裡的補充說明（不定詞當補語、be busy＋V-ing）放候選卡片。
- **介系詞與搭配的動詞**：打字題常有好幾個說得通（Go straight for／about two blocks、turn left on／onto、on／to your left；catch／get a taxi、美式的 ride the metro）。試填後還是多解，而教材有對照時，改成 §5 C 的比較，讓選項限住答案。
- **只有一個答案**：片語的反例（§4 C）一樣要做，文法還多了這六種：

| 多解的來源 | 要試的反例 | 改法 |
|---|---|---|
| 縮寫 | 否定的 `hasn't gone`／`has not gone` 都對、字數不同；主詞在空格外時，`have known` 也可以寫成 `'ve known` | 否定詞寫在空格外，或改用肯定句；主詞後面能縮寫的，答案也列縮寫（`have known \| 've known`）。不能漏收縮寫、把它判錯 |
| 時態、時貌 | `since 2020` 不一定排除 `has been living`；`tomorrow` 排除不了 `will`／`be going to` | 測持續用狀態動詞（know、have、be）；把 will 寫在空格外；還是多解就換題 |
| 主動、被動與狀態 | 沒有清楚的施事、受事時兩種都通；`is closed` 也可能是在說狀態 | 讓句子裡誰做、誰被做清楚 |
| 助動詞與語氣 | 請求的句子 `can`／`may`／`could` 都自然 | 不測的部分寫在空格外；不能唯一判定就不出這一題 |
| 換字、英美用法 | 換同義的動詞也通，或課本以外另有標準寫法 | 括號的原形限定用哪個字；其他照 §4 C 避開或列出 |
| to V 與 V-ing 都對 | like、love、hate、start 後面；當主詞時（`＿＿ movies is fun.` 寫 Watching、To watch 都對） | 字數不同，軟體畫的線分得開（D-122）：答案只寫題目要的那一種，題目底下寫「詳解：」說兩種都可以、這題畫幾條線（使用者 2026-11-05）。字數一樣分不開時換題 |

- **兩種說法都對時**照 §4 C 用 ` | ` 列出，只收同一用法、字數相同的說法；字數不同就改題，把造成差別的部分寫在空格外（to V 與 V-ing 例外，照上表）：

  ```
  - 動名詞（當主詞） 文法
      - ＿＿ movies is fun. (watch) :: Watching
          - 詳解：用不定詞當主詞也對（To watch movies is fun.）；這題只畫一條線，所以寫 V-ing
  ```

- 答錯時，軟體用名稱裡的文法點（括號前面那段，例如「現在完成式」）當第 2 步的提示；題目已經給了同一個文法點的，第 2 步跳過（D-121）。
- **已經有的舊寫法**：錯題補強建過的文法目標（名稱「能在……時用……」、`類型：文法句型`），照 §5 D 用 ID 認，加題時用原名，不改名。

### B. 排序

- **詞序本身是難點的文法**建排序目標：間接問句、疑問句的詞序、頻率副詞的位置、代名詞放在可分片語中間（turn it off）。名稱的文法點照 A，結尾寫「排序」：`間接問句 排序`。
- **用點選填空排**（[D-192](../decisions.md#d-192-比較點選改名點選填空英文預設也勾)）：句中要排的每一塊挖成一格，孩子照順序把詞塊點進空格。一個目標好幾格，取最差的一格（[D-187](../decisions.md#d-187-全詩順序卡一首一張放在這首最後)）。
- **題目是中文整句加英文句子**：

  ```
  - 間接問句 排序
      - 我不知道他住在哪裡。I don't know ==where== ==he== ==lives==.
      - 你知道公車站在哪裡嗎？Do you know ==where== ==the bus stop== ==is==?
      - 請告訴我你為什麼遲到。Please tell me ==why== ==you== ==were== ==late==.
  ```

- **詞塊怎麼切**：只挖句中詞序是難點的那一段，其他留在空格外。不測的名詞片語包成一塊（the bus stop）；要排的關鍵字分開，不能包在同一塊（he lives 包成一塊就把答案給了）。
- **大寫與標點不洩漏**：句首與句尾留在空格外，`==` 不包句尾的標點。真的要挖句首時，只去掉因為放在句首才有的大寫；I、人名、縮寫的撇號照原樣。
- **一句只有一種排法**：試排其他位置，能移動也通的（often、時間與地點副詞）留在空格外，或換句子。
- **文字相同的詞塊**可以出現兩次（兩個 the），互換不算錯，軟體判。
- **每個目標先 3 句**，主詞、動詞或情境不同，不只換一個人名；和 A 的打字題不用同一句。
- 家長取消點選填空的勾選時，不出排序（D-187 第 8 點）。

### C. 比較（容易混淆的字）

- **第一次製卡就建**（使用者：老師最愛考，要讓學生搞懂，不是不出）：這一課有字或用法正在學，而且說得出這一課容易錯在哪的混淆組，同一課一起出現也一樣。來源：教材有對照的；國中常考的，例如 borrow／lend、say／tell、since／for、interesting／interested；錯題顯示孩子會搞混的。和這一課無關、程度超出的組不建。
- **教材沒列、AI 補的組**：在給家長的備註一組寫一行理由，例如「borrow／lend：國中常考，這一課學 borrow」（通用規則的給家長的備註多這一種）。
- **名稱**照[規畫](../plans/similar-chars.md#卡組怎麼寫)：組裡每個字一個目標，`borrow（borrow、lend） 比較`、`lend（borrow、lend） 比較`，括號裡是整組，用頓號隔開。組裡的字不在這一課的也一樣建。一個字在兩組（say 和 tell、say 和 speak），各一個目標。介系詞的組用整個片語當名稱：`on the corner（on the corner、in the corner） 比較`；只寫介系詞（`on（on、at、in） 比較`）會和別課時間用法的同一組撞名。since 的組只用時間的用法，「因為」的意思不放進同一池。
- **題目**：英文句子挖空，答案就是組裡的那個字。空格的位置要用組裡的原樣（例如放在 can、to 後面），不出要變化形的句子。中文翻譯會直接分出答案時不附（「借」兩個方向都用，可以附）。
- **每個字至少兩句；只有兩個字的組，每個字至少三句**（[D-182](../decisions.md#d-182-比較點選各科都能用家長出題時勾選)）。試填組裡的每個字，有兩個說得通就改句子；答案的字不能出現在題目裡；不能只靠句子裡重複出現的字猜答案。
- **每個字都寫分辨的線索**，放在自己目標底下的記憶錨點，同一組用同一個句型，線索要具體：搭配（**borrow** A **from** B／**lend** A **to** B）、方向（從別人那裡借進來／借出去給別人）、字形（careful／careless 差在 -ful、-less）、詞尾（interest**ing** 讓人覺得有趣／interest**ed** 人自己覺得有趣）。
- **試了還是找不到**每個字都只有一個說得通的句子時（Excuse me／I'm sorry：英式英文的 Sorry 也用來叫人），不建這一組，把分辨寫在記憶錨點：`易混淆 I'm sorry（對不起：做錯事道歉）`。
- **不設門檻**：不用等組裡每個字的英翻中都記得了才出。輸出時單字篇在前。
- 家長取消點選填空的勾選時，比較照通用規則的比較目標寫成一般的問答題，名稱不加括號的組（程式從括號認點選填空，D-182 第 4 點）。

### D. 和學生已有的目標比對

- **怎麼比**：文法、排序看文法點、用法與判準，比較看整組與比的是哪一個用法，不只看名稱。名稱相近只是先挑出候選，例如「現在完成式（持續）」和「現在完成式（從過去持續到現在）」可能是同一個。只看第一題判斷不了時，寫待核對，不合併，也不另建。
- **相同**：用原 ID、原名稱（照抄，包括結尾的「文法」）加一題這一課的句子，寫在「加進已有的學習目標」；一個目標加一題。教材任何地方用到已有的文法都算，例如解析裡的 by＋V-ing 是已有的「動名詞（當介系詞的受詞）」，練習題的 enjoy going 是「動名詞（當動詞的受詞）」。
- **不同**：另立目標；名稱的用法寫清楚差在哪。
- **比較的組多了一個字**：新字新建目標，括號寫完整的組，已有的目標不動。

## 6. 語境分三階

同一個意思、同一個文法用法換一句話，還是同一個目標，所以三階是**同一池一題一題加上去**（同國語，[D-175](../decisions.md#d-175-國小國語的學習地圖字是根生字拆成字形字義讀音) 第 4 點）：

1. **初階**：第一次製卡，用課本的句子；沒有才由 AI 照 §4 A 造句。
2. **第二階**：熟了以後加深時，加生活裡常用的句子。
3. **第三階**：再熟，加閱讀文章裡常見的句子（使用者：會考與段考的閱讀，常是沒看過的文章）。

- 英翻中的例句、中翻英與變化形的挖空、文法的填空、排序與比較都一樣。
- 第二、三階的句子由 AI 照年級寫，只用學過的單字與文法；語境只說得通要考的那個意思，題目沒有直接給答案。

## 7. 記憶錨點（AI 預設加，只寫有連結的）

AI 製卡時就加（修改 D-067 的「預設不加」），但**只寫有連結的**；沒有就不寫，不湊。錨點和卡片一樣先存草稿，家長審核後才採用。

- **有連結的**：和學過的字的連結（詞族、同義、反義、同字根），一看就懂的字形線索（-ful、-less、un-），常見搭配。
- **「學過的字」分三層**（使用者同意）：
  1. 孩子已有的英文單字清單裡有的（§2）。
  2. 清單沒有的，照年級推定：國小與前面年級的基本字算學過。
  3. 錨點裡提到的字一律附中文：`反義：lend（借出）`。推定錯了，孩子也讀得懂；少見、這個年級還沒學的字不提。
  這是推定，不代表孩子記得；有卡也不等於記得。
- **每個方向最多兩行**，算採用後的總數：之後按「補記憶錨點」補的也算在內，已經兩行就換掉一行，在草稿列出換了什麼。比較目標的分辨線索照 §5 C。
- 寫在學習目標底下（不是題目底下），以「記憶錨點：」開頭，一個錨點一行。這個方向的每一題都會顯示，另一個方向不會（D-082）。
- **哪個方向寫什麼**（D-067）：英翻中寫幫忙想起意思的；中翻英寫幫忙寫出來的。

| 錨點 | 例子 | 注意 |
|---|---|---|
| 字首、字尾 | un- + happy → unhappy | 只寫常見、一看就懂的字首字尾，例如 un-、re-、-ful、-less |
| 字根 | tele-（遠）：telephone（電話）、television（電視） | 至少兩個連得到的字，而且查得到構詞或字源的依據；辭典收了這個字、字母相同，都不等於字根相同。查證寫在 AI 輸出快照，不寫在卡上；查不到就只寫常見的字首字尾，不編故事 |
| 詞族 | success（成功）→ successful（成功的）→ successfully（成功地） | 課本沒教的詞族只寫在這裡，不另建目標 |
| 同義、反義 | 反義：lend（借出） | 學過的字；容易混淆的另建比較（§5 C） |
| 常見搭配 | take a photo | 國中程度常用的 |
| 拆音節、發音和拼法 | gi·raffe；ph 念 f | 寫在中翻英 |
| 聯想 | 諧音或畫面 | 只用在難記的字；標 [聯想]，需家長確認是否合適；不能取代發音，諧音可能讓發音學錯；中翻英不用諧音 |
| 圖片 | 具體名詞加一個 emoji，例如 giraffe 🦒 | 沒有貼切的 emoji 就不加；真正的圖片在增強版 |

不確定的錨點不要寫。

**常錯單字的錨點**：家長從入口「給家長」一區按「補記憶錨點」時，你會收到每個字的學習目標（名稱、ID、題目與已有的錨點）、常錯的方向，以及「差一點」與「沒印象」各幾次（D-067、D-103）。

1. 依常錯的方向選錨點，只加在那個方向的學習目標：

| 常錯的方向 | 卡在哪裡 | 適合的錨點 |
|---|---|---|
| 英翻中：看到字想不起意思 | 字的樣子連不到意思 | 聯想、emoji、字首字尾、例句情境 |
| 中翻英：想不起字或寫不出來 | 意思連不到字的樣子、字母順序 | 拆音節（gi·raffe）、發音和拼法的對應（ph 念 f）、常見搭配、易混淆字；不用諧音聯想 |

2. 「差一點」多：記憶在，但想不起來，或和別的字搞混，優先用提示類的錨點，例如易混淆字、常見搭配。「沒印象」多：可能根本沒記進去，優先用幫助記住的錨點，例如聯想、emoji、拆音節。
3. 每個方向最多兩行，算上已有的；上面表格的注意事項照樣適用。
4. 輸出寫成通用規則的「加進已有的學習目標」：每一項是那個方向的學習目標 ID 和名稱，底下是要加的「記憶錨點：」行；要換掉的已有錨點寫在給家長的備註。

## 8. 分篇與輸出格式（取代通用規則的學習目標寫法；其他照通用規則）

一課分成兩篇，有內容才建（[D-190](../decisions.md#d-190-英文單字自成一篇分篇後加深回到原篇)）。屬性相同（同一個單元），目錄合成一課。每一篇都先寫檔名再寫本文：

| 篇 | 檔名 | 放什麼 | 小標題 |
|---|---|---|---|
| 單字 | `國二上英文 L3 單字` | 英翻中、中翻英、不規則變化 | 不用 |
| 文法 | `國二上英文 L3 文法` | 文法、排序、比較 | `### 文法`、`### 排序`、`### 比較`，沒有的省略 |

```
國二上英文 L3 單字

- borrow 英翻中
    - borrow :: v. 借入、向別人借
        - 例句：Can I borrow your pen? 我可以借你的筆嗎？
- borrow 中翻英
    - Can I ＿＿ your pen?（借） :: borrow
    - 記憶錨點：易混淆 lend（借出：把東西借給別人）
    - 動詞變化：borrow - borrowed - borrowed
- go 過去式
    - Yesterday I ＿＿ to school.（去） :: went
    - 動詞變化：go - went - gone
- uniform 英翻中
    - uniform :: n. 制服
        - 例句：We wear uniforms to school. 我們穿制服上學。
- uniform 中翻英
    - We have to wear a school ＿＿.（制服） :: uniform

國二上英文 L3 文法

### 文法
- 現在完成式（從過去持續到現在） 文法
    - I ＿＿ Tom since I was six. (know) :: have known | 've known
    - She ＿＿ a cat since last year. (have) :: has had | 's had
### 排序
- 間接問句 排序
    - 我不知道他住在哪裡。I don't know ==where== ==he== ==lives==.
    - 你知道公車站在哪裡嗎？Do you know ==where== ==the bus stop== ==is==?
    - 請告訴我你為什麼遲到。Please tell me ==why== ==you== ==were== ==late==.
### 比較
- borrow（borrow、lend） 比較
    - Can I ＿＿ your pen? :: borrow
    - You can ＿＿ books from the library. :: borrow
    - May I ＿＿ your bike this afternoon? :: borrow
    - 記憶錨點：**borrow** A **from** B：從別人那裡借進來
- lend（borrow、lend） 比較
    - Could you ＿＿ me your pen? :: lend
    - My brother will ＿＿ his bike to me. :: lend
    - Please ＿＿ me some money. :: lend
    - 記憶錨點：**lend** A **to** B：借出去給別人
```

- 單字篇照單字表的順序；單字表沒有小標題時不用分組。同一個字的目標寫在一起：英翻中、中翻英、變化形。
- 出處、類型不用寫（出處沒寫就是這一課）；重要性需要時才寫。
- **加進已有的學習目標**：寫在同一類那一篇的最後，軟體照 ID 寫回目標所在的篇，不因名稱結尾搬家（D-190 第 3 點）。
- **加深**：單字篇只加深詞彙（英翻中、中翻英、變化形）；文法篇只加深文法、排序、比較。需要另一類的目標時不在這一篇建，在給家長的備註寫一行，家長從另一篇再發起（D-190 第 3、4 點）。
- 給家長的備註、候選卡片照通用規則；備註多兩種事：AI 補的比較組（§5 C）、加深需要另一篇的目標。

## 9. 和舊版的差別

- 中翻英原本預設關、家長逐字開，現在每個字都開；記憶錨點原本家長開啟才加，現在 AI 預設加、只寫有連結的。所以 §2 不再有家長開啟這兩項的選項。
- 文法原本只用在錯題補強，現在第一次製卡就做，名稱改成 `文法點（用法） 文法`；舊的「能在……時用……」目標照 ID 沿用（§5 A）。
- 易混淆字原本只對之前學過的字、同一課的不加，現在這一課需要的第一次就建比較（§5 C）。
- v0.13：動詞的中翻英翻卡後多一行動詞變化（§4 E）；認識字彙只出英翻中（§3）。

## 10. 錯題處理（補充通用規則）

錯因、對應學習目標與輸出格式照通用規則。英文常見的情況：

| 情況 | 錯因 | 補強 |
|---|---|---|
| 拼錯字（borow），已有這個字的中翻英目標 | 忘記 | 提前複習 |
| 拼錯字，還沒有中翻英目標 | 不會應用；對應寫「卡片沒涵蓋」 | 建立這個字的中翻英目標，名稱 `單字 中翻英`，題目照 §4 B；出處寫這個字所在的課，例如 `出處：國一上 L1`，才會和英翻中放在同一篇、配成一組（D-069） |
| 拼錯不規則變化（wnet），或把規則用在不規則的字上（goed） | 已有 `go 過去式`：忘記；沒有：不會應用 | 已有就提前複習；沒有就建立 `go 過去式`，題目照 §4 D，放單字篇 |
| 意思混淆，例如 borrow／lend；詞性混淆，例如 interesting／interested | 觀念混淆 | 已有這一組的比較目標就加題；沒有就照 §5 C 建這一組，放文法篇 |
| 該用變化形卻寫原形或用錯時態，例如該寫 went 寫成 go | 不會應用 | 已有這個文法的目標就加題；沒有就照 §5 A 建 `過去式（說過去發生的事） 文法` |
| 其他文法錯，例如介系詞、比較級 | 不會應用 | 同上，照 §5 A |
| 詞序錯，例如間接問句寫成 where does he live | 不會應用 | 已有排序目標就加題；沒有就照 §5 B 建 |
| 閱讀理解、聽力、作文 | 不做卡 | 把文章裡學生不認識、而且值得學的單字做成英翻中目標，最多 3 個；不寫「建議另外練習」（§11） |

## 11. 不做的

- **不做卡，也不寫「建議另外練習」**（使用者）：閱讀測驗、聽力測驗、作文、口說、整句翻譯與造句。閃卡做不好的不做。
- KK 音標、發音的文字說明（D-082）。
- 聽音辨義卡（只播聲音、想意思）：會考的聽力用得上，但是新題型，先畫在地圖上，不放 v1。

## 12. 輸出前自我檢查

- [ ] 一課分成單字、文法兩篇，有內容才建；每篇先寫檔名，檔名照 `國二上英文 L3 單字`
- [ ] 單字表每個字與片語都有英翻中、中翻英（認識字彙只有英翻中）；每個目標對應這一課要學的意思；再次出現的字，意思相同才加進舊目標，意思不同就用括號名稱建新目標
- [ ] 英翻中每一題都有例句與中文翻譯；沒有發音行與 KK 音標
- [ ] 單字的中翻英是例句挖空加中文意思，只有一個答案；和英翻中的例句不同句；字首只在換不掉時給
- [ ] 片語的中翻英：空格只有一個 `＿＿`；助動詞、be、名詞受詞、something 在空格外；有會變的部分時有 1～2 題變化題，而且只用學過的文法
- [ ] 試填其他時態、代名詞、受詞位置與同義片語後，仍然只有一個答案；兩種都對的已用 ` | ` 列出並寫詳解
- [ ] 動詞的中翻英與不規則變化目標底下有一行「動詞變化：」，三種形式都對
- [ ] 不規則變化只建教材正在教、或這一課明列（含字旁邊的註明）的；名稱結尾是變化種類；拼法沒變的沒建；單字的中翻英池沒有變化形
- [ ] 這一課的文法重點都有文法目標，名稱照 `文法點（用法） 文法`；題目沒寫文法名稱、括號只有原形；試過六類多解的反例；` | ` 的說法字數相同；to V 與 V-ing 都對的有詳解
- [ ] 排序只挖句中那一段、一句只有一種排法、句首句尾在空格外；每個目標 3 句，和打字題不是同一句
- [ ] 比較只建這一課需要的組；每個字一個目標、至少兩句（兩個字的組至少三句）；試填過組裡每個字；每個字都有具體的分辨線索，同組同句型；AI 補的組在備註寫了理由
- [ ] 記憶錨點只寫有連結的；提到的字都附中文；每個方向最多兩行；字根有依據，沒有編造字源
- [ ] 和已有的目標比對過：教材每一處（單字表、課文、閱讀、解析、練習）用到已有的字或文法都找過；相同的用原 ID、原名稱加一題，拿不準的寫待核對
- [ ] 文法題的答案和括號的字不一樣
- [ ] 錯題的錯因照 §10 的情況表，拿不準時照通用規則選代價低的，並在理由寫出猶豫
