# 製卡規則｜自然預設 v0

> 狀態：💡 v0 草稿。適用於國中自然，搭配通用規則（common.md）使用；與通用規則衝突時，以本檔為準。

## 你會收到

- 課本或講義的頁面（PDF 或照片）
- 或錯題：題目、學生的答案、正確答案

## 知識類型與出題方式

| 類型 | 例子 | 出題方式 |
|---|---|---|
| 定義 | 什麼是介質 | 「用自己的話說明什麼是……」；答案寫 2～3 個關鍵詞，不要求逐字背課本 |
| 因果 | 為什麼真空中聽不到聲音 | 「為什麼……」、「如果……會怎樣？為什麼？」 |
| 比較 | 聲音在固體、液體、氣體中的傳播快慢 | 「A 和 B 有什麼不同？」；答案列 2～3 點 |
| 順序 | 實驗步驟、變化過程 | 「依序說出……」 |
| 實驗 | 探討影響音調的因素 | 問目的、**操縱變因、控制變因、應變變因**、結果與結論 |
| 公式與單位 | 波速 = 頻率 × 波長 | 公式的意義、各符號代表什麼、單位 |
| 圖表 | 波形圖 | 用文字描述圖意出題，標「建議附圖」 |

規則：

1. **理解型至少佔三分之一**：每一節的目標中，因果、比較、實驗這類理解型目標至少佔三分之一，不能全是名詞定義。
2. **生活例子要在教材範圍內**：可以用生活例子出因果題，例如「打雷時為什麼先看到閃電、後聽到雷聲」，但涉及的觀念必須在教材範圍內。
3. **計算題不做成閃卡**：公式與單位可以做卡；需要多步驟運算的題目，在備註中寫「建議另做練習題」。
4. **用語跟課本一致**：例如「質量」和「重量」要分清楚，依課本的用詞。

## 錯題處理

收到錯題時，不要把原題直接變成卡片，因為背下特定題目的答案不等於學會觀念。改為：

1. **判斷錯因**，從下列選一個：
   - 忘記
   - 觀念混淆
   - 不會應用
   - 粗心
   - 題目或答案有誤
2. **對應學習目標**：寫出這題考的是哪個學習目標；如果學生還沒有這個目標，就新建。
3. **依錯因產生補強**：

| 錯因 | 補強方式 |
|---|---|
| 忘記 | 不新增卡片，標記「此目標需提前複習」 |
| 觀念混淆 | 新增 1 張比較題，把混淆的兩個觀念放在一起問 |
| 不會應用 | 新增 1～2 張變式題：同一觀念，換一個情境 |
| 粗心 | 不新增卡片；在備註提醒容易出錯的地方 |
| 題目或答案有誤 | 不新增卡片；在備註說明疑點，請家長確認 |

錯題的輸出格式，在通用格式的每個學習目標下多加兩行：

```
- 錯因：觀念混淆
- 來源錯題：（題目摘要）
```
