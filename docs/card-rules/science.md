## 你會收到

- 課本或講義的轉錄稿（說明見通用規則的「你會收到」）
- 或錯題：題目、學生的答案、正確答案（處理方式見通用規則的「錯題處理」與本檔最後一節）

## 知識類型與出題方式

| 類型 | 例子 | 出題方式 |
|---|---|---|
| 定義 | 什麼是介質 | 「用自己的話說明什麼是……」；答案寫 2～3 個關鍵詞，不要求逐字背課本 |
| 因果 | 為什麼真空中聽不到聲音 | 「為什麼……」、「如果……會怎樣？為什麼？」 |
| 比較 | 聲音在固體、液體、氣體中的傳播快慢 | 「A 和 B 有什麼不同？」；答案列 2～3 點 |
| 順序 | 實驗步驟、變化過程 | 「依序說出……」 |
| 實驗 | 探討影響音調的因素 | 問目的、**操縱變因、控制變因、應變變因**、結果與結論 |
| 公式與單位 | 波速 = 頻率 × 波長 | 公式的意義、各符號代表什麼、單位 |
| 圖表 | 波形圖 | 直接附上轉錄稿裡的圖：圖放在題目那一行，問圖表達的意思，例如「這張波形圖裡，哪一段是一個波長？」 |

規則：

1. **理解型至少佔三分之一**：每一節的目標中，因果、比較、實驗這類理解型目標至少佔三分之一，不能全是名詞定義。
2. **生活例子要在教材範圍內**：可以用生活例子出因果題，例如「打雷時為什麼先看到閃電、後聽到雷聲」，但涉及的觀念必須在教材範圍內。同一個原理的不同生活例子放進同一個題目池，一個例子一題，不要一個例子一個目標（通用規則 2）。
3. **計算題不做成閃卡**：公式與單位可以做卡；需要多步驟運算的題目，在「給家長的備註」寫「建議另外練習：……」。但例題常藏著一個要先判斷的觀念，例如哪些量要算進去、哪些不算：**這個觀念一定要出一題**（已有目標測到就不用重出），備註只寫計算本身，並寫出觀念出在哪個目標。例如浮力的例題用到「浮在水面上靜止時，浮力等於物體的重量」，問「木塊浮在水面上靜止時，浮力和它的重量有什麼關係？」，備註寫「建議另外練習：例題 3 的浮力計算；觀念出在『能說明浮體的浮力等於它的重量』」。
   - 反例：備註寫「另外練習例題 3 的計算與判斷」，卻沒有任何一題問浮力和重量的關係：計算交給了練習，觀念卻沒有卡片幫學生記住。
4. **用語跟課本一致**：例如「質量」和「重量」要分清楚，依課本的用詞。

## 輸出前自我檢查（補充通用規則）

- [ ] 逐個例題確認：每一個例題背後要先判斷的觀念，都指得出出在哪一題；備註寫計算時，同時寫出觀念出在哪個目標
- [ ] 同一個原理的不同生活例子在同一個題目池

## 錯題處理（補充通用規則）

錯因、對應學習目標與輸出格式照通用規則。自然常見的情況：

| 情況 | 錯因 | 補強 |
|---|---|---|
| 公式記錯，例如把密度寫成質量×體積 | 忘記 | 提前複習公式的目標 |
| 不會列式：觀念記得，但不知道從哪裡下手（數學本身沒問題） | 不會應用 | 出 1 題「解題關鍵」，例如「已知質量和體積，要求密度，要怎麼算？」；完整計算寫「建議另外練習：……」 |
| 單位換算錯，例如 g/cm³ 換成 kg/m³ | 不會應用 | 出 1 題換算關鍵，例如「1 g/cm³ 等於多少 kg/m³？」 |
| 列式對，但計算算錯 | 粗心 | 不加卡；在理由寫提醒 |
| 列式對，錯在數學：比例式、移項、分數或科學記號的運算不會（過程看得出來，不是一時算錯） | 先備知識不足 | 照通用規則：數學那一步已有學習目標就提前複習；沒有就出 1～2 題，出處寫「先備：國一數學 ……」 |
| 圖表判讀錯 | 不會應用 | 出 1 題看圖的題目。轉錄稿裡有同一張或相近的圖就附上；考卷上的圖不能附（錯題照片不進 vault），改用文字描述圖意 |
| 實驗的變因弄錯 | 觀念混淆 | 出 1 題問操縱、控制、應變變因的題目 |
| 相近名詞混淆，例如質量與重量、蒸發與沸騰、溫度與熱量 | 觀念混淆 | 比較題 |
