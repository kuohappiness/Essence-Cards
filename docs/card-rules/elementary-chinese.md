## 你會收到

- 課本的轉錄稿（任何版本）：課文、生字與注音、課本列的語詞與解釋、課後的語文練習。有習作時一起收到；習作接近段考的題型，拿來核對有沒有漏。
- 學生的年級，例如 `小五上`。
- 學生已有的國語目標裡，名稱含這一課用到的字的：名稱、ID、出處、第一題的答案。軟體還沒做這一步，試用時手動給。

## 字是地圖的根

國語的核心是字義：詞與成語由字組成，懂字義就能推敲沒學過的詞（使用者 2026-11-03）。國語的網不是因果，是字和字的關係：同一個字的好幾個意思與讀音、長得像的字、由字組成的詞與成語。這些關係寫在全貌的〈知識塊與關係〉；一張卡仍只測一個目標。

| 層 | 內容 | 例子（只示範結構） |
|---|---|---|
| ① | 生字的字形；這一課用到的字義；課本要求的讀音；課本明列要會解釋的語詞與成語；教材有對照的相似字；這一課教的語文知識與課文的核心理解 | 「節」的字形；「節」在節儉裡的意思 |
| ② | 用學過的字義說出一個詞的意思；同一個字的其他常用意思；語文知識換一段材料 | 學過「節（省）」「約（節省）」，說出「節約」的意思 |
| ③ | 用學過的字義推敲沒學過的詞與成語；跨課比較 | 用「循」「序」「漸」「進」推出「循序漸進」 |
| 課外 | 字的由來、成語的典故；往上接國中文言文的同一個字義 | 國中讀到「學而時習之」的「習」，站在國小「習」的字義上 |

- **拆不開的詞**：聯綿詞（蝴蝶、徘徊）、音譯詞（沙發）的意思不是字義加起來，詞本身是一個目標，不拆成字義。
- **有典故的成語**（守株待兔）：字義只推得出字面，比喻的意思要另外學。

## 一個字拆成三種目標

一張卡只考一件事（使用者 2026-11-03 同意）：答案只有一件事，孩子自評才準；每種能力各自排程，熟的不用陪著常錯的一起複習；紀錄也看得出是哪一種弱，考卷的國字注音、語詞解釋、注音各自對到一種目標。

| 目標 | 名稱 | 誰有 | 題目 | 答案 |
|---|---|---|---|---|
| 字形 | `節 字形` | 每個要會寫的生字 | 一句話，要考的字寫成注音 | 字 |
| 字義 | `節（省、不浪費） 字義` | 每個值得學的意思 | 一句話，直接給字，問它在這句的意思 | 意思 |
| 讀音 | `長 讀音` | 多音字、容易念錯的字、認讀字 | 一句話，直接給字，問它在這句怎麼念 | 注音 |

- **名稱照這個寫法**，取代 R3 的「能……」：名稱用來在學生已有的目標裡找同一個字，寫法固定才找得到。字義的括號寫這個意思的簡短說法。
- 本檔的例子只示範結構，頁碼是編的；正式出題照教材。

### 字形

- **每個要會寫的生字都有一個**：生字每個都會考（使用者），這一條不用判斷值不值得。課本分得出習寫字與認讀字時，認讀字只要會念、懂意思，不做字形，改做讀音。
- **題目**：一句話，只有要考的字寫成注音，孩子想出是哪個字，翻面對字形：

  ```markdown
  - 節 字形
      - 出處：p.82
      - 他生活很ㄐㄧㄝˊ儉，捨不得亂花錢。 :: 節
  ```

- **一個字一個目標**：同一個字在不同的詞裡（節儉、節日）放同一池，因為字形一樣。
- **試填同音字**：出完題，把同音的常見字填進去試，有兩個說得通就改句子。「打ㄐㄧㄝˊ」填結、劫都通，改成「鞋帶打ㄐㄧㄝˊ了」。
- **詳解**：這個字容易和長得像的字搞混時，用部首或部件說明意思為什麼不同（見〈相似字〉）；其他的不寫詳解，也不寫筆畫數。

### 字義

- **每個值得學的意思一個目標**：第一次製卡做這一課用到的意思。孩子一看就懂、又只有一個常用意思的字（例如鼻），不做字義；拆不開的詞裡的字（蝴、蝶）也不做。不做的寫一句理由在全貌的字詞清單。
- **題目一定有語境**：只給字、不給句子，答哪個意思都對，分不出孩子會不會。

  ```markdown
  - 節（省、不浪費） 字義
      - 出處：p.82
      - 「他生活很節儉」的「節」是什麼意思？ :: **省**、不浪費
  ```

- **答成同一個字的另一個意思，算錯**；同一個意思換個說法算對（省、節省）。答案的粗體是判斷的重點。
- **題目裡的別的字不能直接給答案**：「節省」的「節」是什麼意思，答案「省」就在題目裡，算洩漏（短規則第 2 條）。
- **同一個字的另一個意思另立目標**，名稱的括號寫那個意思，例如 `節（節日） 字義`。孩子在不同的時候遇到不同句子裡的「節」，每次都要看句子判斷。第一次只做這一課用到的意思；其他常用的意思畫在地圖上，加深時再做。
- **詳解只解這一題**。兩個意思都學過，又有教材對照或錯題證據時，才加一句最短的區別。
- **意思的說法**先照課本的語詞解釋；課本沒寫的，照教育部的辭典核對意思（重編國語辭典修訂本、國語辭典簡編本），不用辭典的例句。

### 讀音

- **只有這三種字有**：課本或習作要求辨讀的多音字；照聲旁念、照常見的錯讀容易念錯的字（AI 判斷，在字詞清單寫理由）；不做字形的認讀字。其他的字讀音由字形卡的注音帶著，不另立目標。
- **一個字一個目標**；多音字的池裡混不同的讀音，答案每題不同：

  ```markdown
  - 長 讀音
      - 出處：p.84
      - 「他長得比哥哥高」的「長」怎麼念？ :: ㄓㄤˇ
          - 詳解：念ㄓㄤˇ是長大、變多的意思
      - 「這條路很長」的「長」怎麼念？ :: ㄔㄤˊ
          - 詳解：念ㄔㄤˊ是長短的長
  ```

- **讀音照課本**。課本照教育部審訂的讀音；AI 知道的可能是舊讀音，課本沒有的寫待核對，不出題。

## 語詞與成語

- **課本明列要會解釋的語詞**：整個詞的意思值得單獨記住時，第一次製卡就建一個詞義目標，名稱寫 `推敲 詞義`。值得單獨記的是：比喻或引申的意思（推敲）、拆不開的詞、課本的解釋多了字義沒有的東西（「形容……的樣子」）。詞的意思就是字義卡的答案時（節儉），不另立，字義卡的詳解寫整個詞的意思。
- **成語**：課本明列要會解釋的，第一次製卡就問整體的意思，名稱寫 `循序漸進 成語`。題目給一句短的語境；答案寫整體的意思；詳解從每個字的意思推到整體（使用者 2026-11-03）：

  ```markdown
  - 循序漸進 成語
      - 出處：p.86
      - 「學游泳要循序漸進」的「循序漸進」是什麼意思？ :: 照著**次序**，一步一步**慢慢**進步
          - 詳解：循是照著，序是次序，漸是慢慢地，進是前進；合起來是照著次序慢慢往前走，用來說學習或做事一步一步來
  ```

  - 說法由 AI 照年級自己寫，不搬辭典的文字（使用者）；AI 要自己核對字的古義與典故，核對不上的寫待核對，不出題。
  - 有典故的成語：答案寫比喻的意思，典故放詳解。
- **用字義推敲沒學過的詞**（③）：加深時做。用一小組結構相近、用到同一組學過的字義的詞，判準是「說得出整個詞的意思，也指得出是哪個字義讓你想到」。練過的詞不能拿來驗收會不會推。

## 相似字

- **一組一個辨別的目標**，名稱寫 `辨、辯 相似字`：只在教材有對照，或錯題顯示孩子真的會搞混時才建。組裡的字是這一課的生字，或已經學過的字（先備寫 ID）；課本沒教的常見字先畫在地圖，加深時做，標 [AI 補充]。
- **題目給語境與注音，答案寫字**；組裡每個字都要有題目，答案不能總是同一個字。題目不要和字形卡用同一個詞。詳解用部首或部件說明意思為什麼不同：

  ```markdown
  - 辨、辯 相似字
      - 先備：（已學過「辨」的字形目標 ID）
      - 兩個人在臺上ㄅㄧㄢˋ論誰對誰錯 :: 辯
          - 詳解：中間是「言」，和說話有關
      - 這兩張照片很像，很難ㄅㄧㄢˋ認 :: 辨
          - 詳解：中間是刀的樣子，和分開、分清楚有關
  ```

- **試填組裡的每個字**，有兩個說得通就改句子；也不能只靠固定的詞尾就猜中。
- 沒有對照、也沒有錯題證據的，不建組，在字形卡的詳解用部首說明。部件和意思的關係只寫有把握的；字的由來要附得出辭典的出處。

## 語境分三階

同一個意思換一句話，還是同一個目標（短規則第 4 條），所以三階是**同一池一題一題加上去**，不是三個目標。字形、字義、讀音、相似字都一樣（使用者 2026-11-03）：

1. **初階**：第一次製卡，用課文的短語或句子。
2. **第二階**：熟了以後加深時，加生活裡常用的句子。
3. **第三階**：再熟，加比較優美的句子。

- 第二、三階的句子由 AI 照學生的年級自己寫（使用者：辭典的例句太死板）。不署名，不寫成名句或某個人說的話。
- AI 寫的句子要檢查：搭配自然、指代清楚、語境只說得通要考的那個意思、題目沒有用近義的字直接給答案；句子裡其他的字詞在孩子的程度內，不然錯在別的字。
- 句子短到在手機上不用來回重讀；先用一句，試用時再看要不要限字數。

## 句子、篇章與讀寫的方法

初階以課文為主，進階不受限於課文（使用者）。找核心判斷（五步的第 1 步）和回頭找漏（第 5 步）時，沿下面四個方向問：

| 方向 | 問什麼 |
|---|---|
| 字義 | 這一課的字詞用到哪些字義？哪些字有好幾個意思、好幾個讀音，或和常見的字長得像？哪些詞拆不開？ |
| 句子 | 這一課教了哪個句型、關聯詞、修辭或標點？它讓句子多了什麼意思或效果？ |
| 篇章 | 這篇在說什麼、怎麼組織、是哪一種文體；作者的感受與想法從哪裡看得出來；課文帶到的文化（節日、典故）是什麼 |
| 讀寫的方法 | 這一課教的閱讀或寫作方法，換一篇文章還用得上嗎？ |

- **語文知識**（修辭、句型與關聯詞、標點、文體、篇章結構、讀寫的方法）不綁課文：名稱不寫課名，課文的句子只出現在題目裡；判斷方式是「換一篇文章還用得上嗎」。
- **分類題的答案不能每題都一樣**：每題都問「這句用了什麼修辭」，答案永遠是譬喻。改問修辭的內容（把什麼比作什麼）；學過兩種以上、教材有對照時，另立辨別的目標。
- **課文的理解**（大意、主旨、關鍵的「為什麼」、作者的感受從哪裡看出來）屬於這一課，名稱寫篇名；只建段考會考的核心理解。
- 題目用短句或短段落；整篇的閱讀測驗、作文、朗讀不做卡。

## 五步的三段怎麼寫

- **全貌**：〈知識塊與關係〉後面加一段「字詞清單」，這一課的每個生字，和要建目標的其他字、詞、成語，各一行：

  ```markdown
  ## 字詞清單

  - 節｜節儉 p.82｜字形：建；字義：省、不浪費（建）；讀音：不用；相似字：無｜比對：已有目標沒有「節」
  - 長｜長得 p.84｜字形：建；字義：長大、變多（建）；讀音：多音字，課本要辨讀（建）；相似字：無｜比對：加題 k3m9qa 長 讀音
  ```

  基本測試不用每個字各一題：字詞抽幾個有多義、多音、相似字的，其他的題目留給語文知識與課文。
- **架構**：學習目標分三組：字詞、語文知識、課文。
- **卡組**：最上層是課名，例如 `## 第七課 ○○○`；底下照 `### 字形`、`### 字義`、`### 讀音`、`### 相似字`、`### 語詞與成語`、`### 句子與篇章` 分組，沒有的組省略，不照課本的小標題。字形放第一組。
- **需要其他練習**：架構段只寫課本要求、閃卡沒做的能力名稱（例如這一課的寫作練習），不寫怎麼練；卡組的給家長的備註不寫「建議另外練習」（使用者：不寫給家長的學習建議）。

## 和學生已有的目標比對

R3 的提示還沒有這一段，暫時寫在這裡，R3 補上後移走（[backlog](../backlog.md#其他待決)）。

- **字形、讀音**：已有同一個字的目標，不新增，加一題這一課的句子。
- **字義**：先比對已有目標第一題的答案，不只看字。意思相同，加一題；意思不同，另立目標，名稱的括號寫新的意思；看不出是不是同一個意思，寫待核對，不合併，也不另建。
- **相似字**：已有同一組，加題；多了一個字，另立一組，先備寫原本那組的 ID。
- **寫法**：卡組最後放「加進已有的學習目標」引言框，每項寫已有目標的 ID 和名稱，底下寫新的出處（寫年級學期與課，例如 `小五上 L8 p.90`）和新的題目（[syntax.md §2-9](../syntax.md#2-9-ai-製卡交回的草稿)）：

  ```markdown
  > [!note] 加進已有的學習目標
  > - k3m9qa 長 讀音
  >     - 出處：小五上 L8 p.90
  >     - 「他是我們的班長」的「長」怎麼念？ :: ㄓㄤˇ
  ```

- 比對的結果寫在全貌的字詞清單。

## 加深的先後

不設上限，份量交給每日的時間上限。加深時照這個先後，順序依先備與實際需要調整：

1. 常錯的目標先換一句補題；題目本身多解或太難的，改題。
2. 熟了的目標，在原池加第二、三階的句子。
3. 支援課內詞義的常用新意思、有錯題證據的相似字。
4. 用字義說出詞的意思（②），再到推敲沒學過的詞與成語（③）。
5. 課外：字的由來、成語的典故、往上接國中。

## 照教材與不做的

- **照教材**：字義的說法先照課本，課本沒寫的照教育部的辭典；讀音照課本；字形不出簡體字或異體字。成語的說法例外，由 AI 照年級寫，意思仍要核對（〈語詞與成語〉）。
- **不做**（使用者）：寫字卡；筆畫數與每個字的部首；給家長的學習建議。閃卡做不到的（寫國字、整篇閱讀、作文、朗讀）就不做，也不寫建議另外練習。

## 輸出前自我檢查（補充）

- [ ] 每個要會寫的生字都有字形目標；名稱照 `字 字形`、`字（意思） 字義`、`字 讀音` 的寫法
- [ ] 字形題只有要考的字寫成注音；試填過同音字，只有一個答案
- [ ] 字義題都有語境；題目裡的別的字沒有直接給答案
- [ ] 一個字義目標只有一個意思；不同意思另立目標
- [ ] 讀音目標只給多音字、容易念錯的字與認讀字；多音字的池裡讀音不是每題都一樣
- [ ] 課本明列要會解釋的語詞與成語，有目標或在字義卡的詳解；成語的詳解從每個字推到整體
- [ ] 相似字的組都有教材對照或錯題證據；組裡每個字都有題目
- [ ] 語文知識的名稱沒有課名；分類題的答案不是每題都一樣
- [ ] 全貌有字詞清單與比對結果；加題只用收到的 ID，出處寫了年級學期
- [ ] 讀音、字義拿不準的寫了待核對，沒有出題

## 錯題處理

照通用規則。國語考卷的題型大多對得到一種目標：國字注音對字形，看字寫注音對讀音，語詞解釋對字義或詞義，改錯字對相似字或字形。其他的情況等試用後再補。
