## 你會收到

- 課本的轉錄稿（任何版本）：課文、生字與注音、課本列的語詞與解釋、課後的語文練習。有習作時一起收到；習作接近段考的題型，拿來核對有沒有漏。
- 學生的年級，例如 `小五上`。
- 學生已有的國語目標裡，名稱或題目含這一課生字的：名稱、ID、出處、題目與答案。軟體還沒做這一步，試用時手動給。

## 字是地圖的根

國語的核心是字義：詞與成語由字組成，懂字義就能推敲沒學過的詞（使用者 2026-11-03）。國語的網不是因果，是字和字的關係：同一個字的好幾個意思與讀音、長得像的字、由字組成的詞與成語。這些關係寫在全貌的〈知識塊與關係〉；一張卡仍只測一個目標。

| 層 | 內容 | 例子（只示範結構） |
|---|---|---|
| ① | 生字的字形；這一課用到的字義；課本要求的讀音；課本明列要會解釋的語詞與成語；教材有對照的相似字；這一課教的語文知識與課文的核心理解 | 「節」的字形；「節」在節儉裡的意思 |
| ② | 用學過的字義說出一個詞的意思；同一個字的其他常用意思；語文知識換一段材料 | 學過「節（省）」「約（節省）」，說出「節約」的意思 |
| ③ | 用學過的字義推敲沒學過的詞與成語；跨課比較 | 用「循」「序」「漸」「進」推出「循序漸進」 |
| 課外 | 字的由來、成語的典故；往上接國中文言文的同一個字義 | 國中讀到「學而時習之」的「習」，站在國小「習」的字義上 |

- **拆不開的詞**：聯綿詞（蝴蝶、徘徊）、音譯詞（沙發）的意思不是字義加起來，詞本身是一個目標，不拆成字義。
- **有典故的成語**（守株待兔）：字義只推得出字面，比喻的意思要另外學。

## 一個字拆成三種目標

一張卡只考一件事（使用者 2026-11-03 同意）：答案只有一件事，孩子自評才準；每種能力各自排程，熟的不用陪著常錯的一起複習；紀錄也看得出是哪一種弱，考卷的看注音寫國字、語詞解釋、看國字寫注音各自對到一種目標。

| 目標 | 名稱 | 誰有 | 題目 | 答案 |
|---|---|---|---|---|
| 字形 | `節 字形` | 每個生字，包括認讀字 | 一句話，要考的字寫成注音 | 字 |
| 字義 | `節（省、不浪費） 字義` | 每個值得學的意思 | 一句話，直接給字，問它在這句的意思 | 意思 |
| 讀音 | `長 讀音` | 多音字，和容易念錯的字 | 一句話，直接給字，問它在這句怎麼念 | 注音 |

- **名稱照這個寫法**，取代 R3 的「能……」：名稱用來在學生已有的目標裡找同一個字，寫法固定才找得到。字義的括號寫這個意思的簡短說法。名稱在架構寫一次，卡組照抄；判準寫在架構。
- **背面的詳解不算進自評**：答案那一格想得出來就算記住了。
- 本檔的例子只示範結構，頁碼是編的；正式出題照教材。

### 字形

- **每個生字都有一個**：生字每個都會考（使用者），這一條不用判斷值不值得。
- **認讀字也一樣**（使用者 2026-11-03）：認讀字也是要學會的字，這張卡本來就不練書寫，只要在心裡想出字的樣子。題目最後加註「（認讀字）」，孩子就知道認得、想得出樣子就好。之後的課改成習寫字時，新加的題不加註。轉錄稿看不清是不是認讀字的，照一般的生字做。
- **題目**：一句話，只有要考的字寫成注音，孩子在心裡想出是哪個字，翻面對字形：

  ```markdown
  - 節 字形
      - 出處：p.83
      - 端午ㄐㄧㄝˊ要吃粽子。 :: 節
  ```

- **和字義題用不同的句子**：字義題已經把這個字寫出來，同一句再考字形就太容易。字義題用課文的句子；字形題先用課本列的其他詞，沒有就用課文的另一處，再沒有才用同一句。
- **一個字一個目標**：同一個字在不同的詞裡（節儉、節日）放同一池，因為字形一樣。
- **試填同音字**：出完題，把同音的常見字填進去試，有兩個說得通就改句子。「打ㄐㄧㄝˊ」填結、劫都通，改成「鞋帶打ㄐㄧㄝˊ了」。
- **詳解**：這個字容易和長得像的字搞混時，用部首或部件說明意思為什麼不同，寫法照〈翻面的對照〉；其他的不寫詳解，也不寫筆畫數。

### 字義

- **每個值得學的意思一個目標**：第一次製卡做這一課用到的意思。孩子一看就懂、又只有一個常用意思的字（例如鼻），不做字義；拆不開的詞裡的字（蝴、蝶）也不做。不做的在全貌的字詞清單寫一句理由。
- **題目一定有語境**：只給字、不給句子，答哪個意思都對，分不出孩子會不會。

  ```markdown
  - 節（省、不浪費） 字義
      - 出處：p.82
      - 「他生活很節儉」的「節」是什麼意思？ :: **省**、不浪費
  ```

- **答成同一個字的另一個意思，算錯**；同一個意思換個說法算對（省、節省）。答案的粗體是判斷的重點。
- **題目裡的別的字不能直接給答案**：「節省」的「節」是什麼意思，答案「省」就在題目裡，算洩漏（短規則第 2 條）。
- **同一個字的另一個意思另立目標**，名稱的括號寫那個意思，例如 `節（節日） 字義`。孩子在不同的時候遇到不同句子裡的「節」，每次都要看句子判斷。第一次只做這一課用到的意思；其他常用的意思畫在地圖上，加深時再做。
- **詳解只解這一題**。兩個意思都學過，又有教材對照或錯題證據時，才加一句最短的區別。
- **意思的說法**先照課本的語詞解釋；課本沒寫的，照教育部的辭典核對意思（重編國語辭典修訂本、國語辭典簡編本），不用辭典的例句。

### 讀音

- **只有這兩種字有**：課本或習作要求辨讀的多音字；照聲旁念、照常見的錯讀容易念錯的字（AI 判斷，在字詞清單寫理由）。其他的字讀音由字形卡的注音帶著，不另立目標。
- **一個字一個目標**；多音字的池裡至少兩種讀音，答案每題不同：

  ```markdown
  - 長 讀音
      - 出處：p.84
      - 「他長得比哥哥高」的「長」怎麼念？ :: ㄓㄤˇ
          - 詳解：念ㄓㄤˇ，和「成長」的長一樣，是長大、變多的意思
      - 「這條路很長」的「長」怎麼念？ :: ㄔㄤˊ
          - 詳解：念ㄔㄤˊ，和「長短」的長一樣
  ```

- **詳解舉一個同讀音的常用詞**：孩子用熟悉的詞記讀音；系統語音不會念注音，之後做中文朗讀時，念這個詞就聽得到讀音。
- **讀音照課本**。課本照教育部審訂的讀音；AI 知道的可能是舊讀音。多音字在課本只出現一種讀音時，另一種照教育部的審訂音核對；核對不了寫待核對，這個目標先不建，免得池裡只有一種讀音、看起來卻像在練辨讀。

## 語詞與成語

- **課本明列要會解釋的語詞**：第一次製卡就建一個詞義目標，名稱寫 `節儉 詞義`，題目給一句話，問整個詞的意思。字義卡只問一個字，孩子不一定想過整個詞的意思，所以兩個都建。詞義和字義的判準實質相同時（例如這個詞就是那一個字），只建一個，在架構寫明它承接哪個字義。
- **課本沒有明列的詞**：整個詞的意思值得單獨記住時才建，例如比喻或引申的意思（推敲）、拆不開的詞。
- **成語**：課本明列要會解釋的，第一次製卡就問整體的意思，名稱寫 `循序漸進 成語`。題目給一句短的語境；答案寫整體的意思；詳解從每個字的意思推到整體（使用者 2026-11-03）：

  ```markdown
  - 循序漸進 成語
      - 出處：p.86
      - 「學游泳要循序漸進」的「循序漸進」是什麼意思？ :: 照著**次序**，一步一步**慢慢**進步
          - 詳解：循是照著，序是次序，漸是慢慢地，進是前進；合起來是照著次序慢慢往前走，用來說學習或做事一步一步來
  ```

  - 說法由 AI 照年級自己寫，不搬辭典的文字（使用者）；AI 要自己核對字的古義與典故，核對不上的寫待核對，不出題。
  - 有典故的成語：答案寫比喻的意思，典故放詳解。
- **用字義推敲沒學過的詞**（③）：加深時做。用一小組結構相近、用到同一組學過的字義的詞，判準是「說得出整個詞的意思，也指得出是哪個字義讓你想到」。練過的詞不能拿來驗收會不會推。

## 相似字

> v0.2（2026-11-04）：一個字一個目標、點字比較（[D-178](../decisions.md#d-178-相似字用點字比較卡一格一個學習目標)）。比較卡的程式還沒做；做好之前這些目標照一般的問答卡出，寫法不用改。翻面的對照是使用者定的呈現方式；名稱與題目的寫法照[規畫](../plans/similar-chars.md)。

- **組裡每個字一個目標**，名稱寫 `寨（寨、塞、寒、賽） 相似字`，括號裡是整組的字，用頓號隔開，一組一般 2～5 個，教材列更多時照教材。只在教材有對照，或錯題顯示孩子真的會搞混時才建。**教材列了對照就建，第一次製卡沒有已有的目標也一樣**：這一課的生字、教材對照裡的其他字都直接新建，學過的字有 ID 時寫進先備。課本和教材都沒列的常見字先畫在地圖，加深時做，標 [AI 補充]。同一個字被教材列在兩組時（添和漆、添和舔），各一個目標，因為比的對象不同。
- **題型是[比較點選](../question-types.md#比較點選)，它測的是分辨，不是想出一個字**：孩子看到整組字，點字填進句子，程式判對錯。題目只有一句話，要考的字寫成 ＿＿，答案只有那個字，不用問為什麼：

  ```markdown
  - 寨（寨、塞、寒、賽） 相似字
      - 出處：p.90
      - 盜匪躲在山＿＿裡。 :: 寨
      - 這座古老的＿＿子建在山頂上。 :: 寨
      - 記憶錨點：下面是**木**，木頭圍成的防守地：山寨、寨子
  ```

- **每個字至少兩句**（只有兩個字的組至少三句，[D-182](../decisions.md#d-182-比較點選各科都能用家長出題時勾選)），再出時換一句。**句子由 AI 寫**：對照的字常常不在課文裡，不用課文的句子，先用教材列的詞；照〈語境分三階〉的檢查項目，第二、三階照舊加深時加。
- **試填組裡的每個字**，有兩個說得通就改句子。答案的字不能出現在題目裡（喵喵叫改成喵了一聲）；教材的詞裡的另一個字不算洩漏（寒冷、增添）。題目盡量不和字形卡用同一個詞。

### 翻面的對照

對答案後，整組字排在一起，每個字一行，這是這張卡最能幫孩子記住的地方（使用者 2026-11-04 指定真實的卡要這樣呈現）。**每個字都要寫**，放在學習目標底下的「記憶錨點：」，例如這一組：

| 字 | 記憶錨點 |
|---|---|
| 寨 | 下面是**木**，木頭圍成的防守地：山寨、寨子 |
| 塞 | 下面是**土**，用土堵住：塞車、塞住 |
| 寒 | 下面兩點是**冰**，冷到結冰：寒流、寒假 |
| 賽 | 下面是**貝**（古代的錢）：比賽、賽跑 |

- **三段**：差別在哪個部件，粗體；這個部件怎麼連到這個字的意思；全形冒號後面一兩個常用詞，先用教材列的詞，太少見的不用。
- **連到本義就好**：部件連的是這個字原本的意思，接不到教材的詞也沒關係（采：下面是**木**，手摘樹上的東西：神采、風采）。
- **同一組用同一個句型**，都說不同的那個部位，部位照實寫（下面、左邊、右上），排在一起才看得出差別。差別只是有沒有某個部件時，直接寫有沒有，再接這個字本身的說法（藐：上面多了**艹**，原本是一種草；貌：上面**沒有艹**，右邊畫的是人臉）；拆不出部件時，說筆畫差在哪。
- **短**：冒號前面約 15 字以內，手機上一行讀完。
- **只寫有把握的**：部件和意思的關係要查得到依據（教育部的辭典、《說文解字》等字書），依據不用寫在卡上；查不到，或只是自己推想的情節（「加水讓東西變多」），就只寫部件和常用詞，不編故事（賽的「貝」只寫到部件是什麼）。**差別的部件只管讀音時**（形聲字的聲旁），寫「右上是**天**，念法接近天」，不硬連意思；聲旁也帶意思的，連意思（澗的「間」：山間的流水）。

沒有對照、也沒有錯題證據的，不建組；這個字容易和長得像的字搞混時，字形卡的詳解用同樣的寫法。

## 語境分三階

同一個意思換一句話，還是同一個目標（短規則第 4 條），所以三階是**同一池一題一題加上去**，不是三個目標。字形、字義、讀音、相似字都一樣（使用者 2026-11-03）：

1. **初階**：第一次製卡，用課文的短語或句子；字形題照〈字形〉，先用課本列的其他詞。
2. **第二階**：熟了以後加深時，加生活裡常用的句子。
3. **第三階**：再熟，加比較優美的句子。

- 第二、三階的句子由 AI 照學生的年級自己寫（使用者：辭典的例句太死板）。不署名，不寫成名句或某個人說的話。
- AI 寫的句子要檢查：搭配自然、指代清楚、語境只說得通要考的那個意思、題目沒有用近義的字直接給答案；句子裡其他的字詞在孩子的程度內，不然錯在別的字。
- 句子短到在手機上不用來回重讀；先用一句，試用時再看要不要限字數。

## 句子、篇章與讀寫的方法

初階以課文為主，進階不受限於課文（使用者）。找核心判斷（五步的第 1 步）和回頭找漏（第 5 步）時，沿下面四個方向問：

| 方向 | 問什麼 |
|---|---|
| 字義 | 這一課的字詞用到哪些字義？哪些字有好幾個意思、好幾個讀音，或和常見的字長得像？哪些詞拆不開？ |
| 句子 | 這一課教了哪個句型、關聯詞、修辭或標點？它讓句子多了什麼意思或效果？ |
| 篇章 | 這篇在說什麼、怎麼組織、是哪一種文體；作者的感受與想法從哪裡看得出來；課文帶到的文化（節日、典故）是什麼 |
| 讀寫的方法 | 這一課教的閱讀或寫作方法，換一篇文章還用得上嗎？ |

- **語文知識**（修辭、句型與關聯詞、標點、文體、篇章結構、讀寫的方法）不綁課文：名稱不寫課名，課文的句子只出現在題目裡；判斷方式是「換一篇文章還用得上嗎」。
- **分類題的答案不能每題都一樣**：每題都問「這句用了什麼修辭」，答案永遠是譬喻。改問修辭的內容（把什麼比作什麼）；學過兩種以上、教材有對照時，另立辨別的目標。
- **課文的理解**（大意、主旨、關鍵的「為什麼」、作者的感受從哪裡看出來）屬於這一課，名稱寫篇名；只建段考會考的核心理解。
- 題目用短句或短段落；整篇的閱讀測驗、作文、朗讀不做卡。

## 古典詩

> v0.4（2026-11-05，[D-183](../decisions.md#d-183-國語一課分成幾篇古典詩做接句)）。只用自編的題目試過（[試用紀錄](trials.md)），還沒用真的課本試過。

- **接句只做古典詩**（絕句、律詩等）。現代詩預設不做，課本要求背的才做；其他照一般課文出題。
- **每句接下一句各一個目標，再加一個從題目接第一句**：一首絕句 4 個目標。名稱寫 `鳥鳴澗 第 1 句 接句`，第幾句是答案那一句。放在詩句篇，一首一個小標題。
- **題目只有上一句，答案只有下一句**；第 1 句的題目問「〈鳥鳴澗〉的第一句是什麼？」。字與標點照課本，不改字。
- **每個目標都寫記憶錨點，照詩句的排列分行，一行一個子項目**：第一行解釋上一句，第二行解釋下一句；上下句的關係值得說時放第三行，一句就好。第 1 句的卡只有一句詩：第一行解釋這一句，題目或全詩的畫面放第二行。
- **解釋照課本的語譯或注釋**，不自己編情節。課本沒有語譯的，照字面說這一句在講什麼，卡上不寫「字面意思」這幾個字。有拿不準的地方（例如一個詞有兩種讀法），不選邊，只寫兩種都說得通的部分；整句都拿不準才不寫那一行，在架構段寫待核對，只剩一行就寫一行。接句照做，答案是原句，不靠解釋。

  ```markdown
  ### 鳥鳴澗
  - 鳥鳴澗 第 2 句 接句
      - 出處：p.84
      - 人閒桂花落， :: 夜靜春山空。
      - 記憶錨點：人心清閒，桂花悄悄飄落；
      - 夜晚寂靜，春山顯得空曠。
      - 兩句都在寫靜。
  ```

- **白話放課文篇**：每首至少一題問整首在寫什麼，題目與答案都用白話，不引原句，免得洩漏接句的答案。整首的意思拿不準就不出這一題，寫待核對。

## 五步的三段怎麼寫

- **全貌**：基本測試後面加一段「字詞清單」。這一課的每個生字、課本明列的語詞與成語、要建目標的其他字詞，各一行，寫頁碼、每種能力的去向（新建的代號、加題的已有 ID、略過或待核對的理由）：

  ```markdown
  ## 字詞清單

  - 節｜p.82 節儉、p.83 節日｜字形：T01；字義（省、不浪費）：T08；讀音：不用，課本不要求辨讀；相似字：無
  - 長｜p.84 長得｜字形：T02；字義（長大、變多）：T09；讀音：加題 k3m9qa 長 讀音
  - 節儉｜p.82 語詞｜詞義：T15
  ```

  基本測試不用每個字各一題，只抽有多義、多音、相似字的和核心的。字詞類的基礎目標（字形、字義、讀音、明列的詞義）沒被抽到的，以字詞清單寫的教材要求為依據，這是五步第 5 步「每個目標都有測試裡的題目支持」的例外。
- **架構**：學習目標照卡組的篇分組：字詞、成語、課文（語文知識也在這裡）、詩句。每個目標在名稱前標「新建」「加題」或「待核對」；R3 格式的「架構和卡組的名稱一字不差」只用在新建的目標，加題的沿用已有目標的 ID 與原名，寫在卡組的引言框（〈和學生已有的目標比對〉）。
- **卡組**：一課分成幾篇，有內容才建；屬性相同（同一個單元），檔名照 `小五上國語 L7 字詞`。每一篇都先寫檔名再寫本文，最上層都是課名，例如 `## 第七課 ○○○`。第一次製卡和加深都這樣分；加深的新目標進同一篇的同名小標題。不照課本的小標題。

  | 篇 | 放什麼 | 小標題 |
  |---|---|---|
  | 字詞 | 字形、字義、讀音、相似字、語詞 | `### 字形`、`### 字義`、`### 讀音`、`### 相似字`、`### 語詞`，沒有的省略 |
  | 成語 | 課本明列要會解釋的成語 | 不用 |
  | 課文 | 句子與篇章、語文知識、課文理解、詩的白話 | `### 句子與篇章` |
  | 詩句 | 古典詩的接句 | 一首一個，例如 `### 鳥鳴澗` |
- **需要其他練習**：架構段只寫課本要求、閃卡沒做的能力名稱（例如這一課的寫作練習），不寫怎麼練；卡組的給家長的備註不寫「建議另外練習」（使用者：不寫給家長的學習建議）。

## 和學生已有的目標比對

R3 的提示還沒有這一段，暫時寫在這裡，R3 補上後移走（[backlog](../backlog.md#其他待決)）。

- **怎麼比**：看字或詞、哪一種能力、必要的意思，不只看名稱。名稱有這個字只是先挑出候選；舊的目標名稱也可能沒有這個字。只看第一題的答案判斷不了時，再看其他題目與出處；還是不確定，寫待核對，不合併，也不另建。
- **字形、讀音**：已有同一個字的目標，不新增，加一題這一課的句子。
- **字義**：意思相同，加一題；意思不同，另立目標，名稱的括號寫新的意思。
- **詞義、成語、語文知識**：判準相同，加一題；不同，另立。
- **相似字**：同一個字、同一組已有目標，加題；組多了一個字，新字新建目標，括號寫完整的組，已有的目標不動（💡 要用 L8 測）。
- **寫法**：卡組最後放「加進已有的學習目標」引言框，每項寫已有目標的 ID 和原名，底下寫新的出處（寫年級學期與課，例如 `小五上 L8 p.90`）和新的題目（[syntax.md §2-9](../syntax.md#2-9-ai-製卡交回的草稿)）：

  ```markdown
  > [!note] 加進已有的學習目標
  > - k3m9qa 長 讀音
  >     - 出處：小五上 L8 p.90
  >     - 「他是我們的班長」的「長」怎麼念？ :: ㄓㄤˇ
  ```

- 比對的結果寫在全貌的字詞清單。

## 加深的先後

不設上限，份量交給每日的時間上限。加深時照這個先後，順序依先備與實際需要調整：

1. 常錯的目標先換一句補題；題目本身多解或太難的，改題。
2. 熟了的目標，在原池加第二、三階的句子。
3. 支援課內詞義的常用新意思、有錯題證據的相似字。
4. 用字義說出詞的意思（②），再到推敲沒學過的詞與成語（③）。
5. 課外：字的由來、成語的典故、往上接國中。

## 照教材與不做的

- **照教材**：字義的說法先照課本，課本沒寫的照教育部的辭典；讀音照課本；字形不出簡體字或異體字。成語的說法例外，由 AI 照年級寫，意思仍要核對（〈語詞與成語〉）。
- **不做**（使用者）：寫字卡；筆畫數與每個字的部首；給家長的學習建議。閃卡做不到的（寫國字、整篇閱讀、作文、朗讀）就不做，也不寫建議另外練習。

- [ ] 字形題只有要考的字寫成注音；試填過同音字，只有一個答案；和同一個字的字義題不是同一句
- [ ] 字義題都有語境；題目裡的別的字沒有直接給答案
- [ ] 一個字義目標只有一個意思；不同意思另立目標
- [ ] 讀音目標只給多音字與容易念錯的字；多音字的池裡至少兩種讀音

## 錯題處理

照通用規則。國語考卷的題型大多對得到一種目標：看注音寫國字對字形，看國字寫注音對讀音，兩種都要寫的題按小題分開；語詞解釋對字義或詞義；改錯字對相似字或字形。其他的情況等試用後再補。
