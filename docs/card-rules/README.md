這裡是 Essence Cards 交給 AI 的製卡規則。未來會成為外掛內建的預設規則，家長可以在 Obsidian 裡修改。分層設計見[架構 §7](../architecture.md#7-製卡規則-)。

| 檔案 | 層級 | 狀態 |
|---|---|---|
| [common.md](common.md) | ① 通用規則與 ② 知識類型共用的格式 | v0.2 |
| [english.md](english.md) | ③ 英文預設：詞彙、例句、發音、記憶錨點 | v0.3 |
| [science.md](science.md) | ③ 自然預設：七種知識類型、錯題處理 | v0，第一輪試用通過 |
| [general.md](general.md) | ③ 一般知識預設：學業以外的領域，例如攝影、醫學（D-038） | v0，尚未試用 |

試用紀錄：

| 日期 | 結果 |
|---|---|
| 2026-10-10 | 第一輪（ChatGPT）：英文沒問題；自然有附課本明顯比不附好；例句問法適合當答對後的進階題 → 規則改為 v0.1（D-021、D-022） |
| 2026-10-10 | 架構釐清第 4 步：加入題目池、已學過的知識再次出現、跨單元比較題的規則 → v0.2（D-027、D-028）；v0.2 尚未試用 |

## 試用方式（不需要寫程式）

目的：用真實教材確認這些規則能不能做出好卡片，並依結果修改規則。

### 1. 準備教材

- **自然**：國二上的一節，2～4 頁課本 PDF 或照片。有錯題的話也準備 2～3 題。
- **英文**：一課的單字表，10～20 個字；有課文的話一起準備。
- **一般知識**：一部影片或一篇文章的筆記，自己寫的或工具整理的都可以；再寫一句學習目的，例如「想看懂健檢報告」。
- 教材只上傳到 ChatGPT 或 Claude 的對話，**不要放進這個 repo**（版權，見 D-003）。
- 從整本 PDF 取出幾頁：用 Edge 或 Chrome 打開 PDF → 列印（Ctrl+P）→ 印表機選「另存為 PDF」→ 頁面選「自訂」並輸入頁碼，例如 `45-48` → 儲存。沒有 PDF 時，直接用手機拍課本也可以。

### 2. 在 ChatGPT 開新對話

上傳 `common.md`、對應科目的規則檔（`science.md`、`english.md` 或 `general.md`）和教材，再貼上：

```
請依照我上傳的「通用規則」與科目預設，為附件教材製作複習卡片。
學生：國中二年級
科目：自然（或：英文）
家長調整：無（英文可寫：開啟記憶錨點）
請先完整讀完規則，輸出前依通用規則最後的自我檢查逐項確認。
```

### 3. 對照實驗（選做）：不給課本會怎樣？

另開一個新對話，同樣上傳規則，但**不上傳課本**，只說章節名稱，例如「國二上自然 第三章 波動與聲音 第二節」。比較兩次結果：範圍對不對、深度符不符合、用語和課本一不一致。

### 4. 以家長身分評分

每個學習目標標一個符號：

| 符號 | 意思 |
|---|---|
| ✅ | 直接可用 |
| ✏️ | 要修改（寫一句改什麼） |
| ❌ | 不要（寫一句為什麼） |

再回答四個整體問題：

1. 有沒有漏掉的重點？
2. 題數太多、剛好，還是太少？
3. 難度和用詞符合國二嗎？
4. 有沒有錯誤的內容？

### 5. 把結果帶回來

把評分和整體回答貼給 Claude。只需要貼有 ✏️、❌ 的部分和整體回答，不用貼全部卡片，比較省額度。Claude 會依結果修改規則，再進行下一輪。可以照這個格式：

```
【試用回報】科目：自然／教材：第 X 章第 X 節 p.45-48／模型：ChatGPT
學習目標數：8（✅ 5、✏️ 2、❌ 1）
✏️ LT-3：答案太長，學生在腦中答不出來
✏️ LT-6：用詞是高中程度
❌ LT-8：課本的補充閱讀，不用考
漏掉的重點：沒有出實驗的變因題
題數：剛好／太多／太少
難度與用詞：……
錯誤內容：無
對照實驗（不給課本）：範圍超出課本，用詞不同
```

試用的教材、卡片與評分，之後會整理成 AI 評測集（benchmark）的第一批案例。

## NotebookLM 對照實驗

2026-10-11 排入 v1 開發前要做的事（[路線圖](../roadmap.md#v1-開發前要做的事)、[背景](../backlog.md#ai-規劃2026-10-11-起的專題討論)）。

目的：NotebookLM（Gemini Notebook）匯入教材就能直接產生閃卡。這個實驗確認我們的製卡規則比它好多少，以及 NotebookLM 能不能當複製貼上模式的 AI。

教材：國二上自然一節，和上面的試用一樣。英文一課的單字表選做。

1. 在 NotebookLM 建一個 notebook，上傳教材。
2. **A 組**：在 Studio 產生閃卡，用預設設定。有下載 CSV 的按鈕就順便下載，記下有哪些欄位。
3. **B 組**：在同一個 notebook 的對話裡，請它依照我們的規則製卡。規則有兩種給法，先試第一種，不行再試第二種，記下哪一種可行：
   - 把 `common.md`、`science.md` 也加成來源，再貼上[第 2 步](#2-在-chatgpt-開新對話)的提示。
   - 把規則內容直接貼進對話。
4. A、B 兩組都用[第 4 步](#4-以家長身分評分)的 ✅ ✏️ ❌ 評分，另外記下：
   - 題數。
   - 家長審完一組大約花幾分鐘。
   - B 組能不能照輸出格式寫：清單縮排、出處頁碼。
   - NotebookLM 的引用標記能不能對應到課本頁碼。

回報時在[第 5 步](#5-把結果帶回來)的格式後面加上：

```
【NotebookLM 對照】
A 組（Studio 閃卡）：題數 __（✅ __、✏️ __、❌ __），審核約 __ 分鐘，CSV 欄位：……
B 組（我們的規則）：題數 __（✅ __、✏️ __、❌ __），審核約 __ 分鐘
B 組的格式：可以直接用／要修改（哪裡）
規則給法：加成來源／貼進對話／都不行
引用對應頁碼：可以／不行
```

結果怎麼用：

| 結果 | 下一步 |
|---|---|
| A 組和 B 組差不多 | 製卡規則少投入；考慮做閃卡 CSV 匯入 |
| B 組明顯較好 | 繼續投入製卡規則；NotebookLM 只當上游 |
| B 組在 NotebookLM 裡能照格式輸出 | 使用說明書推薦它當複製貼上模式的 AI：免費，而且以教材為依據 |
