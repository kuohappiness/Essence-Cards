# Essence Cards｜討論紀錄

記錄討論經過、取捨與結論如何形成。此目錄不作為畫板的內容來源。

## 紀錄方式

- 按日期與主題保存 Markdown 摘要，同一天可按主題拆分。
- 保留使用者提出的需求與限制、助理的提案、取捨理由、確認或排除的結果、未解問題。
- 摘要不冒充逐字聊天，也不補寫未發生的討論或未確認的理由。
- 有結論或狀態改變時，同步更新[決策紀錄](../../decisions.md)或[開發現況與路線圖](../../roadmap.md)（2026-10-10 前為 v0 的 consensus.md 與 tasks.md）。
- 過去的立場按當時狀態記錄，後續改變另加新紀錄，不覆寫成彷彿一開始就如此。
- Git 提交保留文件版本；本目錄保留人容易閱讀的討論脈絡。

## 後續摘要格式

1. 日期與主題。
2. 使用者提出的想法或限制。
3. 助理提出的選項及理由。
4. 取捨、修正與結果，標示已確認或仍為提案。
5. 尚待釐清的問題。
6. 受影響的共識與任務 ID。
