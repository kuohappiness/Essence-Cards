# 2026-10-06｜點子收集箱與參考軟體

日期：2026-10-06（Asia/Taipei）。此文件為討論摘要，不是逐字聊天紀錄。

## 使用者想法

接下來會直接提出許多零散點子，希望助理先記錄在看板上，之後再一一釐清。第一個例子是設置專區，蒐集其他類似軟體的功能；閃卡可以參考 RemNote，以及使用者提供的 [Memory Toast](https://www.memory-toast.com/zh-TW)。

## 取捨與結果

- 已確認：先收集零散點子，再逐項討論；不要求使用者先整理成需求規格。
- 已確認：收集參考軟體功能，初始參考為 RemNote 與 Memory Toast；尚未決定採用任何具體功能。
- 依最新要求調整既有畫板範圍：在目前任務、最新共識之外，加入獨立的待釐清點子區。過往討論與已排除選項仍不進入看板。
- 助理實作：以 `docs/ideas.md` 保存原意與問題，以 `docs/references/software.md` 保存來源，建立 I-001、R-001 與 R-002。
- 助理實作：新增由 Markdown 生成的單檔 HTML，看板、自由畫板、文字綱要與參考軟體皆使用同一份內容；建立同步與 Pages 發布工作流程，首次 Pages 啟用另列 T-004。
- 助理提出的比較面向：製卡負擔、卡片形式與來源連結、複習與回饋、資料可攜性。這些尚未確認為產品需求。
- 查核範圍：找到 RemNote 官方閃卡文件；Memory Toast 頁面本次未能讀取，先保留網址，未推測其功能。

## 尚待釐清

- 參考軟體專區目前先作為專案研究區；是否也要成為軟體內的功能，待討論。
- 比較情境、研究深度與功能優先順序。
- 實際觀察後，哪些功能適合 Essence Cards。
