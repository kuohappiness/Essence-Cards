# 2026-10-11｜API 挑選專題討論

使用者另開一條討論，專門談 API 相關的規劃。本紀錄是摘要，不是逐字紀錄；討論進行中，有新進展再補。調查結果見[AI API 供應商調查](../../research/api-providers.md)。

## 1. 從哪裡開始

**使用者提出**：不知道怎麼開始；是不是先找符合需求的 API？條件是免費額度優先，也接受 CP 值高的，再從裡面挑品質最好的。

**助理整理文件裡已經有的**：條件就是 [D-055](../../decisions.md#d-055-ai-模型的選擇原則)；[D-059](../../decisions.md#d-059-ai-的接法一種介面模型不包進外掛) 定了一種介面、依卡片品質比較 2～3 個候選；[架構 §6](../../architecture.md#6-ai-的位置-細節之後專門討論) 有用量估計；[D-048](../../decisions.md#d-048-使用說明書) 補充要說明書教申請免費金鑰。缺的是「找之前」先定淘汰條件。

**助理提案的流程（💡）**：① 定淘汰條件 → ② 查官方資料列候選 → ③ 在試作場實測 2～3 個 → ④ 定案（免費首選＋付費備案）。依 [D-065](../../decisions.md#d-065-試作場)，第 ③ 步由 AI 跑程式、先評分；使用者只要申請金鑰、提供教材，最後在前兩名之間挑。

## 2. 未成年的條款

**助理查到**：[Gemini API 附加條款](https://ai.google.dev/gemini-api/terms)（2026-03-23 生效）要求使用者滿 18 歲，也不能用在「以 18 歲以下為對象，或很可能被他們使用」的程式裡。家長申請金鑰沒問題，但 Essence Cards 是給學生用的程式，照字面會碰到第二條。免費方案另外要求不要送個人資料。

**助理建議**：從嚴，說明書不推薦這類服務。

**使用者決定**：使用者多半是家長，先不考慮未成年的問題，不用太嚴格。→ 不列為淘汰條件。

## 3. 淘汰條件

**助理提出五條**：OpenAI 相容、能看圖、一次塞得下、家長申請得到、價格。

**使用者**：五條都同意，第 3 條要討論：會不會太嚴？Capture 負責把 PDF、影片轉成 .md，很耗 token，也要能辨識圖片與音檔；Cards 拿 .md 往下做，需求不同。兩個外掛要不要能各自選模型？

**助理回答**：

- 第 3 條不嚴：一次約 2 萬 token 裡，大部分是製卡規則本身（通用加自然約 1.2 萬字），教材先轉成 .md 也差不多。大多數模型都塞得下，只會刷掉上限特別小的免費方案。
- 建議放寬：每天能用幾次不拿來淘汰，只記在表上。
- v1 的 Cards 仍然要能看圖：Capture 不在 v1（D-039），Cards 要自己讀 PDF 頁面（D-032）；學業科目直接用課本製卡（D-021）；錯題照片在 Cards 裡分析（D-061）。
- 兩個外掛各自安裝、各自設定（D-006、D-059），本來就能選相同或不同的模型。兩邊用同一把免費金鑰時，每天的額度共用。

**使用者**：兩個外掛其實都需要能讀圖的模型。請分別替兩個外掛查詢；如果要付費，買同一家對使用者比較省事。也強調：整件事是我們把所有工作做好，對家長和學生來說，摩擦力越低越好，這點非常重要。

**結果**：五條淘汰條件定案，第 3 條照助理的建議放寬（[調查 §2](../../research/api-providers.md#2-淘汰條件2026-10-11-使用者同意)）。

## 4. 調查結果

詳見[AI API 供應商調查](../../research/api-providers.md)。摘要：

- **Google AI Studio（Gemini）**：免費、不用綁卡、台灣可用；圖片、PDF、音檔、影片、YouTube 網址都能處理，兩個外掛都夠用。免費額度 Google 已經不公布，第三方實測 Flash 每天約 20 次、Flash-Lite 每天約 500 次。
- **OpenRouter**：一把金鑰用幾百個模型；免費模型每天 50 次；付費是預付，不會被多扣。
- **Mistral**：Cards 能用，Capture 要的影片不行。
- **淘汰**：Groq（免費方案沒有能看圖的模型、每分鐘 8 千 token）、GitHub Models（已停止服務）。
- Cards 一學期的花費：便宜的模型約 0.2 美元，Gemini 3.8 Flash 約 1.4 美元，最強一級的也只要幾美元。

**助理提案（💡，待確認）**：

- 兩個外掛都推薦「一個帳號」：家長申請一次，兩個外掛貼同一把金鑰。首選 Google AI Studio：多數家長已經有 Google 帳號，要付費時同一個專案開通就好，設定不用改。備案 OpenRouter：Google 改免費方案時可以直接換。
- 降低摩擦、由外掛做好的事：
  - 設定頁提供選單：選「Google Gemini（免費）」就自動填好網址與模型，家長只要貼金鑰；仍保留自訂。這會調整 D-059「家長填網址、金鑰、模型名稱」的做法。
  - 額度用完時說清楚：例如「今天的免費額度用完了，台灣時間下午 3 點後恢復」（Google 在太平洋時間午夜重置）。
  - Google 的額度每個模型分開算：Cards 和 Capture 預設用不同模型，就不會互相用掉額度（Capture 開發時再定）。
- 實測先只測免費的：Gemini 3.8 Flash、Gemini 3.5 Flash-Lite、OpenRouter 的一個免費模型；免費的品質不夠，再加付費的對照。

## 5. 使用者追問：Claude Haiku 5.5、DeepSeek、三種語音

**使用者問**：Claude Haiku 5.5、Edge TTS、Gemini TTS、ElevenLabs、DeepSeek 查過了嗎？

**助理說明**：Claude Haiku 5.5 查過；DeepSeek 只看過 OpenRouter 的標價；語音因為屬於增強版，原本沒查。語音也會影響「同一個帳號」的方向，所以一起補查（[調查 §4、§5](../../research/api-providers.md#5-語音增強版的發音朗讀)）：

- Claude Haiku 5.5：付費裡最便宜的一級，Cards 一學期約 0.2 美元；沒有免費方案，不能聽音檔、看影片。
- DeepSeek：能看圖的 Flash 一學期約 0.3～0.5 美元；沒有免費方案，不能聽音檔、看影片。
- Gemini TTS：有免費方案，支援繁體中文，可以和製卡共用同一個 Google 帳號。
- Edge TTS：免費、不用帳號，有台灣華語的聲音；但是非官方，隨時可能失效。
- ElevenLabs：品質好，但免費每月只有約 10 分鐘，付費是訂閱制，要另開帳號。

**助理看法（💡）**：方向不變。Haiku 5.5 是付費對照組的好人選；DeepSeek 不推薦直接申請，要用時透過 OpenRouter。語音在增強版討論時，先比較 Gemini TTS 與 Edge TTS 的台灣口音與英文發音。

## 6. 定案：D-072 與推薦文件

**使用者**：同意「同一個帳號，首選 Gemini、備案 OpenRouter」，也同意三件降低摩擦的事。請給出製卡與語音、付費與免費各自推薦的方案，在 repo 裡做一份整理文件，之後依新模型的推出更新。

**結果**：[D-072](../../decisions.md#d-072-ai-服務的推薦與設定方式)；新增 [AI 模型推薦](../../ai-models.md)：製卡與語音的免費方案都是 Google AI Studio，付費是同一個帳號開通付費，備案是 OpenRouter。文件裡寫了外掛預設選單的內容與更新步驟；換推薦的模型不必新增決定。

**使用者接著回覆**：

1. 「摩擦力越低越好」寫進產品原則，但前提是不能影響學習品質。→ 產品原則第 5 條擴大到家長（[D-023](../../decisions.md#d-023-產品原則) 補充）。
2. Claude Haiku 5.5 跟 Gemini 付費相比值得嗎？值得的話再考慮儲值。→ 助理看法：兩者一學期都只要零點幾到一兩美元，差別在品質，要實測才知道。Gemini 的免費和付費是同一個模型，T4 先只測免費的，不用花錢；Gemini 的卡片有明顯問題時，再儲值加測 Haiku 5.5。

## 7. 其他 session 的相關變動

- 「AI planning」session：使用者沒時間做 NotebookLM 對照實驗，先延後；挑模型改成完全依賴這邊的試作場實測（D-059 補充）。增強版「外接模型與語音模型的選擇」、教材轉成頁面圖片的確認，都交給這條討論。

## 尚待釐清

- 推薦的模型待試作場 T4 實測確認。
- 試作場實測（第 ③ 步）。
- Gemini 付費的開通步驟對家長難不難、能不能設花費上限。
- OpenRouter 的免費模型是否要在隱私設定裡允許訓練才用得到。
- Capture 的介面：影片與 PDF 在 Gemini 要用它自己的介面，開發 Capture 時再定。
- 增強版：語音模型與本機模型的選擇。
