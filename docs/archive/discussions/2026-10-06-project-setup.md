## D-002 Markdown、無限畫板與同步

使用者提出：希望共識文件以無限畫板呈現，便於視覺理解；詢問畫板檔案格式。

助理提案：固定分區的無限畫板，可縮放、拖曳、點選卡片看細節與切換文字綱要；Markdown 保存完整內容，HTML 負責互動呈現。此前展示的畫板是預覽，操作結果不保存。

使用者確認：Markdown 與 HTML 同步，並希望畫板能透過網際網路開啟。

助理提案：由 Markdown 產生 HTML，保持版本一致，再以 GitHub Pages 發布。自動產生與發布流程當時尚未建立。

取捨：用共同的內容來源減少兩份內容分歧；畫板提供全貌，綱要提供逐項檢查的閱讀順序。
