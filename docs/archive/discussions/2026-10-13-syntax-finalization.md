## 途中的三個題目（使用者在第 1 題之前提出）

### 循序漸進加深（D-077）

- 使用者問：能不能靠製卡規則和檢核系統，讓 Essence Cards 像老師一樣，先從原子知識點與架構出卡，確認基礎都 OK 再疊加深度？
- 助理：可以，大半零件已經在設計裡（D-062、D-069、通用規則第 16 條、D-076 的教材庫）。提出兩種做法：甲是一次出完、程式逐層放出；乙是熟了才產生下一層。建議乙，並引用 Agarwal（2019）：只練事實題，高層次的題目不會跟著進步，所以要「基礎為主、熟一層加一層」，不是全部基礎熟了才深入。
- 使用者選乙，也很喜歡回答引用研究。使用者在 API 規劃補充：延伸內容也照同一個原則（D-083 補充）。

### 考試時程與目標保持率（D-078）

- 使用者問：為了配合考試時程，要不要開放自訂 FSRS 參數，例如把 7 天改成 5 天？
- 助理：7 天是「建議加深」的門檻，不是 FSRS 的參數；門檻由考試日期自動調整，家長隨時可以直接按加深。FSRS 的其他參數不開放（D-062）。只照排程複習，考試那天的預測保持率本來就在目標以上。
- 使用者接著要求：目標保持率可以自訂，介面要有說明；預設從 90% 改成 80%。
- 助理用 FSRS 預設的遺忘曲線粗估：80% 的間隔約是 90% 的 2.4 倍，隨時抽測的平均保持率約 89%（90% 約 95%）。引用 Pyc 與 Rawson（2009）支持較長的間隔，但指出考前抽測 ≥ 85% 的餘裕很薄，建議考前自動提高到 90%，並引用 Cepeda 等人（2008）。這修正了助理前一則「考前提高等抽測數字再說」的說法，因為那是以預設 90% 為前提。
- 使用者確認考試日期的情況：一份範圍裡可能有不同的考試日期，操作要簡單。結論：每一科可以有自己的日期、預設同一天；小考和段考可以同時存在，同一個單元看最近的考試；「自動」的規則見 D-078 的表格。

### Mindmap 當考題（D-056 補充）

- 使用者：Mindmap 也可以是考題的呈現；未來 Essence Mindmap 可以直接抓取引用。
- 助理：同意，設計已經預留（架構 §3、backlog「多種呈現方式」）。引用 Karpicke 與 Blunt（2011）、Blunt 與 Karpicke（2014）：看心智圖讀書不如提取練習，憑記憶填出心智圖則和提取練習一樣好，所以要先挖空回想。不需要改語法。

## 第 1 題：學習目標 ID 的寫法

- 助理提案 6 點：區塊 ID 寫在學習目標那一行行尾（單獨一張卡就寫在那張卡）；6 碼、去掉易混字元；家長與 AI 都不寫，程式補上；閱讀模式隱藏、編輯模式調淡；一張卡變成題目池時程式把 ID 搬到新的學習目標行；沿用家長自己的區塊 ID，複製造成的重複換新 ID。
- 使用者同意第 2～6 點；第 1 點問：一張卡自己就是學習目標時，同時有指紋又有 ID，會不會有問題？請用英文舉例討論。（討論中）
