# 英文學習框架與學習順序

2026-10-22｜使用者與 Codex｜討論摘要，非逐字紀錄。框架與順序已確認為 [D-123](../../decisions.md#d-123-英文學習框架與先懂意思再練拼寫)，各層的具體通過判準接著討論。

## 討論如何形成

- 使用者希望優化英文製卡規則，提高學生的學習效率。Codex 先檢視英文 v0.8、通用規則、出題語法與既有試用，提出目標邊界、練習方向、新情境、答案多解及錯因判斷等建議。
- 使用者提出四個維度：單字 → 片語 → 句子；先會念、懂意思 → 會拼（中翻英，包含時態）→ 會用（例句、文法）；一字多義多用；各種題型。
- Codex 建議區分學習單位、掌握程度、延伸範圍與練習工具。用 `went` 說明能拼出變化形與知道何時使用提供不同的能力證據；用 `borrow` 說明例句可從一開始幫助理解；用 `take a bus`／`take a photo` 說明延伸跟著實際需求。
- 使用者同意能力層次的釐清，進一步明確要求先知道中文意思、會念，最後才練拼寫：先出英翻中，不會拼字沒關係，會了才出中翻英。理由是背下不知道意思的字沒有意義。使用者也同意該輪其餘學習順序與建議。

## 確認與未解問題

- 確認內容集中在 [D-123](../../decisions.md#d-123-英文學習框架與先懂意思再練拼寫)，英文規則同步為 v0.9；本輪沒有學生試用結果。
- 這次確定的是學習框架與順序；各層怎樣算會，以及「會念」如何確認與銜接出題，留在 [backlog〈英文學習判準〉](../../backlog.md#英文學習判準)。沒有因為談到題型，就新增發音評分、排序或整句輸入功能。
