# 功能架構總覽與圖表同步

日期：2026-10-07（Asia/Taipei）。本文件是討論摘要，非逐字紀錄。

使用者希望依目前大型專案架構下的功能草案繪製 Mermaid 圖，也詢問更合適的呈現方式；要求與既有架構圖放在一起互相參照，未來所有圖隨開發方向更新。

本輪採功能分區總覽，保留 19 個 F-ID；與學習循環、技術架構及開發路線圖共同使用 B-ID。總覽回答功能組成及主要關係，既有圖各自說明學習原理、技術分工與開發門檻，避免一圖塞入所有欄位、介面與驗收細節。分區與箭頭仍是目前設計草案。

實作將功能名稱從目錄產生為 Mermaid 與功能對照表；靜態 SVG 嵌入字型，與既有圖一起呈現在桌面／手機看板。既有學習圖補上手機疑問與電腦處理，技術及路線圖補上已建立、待實機的可丟棄 UI 原型。

所有圖表登錄來源及產物，檢查索引配對、漏登錄、來源變動與產物變動。來源變動須先核對圖意及版面，再明列圖 ID 記錄快照；工作流程不自動更新核對快照。雜湊可發現漏更新，不能證明圖意正確，也不能代替需求決策。

結果：保存 C-019 與共用圖表維護規則；功能草案未升格為正式範圍。T-011 的實機結果、完整 P0、欄位、算法及第一版交付仍未定案。
