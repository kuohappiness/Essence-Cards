| T-009 | 細化 Git 備份與回復策略 | 待設計 | 驗證外部 .git、電腦限定、commit／push 與拉取設定、AI 檢查點、忽略規則、附件範圍及個別回復；個人私人備份另建 | [Git 設計重點](technical-roadmap.md)、[I-014](ideas.md) |
| T-007 | 確認 ChatGPT 手機檔案預覽可閱讀 | 待實機確認 | 使用者開啟新的 mobile.html，確認可見手機閱讀版標題、目前共識版本 及內容；若仍空白，需檢查實際開啟的附件與預覽方式 | [手機預覽追蹤](discussions/2026-10-06-mobile-preview.md) |
