## 要查的事

1. **和已有的決定、syntax.md 有沒有矛盾**，特別是 syntax §6 說快照「只寫不讀」與「AI 交回的文字原樣保留，只多了外掛配的學習目標 ID」：§5 拿掉 AI 自己寫的 ID、整理 code fence 與換行，再用 `程式改動` 記下，這樣寫可不可以；還是快照要另外留一份未整理的原文。
2. **拆篇的篇名行**（§4）：用表單的年級學期、科目、編號比整行，這條規則會不會把卡組裡正常的一行誤認成篇名（例如一般筆記段落剛好是那串字）；`## 國二上英文 L3 單字` 這種寫成標題的要不要也認；第一篇前面的引言框併進第一篇合不合理。
3. **快照的新欄位**（§5）：`時間`、`識別碼`、`對象` 改成清單、`規則`、`提示`、`提示雜湊`、`任務資料`、`已有目標`、`教材說明`、`程式改動`。夠不夠讓之後重組出送出的整份提示、回答 D-042 的比對與 D-194 第 5 點的基準；有沒有多的；欄位名稱和既有的（考試範圍的 `識別碼`）是否一致；Obsidian 屬性面板顯示巢狀清單的問題要不要避開。
4. **送出內容的檔**（§5）：放在 `紀錄/AI 輸出/送出內容/`、檔名用雜湊前 12 碼、只建立；碰撞與還原（syntax §6 最後一點）怎麼處理；規則與已有目標清單放在同一個資料夾是否合適。
5. **寫入順序與中斷**（§5）：送出內容 → 快照 → 卡組，都只建立。對照環節 8 第 4 條與它的五個反例：哪些中斷點會留下什麼；「Obsidian 中途關掉後重新貼回是新的一次、只寫了快照時那份的 ID 不算占用」這個簡化，會不會讓之後的快照比對（D-042）或加深（D-194）讀錯；要不要改成快照最後寫，或把快照的 ID 算進占用。
6. **引言框裡的 ID 算占用**（§6）：範圍寫成「標題是候選卡片、加深的學習目標的引言框，最上層清單項目那一行最後」夠不夠精確（巢狀引言框、摺起的 `[!note]-`、引言框裡縮排的清單）；它們不算 D-157 的重複，會不會讓剪下貼出時的撞號晚一步才發現；舊版外掛（`0.3.0`、`0.4.0`）不認得這條，會不會配出撞號的 ID，要不要擋。
7. **新建的草稿卡組**（§5）：屬性只寫年級學期、科目、單元、狀態（必要時 `需要版本`），檔名照 D-081，放在 `學業/<年級學期>/<科目>/`；舊版外掛讀到這種草稿會不會有問題（例如有比較卡、還沒有 `需要版本` 的舊版）。
8. **草稿 → 啟用**（§7）：`set: status` 的 `val: 啟用` 從草稿來，複習紀錄的重播與 D-115 的考試範圍歷史有沒有要多記的；舊版讀到這一行會不會出錯。
9. **邊界與測試**：§8 的單元測試清單漏了哪些應該寫成測試的情況。

只回報有證據的；不擴張成新的功能（引言框的「加入」、加深、訂閱接法都在之後的任務）。
