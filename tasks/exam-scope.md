## 和「不做」比較（D-153）

- **不做會怎樣**：v1 的驗收是「能在 iPhone 完成段考範圍的每日複習」，現在 `src/state/index.ts` 的 `exam` 是 `null`：今天的份不會優先出範圍內的卡，考前不提高保持率（D-078），學生看不到離考試還有幾天，每日時間上限照樣可能排滿範圍外的卡。
- **做的代價**：多一種外掛會寫的檔、一種紀錄行、一個畫面、`state` 多一種要讀的檔；出處的結果多三個欄位。學生多看到一行倒數，家長或學生大考前要勾一次單元。
- **更小的做法**：
  - 只做範圍檔、不做設定畫面，家長手寫檔案：D-071 的硬性要求是最多三步；家長不會手寫（D-169 第 1 點）。不夠。
  - 不做 D-170 第 11 點的檢查：`國二上 1-3, 10-15 p.44` 這種要猜的只在存檔按鈕提示，提示不一定有人看，考試時才發現少了卡。不夠。
  - 不記紀錄行與識別碼（D-115）：這批省一點，但第一次真實考試的證據補不回來。不夠。

## 2. 範圍檔（syntax §4）

檔案 `Essence Cards/考試範圍/2026-10-28 國二上.md`：

```markdown
---
識別碼: x7f3k2
考試開始: 2026-10-28
考試結束: 2026-10-29
---
- 國二上 自然 2
- 國二上 自然 3-1
- 國二上 英文 L1
- 國二上 英文 L2
```

這是固定格式（D-176 第 7 點）：一行一個編號，不再有區間與一行好幾項。平常由設定畫面的勾選寫出來，家長不用學。syntax §4 的區間、頓號與 `Unit 1～Unit 3` 的例子跟著改。

### 2-1 一行怎麼讀

純函式，放 `src/core/catalog/scope.ts`，只看字面。`termKey`、`codeKey` 是比對鍵，不是讀取器（`codeKey('第2章')` 還是 `第2章`，Codex F2b），所以 `deck` 多匯出去雜訊與年級學期的讀法，編號的別名（`第2章`、`第1章第3節`、`L 1`、`單元 2-1`）在這裡讀成標準的編號。

**屬性區以外逐行當純文字讀**（Codex F2d），不看 Markdown 語境：圍欄、HTML 註解、`>`、分隔線裡的字一樣是一行，讀得懂就算，讀不懂就留著、列出來（§2-6）；非空、不是標題（`#`）的都算一行。檔頭的 BOM 拿掉。不因為少打一個 `- ` 就默默不算；代價是註解裡的合法行也生效，範圍檔本來就不放自由筆記（D-176 的代價）。

一行是「年級學期 科目 編號」，照這個順序讀（Codex F2c）：

1. 去雜訊（和出處同一個），拿掉開頭的清單符號（`-`、`*`、`+`、`1.`）與結尾的標點。
2. **先拒絕**，在吃名稱之前：行中還有 `,`、`、`、`;`、`/`、`~`，或數字之間的 `到`、`至`，就是一行好幾項或區間，算看不懂。
3. **年級學期**：開頭是認得的（`八上`、`國二 上`、`國二上學期` 都是國二上；後面不用空白）；否則是第一個空白前的字，照原字，不當成已知學期（`B2` 對得到 `B2` 的卡組，`今天` 對不到）。
4. 剩下的用空白切成字，先把 `L 1` 併成 `L1`（字母最多兩個）、拿掉編號前的 `單元`。第一個字一定是科目的一部分；從第二個字往後找**第一個像編號的字**：`2`、`2-1`、`L1`、`L1-2`、`第2章`、`第1章第3節`。
   - 找到：前面是**科目**，它是**編號**，後面是名稱，名稱不看。但名稱裡有同一類的編號或年級學期就算看不懂（`2-1 2-2`、`L1 L2`、`2-1 國二上`），不同類的可以（`2-1 CO2 的性質`、`L1 Unit 2`）。
   - 沒找到：最後一個字是編號（`Starter`、`2-`），其他是科目。這種編號不能帶名稱。
   - 少於兩個字：算看不懂。

| 這一行 | 年級學期／科目／編號 |
|---|---|
| `- 國二上 自然 2` | 國二上／自然／2 |
| `國二上 Social Studies L1` | 國二上／Social Studies／L1 |
| `國二上 Social Studies Starter` | 國二上／Social Studies／Starter |
| `八上 Math2 L 1` | 國二上／Math2／L1 |
| `國二 上 自然 第1章第3節` | 國二上／自然／1-3 |
| `國二上 自然 2-2 水溶液`、`國二上 自然 2-2 CO2 的性質` | 國二上／自然／2-2 |
| `B2 自然 2-1` | B2／自然／2-1 |
| `今天 自然 2`、`國二上 英文 Unit 1`、`國二上 英文 Starter 開學` | 讀得懂，對不到卡組就列「對不到」，不會算成別的單元 |
| `自然 2-1`、`老師說第三節不考` | 看不懂 |
| `國二上 自然 2-1、2-2`、`2-1, 2-2`、`2-1 ～ 2-3`、`2到3`、`國二上 英文 Unit 1～Unit 3`、`國二上 自然 2-1 水溶液、2-2 酸鹼`、`國二上 自然 2-1 國二下 自然 2-2` | 看不懂 |

**比對**（層級照編號，D-033）：同一學期同一科，`key === code`，或 `key` 以 `code-` 開頭而且後面每一段都不是空的。學期用 `termKey`（認不得的再去雜訊），科目去雜訊、不分大小寫，編號用 `codeKey`；`src/core/catalog` 目錄本身的分組不變。

| 這一行 | 算哪些單元（同一學期同一科） | 不算 |
|---|---|---|
| `國二上 自然 2` | `2`、`2-1`、`2-1-3`（第 2 章全部） | `20-1`、`1-2`、`2-`、`2--1` |
| `國二上 自然 2-1` | `2-1`、`2-1-3` | `2-2`、`2-10` |
| `國二上 英文 L1` | `L1`、`L1-2`、`L1-2-3` | `L10`、`L2`、`L01` |
| `國二上 英文 Starter` | `Starter`、`Starter-2` | `Starter2` |
| `國二上 自然 2-`（卡組真的這樣寫） | `2-` | `2`、`2-1` |

- D-033 的「L1 只有一層」是說課本通常沒有下一層；真的寫了 `L1-2`，它就是 `L1` 底下的。
- 編號不統一成數字（D-176 第 7 點）：卡組寫 `L1`，這裡就寫 `L1`。
- 打字雜訊不影響（全形、多的空白、最後的逗號）。
- **不符合這個格式的不算範圍**：不拆、不猜，整行留著、列出來，設定畫面教「一行只寫一個編號」（D-170 第 1 點）。
- **分類**（`分類：醫學`）另外認得，不生效，畫面寫「這一行目前不支援」；整份只有分類時不能顯示設定成功（D-142 第 6 點）。
- 對不到卡組的單元留著（D-033 邊用邊長），目標寫到它時照樣算在範圍內；入口與目錄要寫行數（§2-6）。

### 2-2 考試期間

讀屬性的值，不用檔名。日期認得 `2026-10-28`、`2026/10/28`、`2026.10.28`、`20261028`、`2026-1-5`、全形（D-176 第 8 點）。不存在的日期（`2026-02-30`）、缺年份（`10/28`）、民國年（`115/10/28`）算看不懂，不猜。

`readDate` 收 YAML 讀出來的值（Codex F3b 實測）：字串照上面讀；數字只收整數，轉成字串再讀（裸寫的 `20261028` 是數字）；`null`（`考試結束:` 空著）算沒寫；布林、清單、明寫 `!!timestamp` 的 Date 算看不懂。

| `考試開始` | `考試結束` | 結果 |
|---|---|---|
| 沒寫 | 沒寫 | 日期未定：生效，不提高保持率，不會自動失效（D-098） |
| 有 | 沒寫 | 一天 |
| 有 | 不早於開始 | 這段期間 |
| 沒寫 | 有 | 一天，就是結束那天 |
| 有 | 早於開始；或任一邊看不懂 | **日期有問題**：範圍照算，不提高保持率；入口與目錄那一列寫「考試日期有問題」，不寫「日期未定」，不會默默變成永遠生效卻沒人發現（環節 7 原則 4） |

- 生效：沒有 `提前結束`，而且沒有期間，或今天（清晨 4 點換日）不晚於結束日；開始日還沒到也生效，填了期間當下就提高（D-078）。
- **提前結束立刻失效**（使用者 2026-11-04，修改 D-105 的「把結束日改成今天」）：屬性多一行 `提前結束: 2026-11-04`（按下去那天的日期），`考試開始`、`考試結束` 不動。有這一行就不生效，不等 4 點，今天的份當場重排。日期看不懂也算結束：這一行只有按下去才會出現，不會憑空變成永遠生效。還沒開始的考試不用改開始日，也就沒有「結束早於開始」的問題；考試原本的日期留著給回測。D-098 不寫狀態欄位的理由是外掛換日時要改檔、兩台各改一次會產生衝突副本，這一行只在使用者按下去時寫一次，所以不衝突。
- `提前結束` 寫的是**複習日**（清晨 4 點換日），和其他日期同一種算法：11/04 凌晨 2 點按下去寫 11/03；紀錄行的 `t` 才是實際的時刻。
- 今天用 `dayOf(now, offset)`；日期換成同一種日編號比較，`contains` 裡不另外讀時鐘（環節 4 第 3 題）。
- **屬性區壞了**（YAML 讀不出來、重複的鍵、最上層不是對照表、只有開頭的 `---`）：日期都算「日期有問題」；原文裡有 `提前結束` 四個字就算結束（和 syntax §2-1 的「需要版本」同一種做法，寧可多擋），不會因為壞了就復活；`識別碼` 那一行還在就照用，同一個識別碼的舊副本一起結束（Codex L2 的 R7）。alias 接不上或繞圈也算讀不出來，只影響這一份。有結束的 `---` 時底下的行照讀；沒有結束就全部算屬性區，沒有範圍行。外掛不寫這種檔（§2-4）。

### 2-3 一次只有一份

照這個順序（Codex F4）：

1. **先按識別碼分組**：同一個識別碼的檔是同一次考試。其中任一份有 `提前結束`，整組都結束：A 已按結束、B 是還沒同步的舊副本時，B 不會讓考試復活（D-176 第 4 點）。
2. **沒有識別碼的檔**（沒有這個屬性或空白）各自算一次考試，用路徑區分，不併；下次由外掛寫入時補上。識別碼是任何非空白的字，只要穩定，不檢查字母表；照寫的字讀，`2e2345`、`012345` 不當成數字，屬性區壞了也用同一種讀法（Codex L2 的 R15）；外掛建立時 6 個字元、和學習目標 ID 同一個字母表、避開已知的，之後不變（D-115）。
3. **候選**：還生效（§2-2），而且至少有一行讀得懂（含對不到卡組的）。只有看不懂的行、只有分類或空的檔不算候選，不會蓋過另一份真的範圍。
4. **選一份**：有效期間的開始日早的先（只寫結束日的用結束日）；沒有期間、日期有問題的排在後面；都一樣時比路徑（字串比較，不看語系）。同一個識別碼的衝突副本也這樣選，紀錄裡是同一次考試。設定畫面寫「還有另一份也生效」與路徑（D-098）。
5. **結束一份之後**，另一個識別碼的那一份還生效就換它接手：今天的份照它排，不是回到平常；沒有另一份才回到平常。
6. 沒有候選、但有還生效的檔（只有看不懂的行）：`exam()` 回傳那一份，入口與目錄寫行數；排程當成沒有範圍，不提高保持率。

- 改名不影響：身分是識別碼，比對不看路徑。只有路徑變、選到的還是同一份時不重排；改名讓平手的另一份贏了，內容不同就重排（§4 比的是選定的結果，A2 見 §9）。
- **限制**：已結束的副本被刪掉、舊副本還在時，舊副本會生效。紀錄行有這次結束，但排程不讀變更（syntax §5）；第一次碰到再處理。已結束的副本屬性區壞到連 `識別碼` 那一行都不見時也一樣：不知道它是哪一次考試，只有它自己結束，不擋別的（擋了新的考試會默默不算）。

### 2-4 外掛怎麼寫

- 新檔的檔名：考試開始日加年級學期（`2026-10-28 國二上.md`），沒有期間是 `日期未定 國二上.md`。年級學期取勾選單元裡最新的那個（設定頁的「目前學期」還沒做）；不認得的學期不放進檔名。之後補日期不改名（D-142 第 1 點）。
- **撞名不蓋掉**（Codex F5c）：`Files.modify` 的回呼看到已有內容就原樣回傳（不寫），換下一個後綴（`… 2.md`）。不存在與 0 位元組的空檔回呼分不出來，都寫進去：空檔沒有內容可丟，接受。同名的是資料夾、或建立時別人先建好（`vault.create` 拒絕），都算寫入失敗，畫面寫原因，再按一次就看得到內容、換後綴。兩台裝置離線各自建同名的，靠 iCloud 留成兩個檔，各有識別碼，照 §2-3 選。
- **一律在回呼裡改最新的內容**（Codex F5b）：畫面只交出變動（`editScope(text, change)`，新勾的、取消的、有改的日期），不拿畫面打開時的舊文字整份蓋回去；家長或同步同時改的別的行留著。
  - 回呼看到空字串（檔被刪、改名或清空）：丟錯，不建立，回 `blocked: 'changed'`，畫面請重新打開（`Files.modify` 對不存在的路徑會建立，所以要在 `edit` 裡丟）。
  - 回呼看到已經有 `提前結束`：不改，回 `blocked: 'changed'`；不會把結束的考試改回生效。
  - **改的是畫面打開的那一次考試**（Codex L2 的 R3）：畫面交出變動時連同打開時的路徑與識別碼。輪到它寫時選定的已經換了（前一筆結束讓另一份接手、被刪、改名、新建），或回呼看到的識別碼不同（同步把另一次考試換到同一個路徑，state 還沒讀到）：不寫不記，回 `blocked: 'changed'`，畫面請重新打開。識別碼相同就是同一次考試，別人改的別的行照 §2-4 留著。打開時沒有識別碼、現在有了，分不出是不是同一次，也回 `changed`：重新打開就好，沒有東西會丟。
  - 屬性區壞了（§2-2）：不寫，回 `blocked: 'broken'`，畫面請先修好。
  - 讀回來不是要的結果（只有這次要改的日期、識別碼與結束可以變，別的屬性都要在、值都要一樣）：同樣回 `blocked: 'broken'`。一行一行的改法碰到清單以外的寫法（`{識別碼: x, 考試開始: 2026-10-28}`、`|`）可能帶走別的屬性；這種寫法不多寫一種改法（Codex L2 的 R2）。畫面的字寫「寫壞了，或不是一行一個屬性」。
- **改舊檔**：只改屬性裡那幾個值與有變動的那幾行，其他字一字不動；換行照檔案原本的（CRLF、結尾沒換行都留著），屬性的值照 YAML 的位置換，註解、別的屬性與引號不動。
  - 取消勾選：刪掉這個編號的行與它底下的行（別名與重複的行一起）。
  - 新勾：加一行；已經被別的行包含就不加。位置在同一科最後一行後面，這一科沒有行就加在最後。
  - 勾「2 全部」：被 `2` 包含的行（含手寫名稱、沒有卡組的 `2-9`）換成一行 `2`，放在第一個被換掉的位置。名稱不影響範圍，`2` 也包含 `2-9`，所以沒有少算。
  - 整章裡取消一個（`2` 取消 `2-2`）：`2` 這一行換成「目前有卡組、在 `2` 底下、不是 `2-2` 也不包含 `2-2` 的單元」，一行一個、照目錄順序，只留最上層的；已經存在的明寫行（`2-9 老師手寫`）留著。結果是：之後才建立的 `2-4` 不再自動算進去（要自己勾，入口會寫「不在範圍內」）；`2` 自己的卡組也不算了，因為這個格式寫不出「只考它自己」（§6，目前沒有這種教材）。沒有取消的單元要是因為這樣掉出範圍（`2-9,3` 一行寫不出來，§2-1），不寫，回 `blocked: 'special'` 與單元編號，畫面寫出來：留著整章，或連它一起取消（Codex L2 的 R6；這個格式不多一種引號）。
  - 看不懂的行、分類行、沒被動到的手寫名稱留著。
  - 讀回來和要寫的不一樣的單元（科目裡有像編號的字，例如 `社會 2 班`；年級學期有空白）不能用勾選加入，那一列灰掉並說明。這個格式不多一種引號（D-153）。
- **日期**：畫面改了的寫新值；畫面沒改的用回呼裡現在的值，讀得懂就寫成 `YYYY-MM-DD`，值沒變、只是寫法不同也一樣；讀不懂的留原字；清空就刪掉那一行。畫面改了日期，套到最新的內容上才變成開始晚於結束（別台改了另一邊，畫面看不到）：不寫，回 `blocked: 'dates'`，畫面請重新打開（R8）；畫面沒改日期時，家長原本的值照舊留著，寫「考試日期有問題」。手改的 `20261028` 讀到時不自動改寫，留到下次按「確定」：讀到就寫會多一條寫入路徑，兩台裝置各寫一次會產生衝突副本（D-098、D-164 第 6 點）。
- **識別碼**：第一次由外掛寫入時補在屬性區最前面；沒有屬性區就建一個。
- 第一次按「確定」就寫進檔；讀不到或還在讀時不寫（§4），畫面說明。iPhone 可以寫（D-142 第 4 點）：這個檔不含學習目標 ID，也不經過卡組的寫入門檻。
- 存完立刻把這份文字當成現在的內容、重排；之後檔案通知讀到同一份不再重排。

### 2-6 家長直接改檔（D-176）

平常不用改：設定畫面就能勾。真的打開來改時，存檔後約半秒重讀，不用重開，也不用學格式：

| 怎麼改 | 結果 |
|---|---|
| 改日期、刪掉 `考試結束` | 倒數跟著變；只剩開始日就是一天 |
| 日期換一種寫法（`20261028`、`2026.10.28`） | 照讀；檔案裡的字等下次按「確定」才變成 `2026-10-28`（§2-4） |
| 日期打錯（`2026-13-01`、`10/28`）、結束早於開始 | 範圍照算，不提高保持率；入口與目錄寫「考試日期有問題」 |
| 新增一行（`- 國二上 自然 2-4`、整章 `- 國二上 自然 2`） | 照新的算；全形、`第2章`、少打 `- `、後面多寫名稱（`2-2 水溶液`）都一樣 |
| 一行寫好幾個（`2-1、2-2`）、區間（`2-1～2-3`） | 不拆不猜，這一行不算；入口與目錄寫「有 1 行看不懂」，設定畫面教「一行只寫一個編號」 |
| 少寫年級學期（`自然 2-1`） | 不猜，這一行不算；入口與目錄寫「有 1 行看不懂」 |
| 單元、科目或學期對不到任何卡組（`英文 1`，卡組寫 `L1`；卡組寫「自然」，這裡寫「理化」） | 這一行留著，目標寫到它時照算；入口與目錄寫「有 1 行對不到卡組」 |
| 寫一句話（`老師說第三節不考`） | 不算範圍，留著，算一行看不懂 |
| 分類行（`分類：醫學`） | 不生效，設定畫面寫「這一行目前不支援」（D-142 第 6 點） |
| 刪掉一行、刪掉整個檔 | 那些單元不再優先；刪檔就是沒有範圍 |
| 改檔名、搬到子資料夾 | 沒有影響 |
| 複製一份 | 識別碼相同，算同一次考試：兩份都生效時用一份（§2-3），設定畫面寫「還有另一份也生效」 |
| 複製已結束的那一份、刪掉 `提前結束` 當新的考試 | 識別碼相同還是算結束；把 `識別碼` 那一行也刪掉就是新的一份 |
| 屬性區寫壞（少一個 `---`、重複的鍵） | 寫「考試日期有問題」；設定畫面不寫入，請先修好（§2-2） |
| 手改之後又用設定畫面 | 手寫的整章、名稱與看不懂的行照 §2-4 留著；只有勾選改到的那幾行變動 |

入口與目錄的「考試範圍與日期」那一列都看得到行數，所以手改壞了不用打開設定畫面才知道；點進去看哪幾行。還不確定的出處（§8）照舊只在設定畫面。

**驗收**：上表每一列一個例子，預期值寫死；每個例子套打字雜訊意思不變；「看不懂」與「對不到」的行數在入口與目錄的元件測試各驗一次；手改的存檔經檔案通知觸發重排。

**驗收**：往返與冪等照共用範例（`tests/exam-scope.test.ts` 的 `scopeCases`，和 `deckCases` 同一種做法），三條路分開驗（Codex F5b）：`讀 → 不改 → 寫` 一個位元組都不變，沒有識別碼的也一樣；第一次按「確定」才補識別碼、標準化日期，第二次同樣操作完全不變，也不多通知、不多記紀錄；只動確定要改的值與行。例子含 CRLF、結尾沒換行、BOM、YAML 註解、別的屬性、空屬性、引號、清單外有字、壞的屬性區。

整章與單元互換用同一份 fixture（父節有卡組、別名與重複的行、深一層的 `2-1-3`、沒有卡組的手寫 `2-9`、帶名稱的行、分類行、看不懂的行），每一行的原文與實際涵蓋的單元都寫死：勾「2 全部」、整章裡取消一個、取消的單元底下還有一層。回呼看到空字串、看到 `提前結束`、屬性區壞了各一例（不寫、不建立）。撞名：舊檔內容不變、換後綴；空檔寫進去。`Files` 的回呼丟錯時不建立檔案，Node 版用測試、Obsidian 版在 §10 實機驗。

### 2-5 紀錄行（syntax §5、D-115 第 3 點）

```jsonl
{"t":"2026-10-20T19:00:00.120+08:00","set":"exam","val":{"id":"x7f3k2","do":"建立","units":["國二上 自然 2","國二上 英文 L1"],"start":"2026-10-28","end":"2026-10-29"}}
{"t":"2026-10-22T19:00:00.120+08:00","set":"exam","val":{"id":"x7f3k2","do":"改","units":["國二上 自然 2","國二上 英文 L1","國二上 英文 L2"],"start":"2026-10-28","end":"2026-10-29","old":{"id":"x7f3k2","units":["國二上 自然 2","國二上 英文 L1"],"start":"2026-10-28","end":"2026-10-29"}}}
{"t":"2026-10-24T19:00:00.120+08:00","set":"exam","val":{"id":"x7f3k2","do":"提前結束","units":["國二上 自然 2","國二上 英文 L1","國二上 英文 L2"],"start":"2026-10-28","end":"2026-10-29","ended":"2026-10-24"}}
```

- `units` 是寫完之後讀得懂的每一行，照檔案的順序，只留年級學期、科目、編號；整章就記 `國二上 自然 2`，不展開。
- `start`、`end` 是寫完之後的 `YYYY-MM-DD`；沒寫就沒有這個欄位。
- `old` 是這次寫入之前回呼裡實際的內容（`建立`、`提前結束` 沒有）：沒寫的日期沒有欄位，看不懂的日期照原字，原本沒有識別碼就沒有 `id`（Codex F6b）。第一次改手寫的檔時，`old` 就是回測能拿到的基準。
- **有變動才記**：比寫入前後的識別碼、單元、日期與結束。補識別碼算（`do: 改`）；只有日期的寫法變了不算。按確定但什麼都沒變，不寫檔、不記。
- 舊版讀得懂（Codex F6a 實測 0.1.0～0.3.0）：`parseLine` 收任何 `set` 只要有 `val`（`src/core/study/entries.ts:27`），放進 `changes`，不影響排程。沒有頂層的 `lt`、`deck`、`undo`，不帶 `need`：帶了舊版會把紀錄算成 `incomplete`。`NewEntry` 多這一種。
- 只記外掛自己的寫入；家長直接改檔不記（小選擇 1）。
- 範圍寫成、紀錄寫不進去時，範圍照舊生效，錯誤照現有的 `onError('write')`；再按一次「確定」沒有變動，不重寫也不重記。
- 等寫入逾時（Codex L2 的 R5）：等待結束、底層取消不了。回呼還沒進入的，之後進入時丟錯，不會寫，畫面寫「這次沒有存」，重試照常；回呼已經進入的可能等一下才寫成，畫面寫「可能等一下才寫好；請重新打開這個畫面確認」，真的寫成了才記這一行、重讀一次，寫不進去就不記。`close()` 等還在寫的範圍有結果才算關好（最多 `writeTimeout`），寫成的紀錄跟著寫進去（Codex L2 的 R14）；關好之後才寫成的不記（關閉之後不寫檔；檔案本身就是結果）。
- D-115 第一次設定與狀態的基準另有範圍，這三種行不算完成那一項。
- **考試開始那天的卡組切面（D-115 第 4 組）這批不做**（使用者 2026-11-04）：記進 backlog 技術債，觸發點是真實使用驗證開始前，漏了補不回來；識別碼與紀錄行這批先留好，之後切面對得上。

## 3. 模組與介面

## 4. 重排與讀不到（環節 7 原則 3、4）

| 情況 | 結果 |
|---|---|
| 範圍檔新增、修改、刪除、重試成功 | 重新選（§2-3），比選定的結果：身分、單元、期間、生效變了才重排一次；只有看不懂的行數或另一份的路徑變了，只通知畫面、不重排；讀到同一份完全不通知 |
| 卡組或出處變了 | 照現有的 `replan`，`contains` 用新的歸屬：範圍檔沒變，目標改了出處也會進範圍 |
| 換日、換時區 | 照現有的 `fresh()` 重排，生效與否用同一個時間重算；結束日的下一個 4 點失效。入口或設定畫面開著跨過 4 點，畫面每分鐘看一次日編號，自己換成新的一天（Codex L2 的 R9）；按「確定」時的通知用當下的日子 |
| 第一次載入 | `ready()` 最多等範圍檔 2 秒，正常情況第一次就排對；沒回來照下一列，`ready()` 不被卡住 |
| 第一次載入讀不到（或還沒回來） | 「不知道」：今天的份當成沒有範圍，入口那一列寫「考試範圍暫時讀不到」，不寫「還沒設定」；`setExam` 回 blocked；讀到後重排。代價：這段時間考前優先的卡可能被一般卡擠掉，已答的還是算數，漏掉的優先順序補不回來；比進不了複習好 |
| 一份讀到、另一份從沒讀到（讀失敗，或一直沒回來） | 用讀到的，是暫定的；入口那一列多寫「有 1 份暫時讀不到」；另一份讀到後重新選（它可能是更早的考試）。`setExam` 回 blocked。範圍檔一份一份讀、讀到就用（`alone`，Codex L2 的 R4）：卡住的那份不擋別份，也不擋之後的通知；同一份一次讀一個，讀的期間又有通知就讀完再讀一次 |
| 通知到了、那一份還沒讀完（還在排或正在讀，還不算讀不到） | `setExam`、`endExam` 先讀完才決定寫哪一份，最多等 2 秒（和卡組寫入前先讀完待讀同一個規則）。讀到更早的考試回 `blocked: 'changed'`；讀不到或還沒回來回 `blocked: 'unread'`；都不寫不記。卡組的寫入不擋（Codex L2 的 R13） |
| 讀過又讀不到 | 沿用上次讀到的；跨日照樣重新判斷生效 |
| 確定刪除（讀到 null；列不出來或列表裡少了都不算） | 沒有這份了，重新選 |
| 範圍檔讀不到 | 算進 `unread()` 與提醒，**不擋卡組的寫入**（D-134 的理由是不知道 ID 用過沒，範圍檔沒有 ID）：`writes` 與 `tracker` 只看卡組與紀錄那一份（§3） |

## 8. 用到的時候才檢查（D-170 第 11 點）

設定畫面的勾選下面，隨著勾選即時算（`catalog` 的純函式，不寫檔），寫成兩行，可以點開：

- **這次範圍裡有 N 個目標來自別的單元**：目標屬於範圍內的單元，但它自己的單元不在範圍內。列名稱與「來自小四上 2-1」。
- **M 個出處還不確定**：同一個學習目標只算一次，列整欄的原文與原因（Codex F8）：
  1. `可能多算`：這個目標只靠沿用學期的參照（`basis: carried`）落在範圍內：拿掉它們就不在範圍內了，例如 `國二上 1-3, 10-15 p.44`。自己的單元或明寫的參照已經在範圍內時不算，那個參照不影響這次考什麼。
  2. `可能打錯`：這份範圍寫到的學期與科目裡，明寫但沒有卡組的單元（`國二上 1-9`，第一批 §9-5 留到這裡）。範圍檔的行本身對不到卡組不算這裡，那是 §2-6 的行數。
  3. `可能少算`：這份範圍寫到的科目裡，`missed` 的出處（`小五上 p.15`、`1-3 p.20`）。

每一列寫 `第 12 行〈溫度影響溶解度〉：1-3 p.20（可能少算）`，點了入口關掉、打開那篇到那一行（第四批後改成小表單）；iPhone 只看得到，改要到電腦（D-134）。超過 20 列寫「另有 N 個」，總數還是實際的數字。沒有就不顯示。不擋「確定」，還不確定的照現有讀法算（D-170 第 1 點）。

字面判斷的界線，不用目錄或材料反過來改歸屬：`1-3` 其實是舊標題時會多列一筆；寫到一個對得到卡組的錯編號時沒有提示；本篇沒有科目的目標不列，它在電腦上的存檔按鈕照舊提示；`小五上 p.15` 在只有國二上的範圍裡也會列，同一科就列，不再看學期。

**驗收**（寫死的卡組與預期）：上面三種各一例，加反例：`國二上 1-3 p.20` 明寫的不算還不確定；同一個目標同時有明寫與沿用的參照落在範圍內不算第 1 種；自己的單元在範圍內也不算第 1 種；範圍外的科目不列；普通舊標題、`p.46-44`、本篇明示、否定段不列；同一個目標寫了三種還不確定只算一次、原因都寫；`p.44 及 1-8 p.45` 的原文看得到 `1-8`；勾選改變時數字跟著變；超過 20 列時總數正確。
