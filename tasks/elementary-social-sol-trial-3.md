# 國小社會預設 v0.6：用 Sol 跑 2-2，測跨單元加題（混入自製的已有目標）

狀態：已完成（2026-11-03）；評分由專案討論串「制定國小社會學習目標地圖」的 Claude 做

遵守 repo 根目錄的 `AGENTS.md`。執行者：使用者電腦上的 Claude，建議 Opus、推理等級 high。評分不在這份任務裡，由專案討論串「制定國小社會學習目標地圖」的 Claude 做。

## 為什麼做

[上一次](elementary-social-sol-trial-2.md)（v0.5）2-2 帶著 2-1 的 42 個目標跑，加題 0 題，但測不出 Sol 會不會加題：兩課沒有同一個判準，而且送出的提示裡沒有「加進已有的學習目標」的寫法（[試用紀錄](../docs/card-rules/trials.md) 2026-11-03 v0.5 那一列）。預設 v0.6 補上了寫法，也要求全貌寫出和已有目標的比對（〈和學生已有的目標比對〉）。這次在清單裡混進幾項為了測試寫的「之前學期」目標，讓判準相同、相近、說不準的情形一定出現，看 Sol 分得對不對。預期結果在評分的討論串封存，不給你，也不給 Sol。

不做的話，D-139 最核心的「換一個地方用同一個道理就加題」只有 Claude 自己製卡的一次證據，開放後才知道 Sol 會不會漏加或誤合併。
