# 學習目標架構第二輪：教材轉錄（給 Codex）

遵守 repo 根目錄的 `AGENTS.md`。

依 [D-127](../docs/decisions.md#d-127-學習目標架構第二輪sol-high第-1-章先跑-1-3) 第 4 點：第二輪只比製卡，轉錄由你直接看教師備課用書的原頁完成，**不呼叫任何付費 API**。做好的教材之後給 R0～R3、S0 五組共用，Claude 核對後凍結。

## 必讀範圍與基準

- [D-127](../docs/decisions.md#d-127-學習目標架構第二輪sol-high第-1-章先跑-1-3)，以及討論稿的 [Claude 審查](<../Claude Codex Discussion/2026-10-21-learning-objective-architecture.md#claude-審查2026-10-23>)。
- 轉錄規則：`experiments/t4/prompts/transcribe.md`（照它的規則寫，只是由你自己看頁面，不送 API）。
- 格式範本：第一輪的 `材料/2-1/教材.md`、`材料/2-1/圖/`（你知道位置）；正式格式由 `experiments/t4/to-formal.mjs` 轉出，見 `docs/syntax.md` §1。
- 第一輪發現的問題：[第一輪結果 §6](<../Claude Codex Discussion/2026-10-21-learning-objective-architecture.md#6-教材輸入的發現和選哪個模型無關>)：2-2 把「給學生」欄標成教師註記。
- 基準 commit：寫這份說明時的 `main`（見 commit 紀錄）。

## 限制

- 不呼叫付費 API，不花錢。
- 教材、圖、轉錄稿只寫進實驗資料夾（repo 外，路徑見交接訊息），不進 repo；學校名稱、學生姓名不寫進 repo。
- **第一輪的檔案一律不動**（`材料/`、`生成/`、`盲評/`、`評分/`、`考題/`）。第二輪的產物放在實驗資料夾的 `第二輪/材料/<節>/`。
- 轉錄時不看考題與標註，照課本本身決定內容，不因為考題而挑重點或補字。
- `experiments/t4/prompts/`、`experiments/t4/arch/` 是 Claude 維護的，只讀不改。
- 原則上不用改程式。若要改（例如讓裁圖或 `to-formal.mjs` 吃你手寫的轉錄稿），在分支 `arch-r2` 上做，本機用 `git worktree add ../Essence-Cards-arch-r2 arch-r2` 開在旁邊，**不要在原資料夾切換分支**；commit 時 pre-commit hook 會跑 `npm run check`，沒通過就修到通過。

## 要做什麼

### 1. 轉錄 1-3〈體積與密度〉

- 範圍：教師備課用書中 1-3 的全部頁面，從節標題頁到下一節開始前。在回報寫出 PDF 頁序範圍。
- 照 `transcribe.md` 的規則逐頁轉錄，以頁面圖片為準；PDF 文字層有亂碼或重複片段時照可見的原頁，不把文字層的重複當成新內容。
- **「給學生」與「教師註記」照頁面判斷**：印給學生看的正文、側欄、補充、例題放正文或對應的 callout；給老師的教學提示、答案、頁邊註記才放 `> [!教師註記]`。分不清的，照最可能的一邊放，並列進 `檢查.md`。
- 圖：照 `transcribe.md` 第 4 點標出內容相關的圖並裁成圖檔；逐張打開裁好的圖確認有包含圖說與圖上文字、沒切到旁邊的正文。純裝飾的圖不標。
- 用 `to-formal.mjs` 轉成正式格式，圖檔名前綴「國二上自然 1-3」。
- 產出 `第二輪/材料/1-3/`：`教材.md`、`圖/`、`檢查.md`。

### 2. 修正 2-1、2-2 的欄位標記

- 把第一輪的 `材料/2-1/`、`材料/2-2/` 複製到 `第二輪/材料/2-1/`、`第二輪/材料/2-2/`，只在複本上改。
- 照原頁逐頁核對「給學生」與「教師註記」的歸屬，改正誤標；核對時順手看到的漏字、錯字、漏圖也改。
- 不改寫、不重排其他內容；每一處修改列進該節的 `修正紀錄.md`（頁碼、原本、改成、理由）。

### 3. `檢查.md`（1-3）

列出：看不清楚的字（`[?]`）、「給學生／教師註記」拿不準的段落、沒標的圖與理由、加了 `[AI 補充]` 的地方。沒有就寫「無」。

## 自我檢查

- 1-3 範圍內每一頁都有頁碼行（`p.xx ^pxx`），沒有跳頁。
- `教材.md` 裡引用的每一張圖在 `圖/` 都找得到，`圖/` 裡沒有沒被引用的圖。
- 隨機抽 1-3 的三頁、2-1 與 2-2 各兩頁，對照原頁再看一次欄位歸屬。
- 第一輪的資料夾沒有任何檔案的修改時間改變。
- 有改程式時：`npm run check` 通過。
