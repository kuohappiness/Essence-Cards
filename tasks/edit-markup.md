## 和「不做」比較（D-153）

- **不做會怎樣**：
  - D-089 第 10 條的「編輯畫面標出問題」一直沒做，寫錯的目標只能靠存檔按鈕的數字發現，長筆記要自己找。
  - 目標那一行被按了 Tab，它和底下的題目就默默不出題（[技術債](../docs/backlog.md#技術債)〈目標那一行被按 Tab〉），編輯時完全看不出來。
  - 看不懂的出處只有存檔按鈕的提示；跨單元的出處要家長自己照規則打字。第二批的考試範圍靠出處算單元，寫錯就會少算。
  - 正式版要等第四批合併才升 `0.4.0`（[roadmap](../docs/roadmap.md#現在在哪裡)），考試範圍、小考、點選填空都還到不了學生手上。
- **做的代價**：
  - 編輯器多一層樣式，每次改字都要重新解析一次，要量速度（§1-5）。
  - 一個會改寫筆記的表單：要往返測試、格式查核與 L2。
  - 解析的結果多記原文位置，`sources.ts` 的讀法要多帶一份位置（§3），讀法本身不變。
- **怎麼解決**：解析延遲到停止打字之後；寫回前先重新解析新的字，意思不同就不寫（§4-3）；一次寫入是一個交易，`Ctrl+Z` 一次復原。

## 1. 結構標示（D-047）

只在電腦版的編輯器（即時預覽與原始碼模式），只在卡組筆記（和 ID 鎖定同一個判斷，`src/main.ts` 的 `lockable`）。閱讀模式、iPhone、一般筆記不顯示。草稿也顯示：家長正在做卡的時候就是草稿。

### 1-1 標示什麼

照樣式稿。顏色用 Obsidian 的 CSS 變數，跟著使用者的主題。

| 對象 | 怎麼標 | 判斷 |
|---|---|---|
| 學習目標那一行 | 左邊一條 2px 細線，`--interactive-accent`，不透明度約 0.45；在清單圓點的左邊，不推動文字 | `parseDeck` 的 `targets`（有題目才算目標，D-079）。直接寫成題目的目標（`- Q :: A`）也算 |
| 題目的 `::` | 那兩個字變 `--text-accent`，不透明度約 0.6 | 每個 `qa` 題目第一行的 `::`（`questionSyntax` 的位置）。填空照 Obsidian 的螢光筆，不另外加 |
| `error` 的問題 | 紅色波浪底線（`--text-error`） | `problems` 裡 `level: 'error'` 的；這一題不會出 |
| `hint` 的問題 | 橘色波浪底線（`--text-warning`） | `level: 'hint'` 的；照常出題。不標 `misplaced-id`（存檔時自動移回，家長不用做事）與屬性區的問題（即時預覽的屬性是 Obsidian 的表格，標不上；存檔按鈕已經提示） |
| 看不懂的出處 | 橘色波浪底線，滑過時底色微微變橘、游標變手指；點了打開 §4 的表單 | `unreadableSources`（§9-5 的判斷不變），範圍是那一項的原文（§3） |

- **底線的範圍**：問題有欄位的位置時（§1-2）只畫那一段；沒有時畫那一行的內容，不含清單符號與行尾的 ID。
- **滑過的說明**：用 Obsidian 的 tooltip（`aria-label`），內容是問題的 `message`；看不懂的出處照 §1-3 的句子。實作時在 Obsidian 確認會顯示，不行再改成自己畫。
- 縮排錯一層（目標被按 Tab）不另外提示：細線、淡紫與波浪線一起消失，ID 也不再上鎖、露出 `^xxxx`，樣式稿第三張就是這個樣子。要不要另外提示照技術債那一列的觸發點，這批不動。

### 1-2 問題多記欄位的位置

`unknown-field-value`、`duplicate-field`、`unknown-field` 是資料欄位那一行的其中一段（`重要性：很高`）。`Problem` 多一個選填的 `columns: { from: number; to: number }`（那一行原文的位置，從 0 算），只有這三種會填，範圍是那一段的值（`很高`）；`unknown-field` 是整段。其他問題不填，畫整行。

### 1-3 看不懂的出處的說明

`unreadableSources` 多回傳原因（§9-5 已經在判斷，只是沒有傳出來），tooltip 照原因寫一句，最後都加「點一下幫你改。」：

| 原因 | 說明 |
|---|---|
| `missed`，原文沒有年級學期（`1-3 p.20`、`L1`） | 沒寫年級學期，不知道是哪一個 1-3（用原文的編號） |
| `problem: 'term-only'` | 寫了年級學期，沒有完整的單元編號 |
| `problem: 'position'` | 頁碼或範圍寫反了，連不到 |
| `problem: 'before'` | 位置前面有一句話，不確定是不是出處 |
| `problem: 'leftover'` | 裡面有像單元編號的字，沒有算進去 |
| `problem: 'negative'` | 有否定的字，外掛不確定意思 |
| `needsUnit` 對不到目錄 | 找不到這個單元 |
| 舊標題在材料裡找不到 | 材料裡找不到這個標題 |
| 單元後面的字不是名稱也不是標題 | 單元後面的字看不懂 |

同一項有好幾個原因時用表上最前面的。`1-3 p.20` 在 `deck` 裡是 `problem: 'before'` 加 `missed`（[§9-3](entry-and-catalog.md#9-3-出處一欄怎麼讀syntax-2-5d-170)），所以第一列排在 `before` 前面；原文有沒有年級學期、編號是什麼，用 §4-1 猜測的同一個函式判斷，不另寫一份。

### 1-4 💡 漏冒號的出處

[backlog](../docs/backlog.md#其他待決) 的 💬「漏冒號的出處」寫著「等編輯畫面標示時一起看」。提案：目標底下開頭是 `出處`、`來源` 接空白（`出處 p.44`），或 `來源：` 的子項目，加一個 `hint`（新的 `ProblemCode` `field-like`，「這一行看起來是出處，要寫成 出處：p.44」），讀法不變（照舊當背面補充）。這會多一種解析的提示，要使用者同意才做；不同意就照舊留在 backlog。

### 1-5 什麼時候更新

- 打開卡組時馬上算；改字之後停 250 ms 沒再改才重新解析整篇，中間的標示跟著改動平移（`DecorationSet.map`）。
- 看不懂的判斷要看材料與目錄：state 的卡組或目錄有變、材料的 `metadataCache` 更新時也重算。材料的快取還沒建好時照 §9-5 不提示。
- **速度**：自編一篇 300 個目標、每個三題的卡組，在這台電腦量一次解析加產生標示的時間，寫進〈結果〉。超過 30 ms 時先停下來想辦法（例如只重新解析改到的那個目標），不把等待拉長。

### 1-6 樣式放哪裡

`src/obsidian/ids.css` 旁邊新開 `markup.css`，class 名稱用 `essence-cards-` 開頭。即時預覽的清單行有自己的縮排與 `text-indent`，細線的位置要在 Obsidian 裡對過（§6-3），不要改到 Obsidian 的清單樣式。

## 2. 表單的入口（D-169 第 5 點、D-170 第 10 點）

1. **點看不懂的出處**：游標照常放到點的位置，同時打開那一項的表單（§4）；焦點留在編輯器，直接打字就照常編輯，改到筆記時表單關掉。`Esc`、點表單外面也關掉。
2. **游標在出處那一行**：主要的選取是空的、而且在某個目標的 `出處` 欄位那一行，或它分行的子項目上時，那一欄的第一行行尾出現一個小圖示（樣式稿的方框加號，`--text-faint`，滑過變 `--text-accent`），`aria-label`「填出處」。點了打開空白的表單，用來加一項。按下去不移動游標（`mousedown` 擋掉預設）。一篇只有一個圖示。
3. **命令「填出處」**（`editorCheckCallback`）：游標在某個目標裡（目標那一行到它的最後一個子項目）才可用。游標在看不懂的出處上時打開那一項的表單，否則打開空白的表單。目標還沒有 `出處` 欄位時，套用後在目標底下的第一個子項目前面加一行 `出處：…`，縮排和第一個子項目相同。

## 3. 出處的原文位置（要格式查核）

[§9-1](entry-and-catalog.md#9-1-模組) 寫著「第四批再加編輯要的原文位置」。讀法不變，只多帶位置。

1. **`listTree` 的 `Item`**：多記每一行文字在原文的位置 `starts: { line: number; column: number }[]`，和 `text.split('\n')` 一一對應（第一行是清單符號之後，接續的行是去掉前面空白之後）。
2. **`parseDeck` 的 `Fields`**：
   - `sourceSpans: ({ line: number; from: number; to: number } | null)[]`，和 `sources` 一一對應，是那一項（頓號切開、去掉前後空白之後）在原文的位置；跨了接續行的是 `null`。
   - `sourceFields: SourceField[]`：這個目標的每一個 `出處` 欄位，照筆記順序。`{ line; key: { from; to }; value: { from; to } | null; joined: boolean; children: number[] }`：欄位那一行、`出處：` 的位置、同一行的值（`出處：` 後面到這一段結束，沒有值是 `null`）、那一行有沒有用 `｜` 接別的欄位、分行的子項目的行號。§4-3 寫回靠它。
3. **`sourceLinks` 的 `SourceItem`**：多一個 `at?: { from: number; to: number }`，是這一項在 `sources.join('、')` 裡的位置（讀的時候本來就是把整欄接起來讀）。範圍是這一項出自的那一段，去掉前後的分隔符號與空白：`p.44, 45` 的第二項 `p.45` 是 `45` 那兩個字；整欄都沒讀到時的那一項是整串。超過 `RAW_CUT_LIMIT` 的、去重後丟掉的不用填。
4. **對到筆記**：Obsidian 層用 `sourceSpans` 把 `at` 換成筆記裡的範圍；跨了兩項的（整串的那一種）每一項各標一段，有 `null` 的整項不標（還是算進存檔按鈕的數字）。
5. **不變的**：`sourceLinks` 的其他欄位、存檔、目錄、考試範圍都不變；現有測試不用改預期值。

驗收（§6-1）：共用範例清單的每一個例子，加上打字雜訊之後也成立：
- 每一個有 `at` 的項目，`at` 在整串裡、不是空的、照順序不重疊；原文就是按鈕文字的，切出來和 `text` 一樣。
- `deckCases` 的每一篇，`sourceSpans` 切出來的原文等於 `sources` 那一項；`sourceFields` 的位置切出來是 `出處`。

## 4. 小表單

照樣式稿：浮在那段文字或圖示的下方，下面放不下就往上開。一列單元、一列以上的位置、一列說明、預覽兩行（會寫成、會算進）、取消與套用。

### 4-1 先填好的內容（猜測）

純函式，放 `src/core/catalog/source-guess.ts`（要看目錄，所以在 catalog；只建議，不改歸屬，D-170 第 2 點）。輸入是那一項（`SourceItem`）、這一篇的屬性、同一科的單元清單（年級學期、編號、名稱）。輸出每一欄的值，並標明來源：**原文**（照實帶進來）、**猜的**（虛線框加「猜的」）、**沒選**。

- **單元的選項**：「這一篇」、候選的單元、「其他單元…」。「其他單元…」展開兩個選單：年級學期（目錄裡同一科有的）與那一學期的單元（顯示編號與名稱）。只列目錄裡有的（D-169 第 5 點）。

| 原文 | 單元 | 其他欄 |
|---|---|---|
| 寫了年級學期與編號，但看不懂（`國二上 1-3 和 1-8`） | 那個單元，**原文** | 位置照原文；說明帶進多出來的字（`和 1-8`） |
| 編號沒寫年級學期（`1-3 p.20`、`L1`） | **沒選**。候選：這一篇的學期加那個編號（目錄裡沒有時寫「還沒有卡組」）、目錄裡同一科同編號的其他學期，這一篇的學期排第一，其他照學期順序。說明「原文沒寫年級學期，請選一個」 | 位置照原文 |
| 短的學期寫法（`二上 2-1 p.15`） | 照這一篇的學制補上（國中的卡組 → `國二上`），**猜的**；這一篇沒有認得的學期時**沒選**，候選列出小、國、高裡目錄有的。說明「原文寫「二上」，猜是國二上」 | 位置照原文 |
| 寫了年級學期、沒寫編號（`小五上 p.15`） | **沒選**，候選列出那一學期目錄裡的單元；是這一篇自己的學期時，「這一篇」排第一 | 位置照原文 |
| 位置前面有一句話（`老師說過 p.44`） | 照原文（沒寫就是「這一篇」） | 位置照原文；說明帶進那句話 |
| 範圍寫反（`p.46-44`）、`p53` 後面接字 | 照原文 | 位置**沒填**，說明「頁碼看不懂，請重新填」 |
| 有否定字、舊標題找不到、猜不出來的 | 「這一篇」 | 都不填；說明照 D-169 第 4 點：「可以這樣寫：p.44、圖 2-14、國二上 1-3 p.20、[[筆記#標題]]；只想記一句話，請寫在「備註」」 |
| 從圖示或命令打開的空白表單 | 「這一篇」，不算猜 | 都不填 |

- `B2`、`第三冊` 要看教材，不猜（D-170 第 10 點只列為可以在表單裡用的寫法；之後有教材資料再加）。
- 有疑問的單元不預先選（D-170 第 10 點）：沒寫年級學期的編號一律算有疑問，就算目錄只有一個候選也不選，因為這一篇自己學期的那個單元可能還沒建卡組（D-170 第 9 點的理由）。

### 4-2 會寫成什麼

純函式，和 §4-1 同一個檔。

- 一項的寫法：`[單元] [位置…] [說明]`，中間一個半形空白。單元是「這一篇」時不寫；別的單元寫 `年級學期 編號`（用目錄顯示的原字）。位置：頁 `p.20`、圖 `圖 2-14`、表 `表 2-1`、例題 `例題 2-3`、筆記連結 `[[筆記#標題]]`（家長打的字沒有括號時補上）。好幾個位置用空白隔開（`國二上 1-3 p.20 p.21`，D-170 第 5 點）。
- 位置的格式：頁是數字；圖、表、例題是數字與連字號，圖可以多一個子圖字母。格式不對時那一格標紅，不能套用。
- 「會算進」：選的單元的 `年級學期 編號 名稱`；「這一篇」寫這一篇的單元。
- 能套用的條件：選了單元、會寫成的字不是空的，而且**用 `sourceLinks` 讀回這一項**（放在它要寫進去的位置、前後照實）得到的單元與位置就是表單上的、沒有 `problem`、不是舊標題。說明裡有像編號或頁碼的字會讀出問題，這時套用不能按，說明「說明裡有像單元或頁碼的字，請改寫，或寫在「備註」」。

### 4-3 寫回筆記（要格式查核）

純函式，放 `src/core/deck/source-edit.ts`：輸入筆記全文、目標那一行、動作（換掉第 i 項／加一項）與 §4-2 的字，輸出要改的範圍（`{ from; to; insert }[]`）。Obsidian 層用一個交易送出（`userEvent: 'input.essence-source'`），`Ctrl+Z` 一次復原。

1. **換掉一項**：換掉那一項的原文範圍（§3）。換成別的單元、後面同一欄還有這一篇的位置時，照寫在原地會讓那些位置改成跟著新單元（D-170 第 6 點），所以把新的這一項搬到這一欄最後（D-164 第 5 點：別的單元後寫）。
2. **加一項**：這一篇的位置加在這一欄最後一個這一篇的項目後面（別的單元之前）；別的單元加在最後。
3. **分行**（使用者 2026-11-06 選定，D-164 第 4 點）：寫完之後這一欄有三項以上（讀回的按鈕數），或裡面有連結，而且現在寫在同一行，就改成分行：`出處：` 單獨一行，底下每一段一行（照現在的頓號、逗號、分號切開的段，一段可能有好幾個位置，例如 `國二上 1-3 p.20 p.21`），子項目的縮排是欄位那一行的內容位置再加四格（這篇已經用 Tab 縮排時用 Tab）。
   - 那一行用 `｜` 接了別的欄位：只把 `出處` 那一段搬出來，其他欄位留在原本那一行；`出處` 原本在最前面時，分行的 `出處：` 放在那一行前面，否則放在後面。
   - 已經分行的照舊分行，加一項就多一個子項目。項目變少不改回同一行。
4. **不寫的情況**：表單照樣打開，套用不能按，寫一句原因：
   - 這個目標有兩個以上的 `出處` 欄位：「這個目標寫了兩處「出處」，先合併成一處」。
   - 那一項的位置是 `null`（跨了接續行）：「這一項分在兩行，請直接改字」。
   - 這篇「需要新版」（syntax §2-1，外掛不寫它）：「這篇需要新版的外掛才能改」。
5. **寫之前核對**：把改動套到全文、重新 `parseDeck`，下面全部成立才送出，否則不寫，表單寫「寫不回去，請直接改字」，並記進錯誤紀錄（新的環節 `where: "edit"`，syntax §9 的表加一格；`msg` 寫哪一項不成立，不寫筆記的內容）：
   - 目標的數量、每個目標的 ID、名稱、題目指紋都不變；別的欄位（類型、重要性、狀態、備註、錯題補強）不變；沒有多出新的問題。
   - 這個目標的出處讀回的每一項（連結、`basis`、`problem`），等於原本的每一項換掉或加上這一項之後的結果；搬到最後的照搬過的順序比。
6. **換行與縮排**：照這篇原本的換行（CRLF 照舊）；新加的行用這篇的縮排字元。

## 5. 不改的

- 檔案格式（syntax）與讀法不變；表單寫的字是 syntax §2-5 本來就有的寫法。
- 存檔按鈕的提示照舊（長筆記沒捲到時靠它，D-164 代價第 5 點）。
- 不自動改寫手寫的出處（D-164 第 6 點）；只有家長按「套用」才寫。
- iPhone、閱讀模式不做。

## 6. 測試與實機

### 6-1 自動測試

預期值寫死，來自這份說明與樣式稿，不用同一個算法再算一次。

- **標示**（`src/obsidian/markup.ts`，和 `lock.ts` 一樣不 import `obsidian`，用 `@codemirror/state` 在 Node 測）：syntax §2-2 的自然例子，目標那幾行、每個 `::` 的位置寫死；同一篇把第二個目標按一次 Tab，那一行沒有目標的標示、它底下的 `::` 也沒有；沒有答案的題目有 `error`；`misplaced-id` 沒有標示；`重要性：很高` 只標 `很高`；看不懂的出處標在原文範圍；改字之後標示跟著平移。
- **原文位置**：§3 的驗收，套到共用範例清單（`tests/sources.test.ts`）與 `deckCases`。
- **猜測與會寫成**：§4-1 表格每一列至少一個例子，加上：`二上` 在國中、國小、沒有學期的卡組；`1-3 p.20` 在國二下的卡組、目錄只有國二上 1-3 時也不預選；位置格式不對不能套用；說明裡有 `1-8` 不能套用。
- **寫回**：每個例子寫死改完的全文，並重新解析核對 §4-3 第 5 點：
  - 同一行換掉一項；換成別的單元、後面還有這一篇的位置 → 搬到最後；
  - 加這一篇的位置在別的單元前面；加別的單元在最後；
  - 變成三項 → 分行；有連結 → 分行；用 `｜` 接別的欄位時只搬出處（出處在最前面、在中間各一個）；已經分行的加一項；
  - Tab 縮排、CRLF、欄位在題目底下（§2-4 的遞迴）、沒有出處欄位時加一行；
  - 兩個出處欄位、跨接續行、需要新版 → 不寫；
  - 套用之後重新打開同一項，不再標成看不懂。
  - 分行之後的幾種寫法加進 `deckCases`，補 ID 與改縮排不能改到它的意思。
- 邊界規則：新檔照現有的模組邊界；`core/catalog/source-guess.ts` 只 import `deck` 的型別與公開函式。
