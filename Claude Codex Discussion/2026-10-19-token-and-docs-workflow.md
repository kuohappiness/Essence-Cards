## 2. 按需讀取與重讀規則

### 2.1 同一議題不反覆載入未變的內容

觀察：[essence-discuss](../.claude/skills/essence-discuss/SKILL.md) 要求「提問前讀決策索引」；[essence-decision](../.claude/skills/essence-decision/SKILL.md) 寫入前又要求查索引。若解讀成每輪都重讀，就會重複帶入約 12,700 字元。

💡 建議的規則文字：

> 每個議題開始時查一次相關決定。同一對話已讀且仍可用的內容直接沿用；文件有變動、上下文不足、出現新問題或規格衝突時，才補讀必要段落。多人並行工作時，必要的變更確認仍保留。

### 2.2 先定位，再讀正文

- 已知 D-ID：直接取該條及其補充、修改、取代條目，不先完整輸出索引。
- 不知道 D-ID：先搜尋索引的相關關鍵字，再讀命中條目。不能只看搜尋摘要就當作完整規格；有關聯或矛盾時擴大查閱。
- roadmap：只讀「現在在哪裡」到下一個二級標題前，保留其中的三級標題與專題入口。
- 資料格式工作：讀 `syntax.md` 的共通規則及相關章節，必要時補讀交叉引用；需要理由或釐清衝突時再追決策紀錄。
- 試作工作：讀共通規則與該任務，不自動讀所有 T1～T7 的詳細紀錄。

先使用現有搜尋與分段讀取工具。若仍經常讀過頭，再評估小型唯讀查詢工具，依章節或 D-ID 回傳正文與必要的後續決定；不必立即拆成一百多個檔案。

### 2.3 精簡固定載入的指令

## 5. 歸檔定義與流程

### 5.1 區分失效規劃與過程紀錄

觀察：[archive README](../docs/archive/README.md) 宣告內容不作目前有效依據，但其中的 [API 討論](../docs/archive/discussions/2026-10-11-api-selection.md) 仍標示進行中。建議明確區分：

- `v0-planning/`：已被取代的規劃，不可照著實作。
- `discussions/` 與試驗歷史：當時的需求、證據與取捨，可追溯，但不直接當現行規格；其中的內容不能一概視為已失效。

既有討論檔可以保留位置，避免大量搬檔與修連結。進行中的未解問題、下一步不能只存在這些紀錄裡，必須能從 backlog／roadmap 找到。

### 5.2 建議的收尾順序

1. **有使用者明確決定才新增 D-ID**；一般測試結果記入試驗紀錄，不自動升格。
2. **更新受影響的現行規範**，不要求每次修改所有核心文件。
3. **未決問題留 backlog，下一步留 roadmap**；設計確認、實作完成與驗證通過分別標示。
4. **有額外取捨脈絡才寫討論摘要**，不重抄整份決定。「重要討論」的門檻應具體，避免每輪都產生多份紀錄。
5. **確認沒有唯一的有效要求或待辦被埋入歷史後，才移出日常入口**。保留來源連結，更新必要索引並檢查連結。

不要用固定「每次對話結束同步所有文件」的流程。觸發條件應是規範、狀態或有保存價值的證據真的改變。

## 6. Claude／Codex 的討論方式與成本

| 方式 | 做法 | 適用情況 |
|---|---|---|
| 使用者轉貼短摘要 | 提案 → Claude 審查 → Codex 整理 | 偶爾討論，設定成本最低 |
| 共用討論檔 | 輪流更新這類議題文件 | 長期交替使用，減少手動搬運背景 |
| Claude Code CLI 橋接 | 程式送出提問、讀取回覆、必要時延續對話 | 確認常有需求後，再評估建置 |

本次環境沒有已連線的 Claude 工具，PATH 也未找到 `claude` 指令；這不代表電腦未安裝。沒有實際傳送內容給 Claude，也未建立橋接。

CLI 官方支援 `claude -p`、結構化回覆與延續對話，但**自動化主要省操作時間，不保證省 token**。一般 CLI 呼叫仍載入專案設定；Claude 產生的回覆又成為 Codex 的輸入，多輪往返還會累積歷史與工具輸出。[來源 4、5](#9-官方參考資料)

💡 建議採「有上限的審查」：

- 每次只送具體提案、必要限制與相關片段，不轉送全部聊天或全專案文件。
- Claude 只指出錯誤、遺漏、不同意之處及理由；Codex 只整理修正與剩餘分歧。
- 預設一次審查；有實質分歧時最多再追問一次，不自動循環直到同意。
- 資訊不足可補讀必要原文；一般議題不自動啟動額外子代理。
- 實際扣訂閱額度或 API 費用，取決於登入與設定；不能把轉到另一種計費方式當作節省總成本。

這次可先讓已熟悉專案的 Claude 對話審查本稿；若該對話已很長，也要考慮歷史上下文成本。哪種較省尚未實測，不承諾節省比例。
