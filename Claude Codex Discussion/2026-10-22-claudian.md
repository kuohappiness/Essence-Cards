# Claude／Codex 討論稿：Claudian 與用訂閱製卡（Capture → Cards → Mindboard）

日期：2026-10-22｜整理者：Claude｜狀態：💬 第二版（使用者回應後重寫），等使用者看過再請 Codex 回應；雙方一致後交給使用者決定，結論和[第二輪設計（整合版）](<2026-10-21-learning-objective-architecture.md#第二輪設計整合版claude-與-codex-一致待使用者確認>)一起確認

## 先讀這裡

- **來源**：使用者 2026-10-22 要求仔細評估 Claudian 這個 Obsidian 外掛，對 Essence Capture → Cards → Mindboard 這條流程有沒有幫助；Capture 和 Mindboard 簡單提到，重心放在 Cards。和 Codex 討論後再決案，決案後併進第二輪整合版一起更新。前提：大多數使用者是 ChatGPT Plus（含 Codex）或 Claude Pro 的訂閱者，每月約 690 台幣。
- **使用者對第一版的回應**（摘要）：
  1. 能用訂閱的 AI（Claude、Codex），家長的摩擦力會小很多；現實中很多人有訂閱，很少人會用 API。在不影響程式大方向的前提下，盡量利用這個外掛，優先於 API；可以有條件地修改之前的決定。只要能讓整個外掛用起來最輕鬆、最簡單，就值得嘗試。
  2. 不同意「多數家長裝不了 CLI」：應該直接輸入訂閱帳號就能用。
  3. 要 Claude 再仔細想一次，想好再交給 Codex。
- **第一版（commit `1676cf1`）錯在哪裡**：
  - 安裝門檻講得太高。Codex 桌面版本身就帶 `codex.exe`，Claudian 會自動找到，裝好 app、登入就能用，不必碰終端機（§1-2，這台電腦就是）。
  - 只把訂閱當成「省貼上」，沒有把「家長很少用 API」當成最大的摩擦。
  - 沒查到 OpenAI 的 Sign in with ChatGPT：開源、在本機執行的 app 可以直接用 ChatGPT 帳號登入，用方案的額度呼叫模型（§1-3）。這比 Claudian 更直接。
- **服務北極星的方式**：家長不必申請 API、不必另外付錢，設定與每次製卡的步驟都更少（縮短家長的時間）；訂閱裡的強模型不另外收費，第二輪如果證明強模型做出的學習目標比較好，就能直接用上（加深記憶、提升學業表現）。學習目標仍是單位（D-114），輸出照出題語法。
- **必讀範圍**：本稿；D-003、D-007、D-039、D-042、D-055、D-059、D-072、D-085、D-088、D-110、D-111、D-114；[architecture.md §6](../docs/architecture.md#6-ai-的位置-細節之後專門討論)；〈第二輪設計（整合版）〉。基準 commit 是 `1676cf1`，再加上本稿的 commit。

## 1. 查到的事實（2026-10-22）

### 1-1 Claudian

- [YishenTu/claudian](https://github.com/YishenTu/claudian)：把 AI 代理嵌進 Obsidian 側欄的外掛，vault 就是代理的工作目錄，能讀寫檔案、跑指令。接 Claude Code、Codex、DeepSeek、Grok、OpenCode、Pi；本身不含模型，用代理自己的登入（訂閱或 API 金鑰）。MIT、約 1.6 萬顆星、已上架社群外掛商店，最新 2.3.27（2026-10-21），一位主要維護者，改版很快。
- 功能：側欄對話、@ 檔案、選取文字直接改、vault 層級的 skill 與指令、MCP。Claude Code 的權限模式預設 `auto`（自動放行），另有 `manual`、`acceptEdits`、`yolo`。只有電腦版。
- **沒有給其他外掛呼叫的介面**：只有開關側欄等指令，Cards 不能直接把請求送進 Claudian 的對話（查過 `src/main.ts`）。

### 1-2 家長要裝什麼才能用訂閱

Claudian 怎麼找代理（查過原始碼 `CodexBinaryLocator.ts`、`ClaudeBinaryLocator.ts`，並在這台 Windows 電腦核對）：

- **Codex**：會找 Codex 桌面版內建的 `%LOCALAPPDATA%\OpenAI\Codex\bin\…\codex.exe`；macOS 也會找 ChatGPT 桌面版內建的 Codex。這台電腦裝了 Codex 桌面版並已登入，Claudian 不用任何設定就找得到。**使用者說得對：Codex 這一邊裝 app、登入就能用。**
- **Claude Code**：只找另外安裝的 Claude Code（`~/.local/bin`、npm、`%LOCALAPPDATA%\Claude` 等）。Claude 桌面版內建的 Claude Code 在 `%LOCALAPPDATA%\Claude-Data\…\claude-code\版本\…\claude.exe`，Claudian 找不到。所以 Claude 這一邊要用一行指令裝 Claude Code，再在終端機打 `claude` 用瀏覽器登入（[官方安裝說明](https://code.claude.com/docs/en/setup)）。Claude Free 方案沒有 Claude Code。

### 1-3 ChatGPT 帳號直接登入（Sign in with ChatGPT）

- OpenAI 的[開發者說明](https://developers.openai.com/cookbook/articles/sign-in-with-chatgpt)：ChatGPT 方案額度一開放就給**開源專案與在本機執行的個人專案**；付費或架在遠端伺服器的 app 才要排隊申請。Plus 與 Pro 的使用者可以用自己的方案；Free、Go 沒有提到。
- 做法（[登入](https://developers.openai.com/siwc/token-sharing-open-source/sign-in)）：app 在 `127.0.0.1` 開一個回呼，打開系統瀏覽器讓使用者登入 ChatGPT，用 PKCE 換到 token；不需要 client secret，也不需要 API 金鑰。token 會過期、要更新。
- 呼叫（[模型與推論](https://developers.openai.com/siwc/token-sharing-open-source/models-and-inference)、[預覽版限制](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations)）：一般的 Responses API（`api.openai.com/v1/responses`），模型用帳號可用的（範例是 `gpt-6.1-sol`）；`stream: true`、`store: false`；不能用 system 訊息、`temperature`、`max_output_tokens` 等欄位；**模型支援的話可以送文字、圖片與檔案**，不支援音訊、影片。額度用完會回 `subscription_sharing_usage_limit_exceeded`。
- 拿不到使用者的對話紀錄或 API 金鑰。目前是預覽版。
- Essence Cards 是公開 repo、免費、在家長電腦上跑，**應該符合自助資格**。但 repo 沒有 LICENSE 檔，嚴格說還不算開源（§7）。

### 1-4 Claude 端的規定

- Anthropic [明文不允許](https://code.claude.com/docs/en/legal-and-compliance)第三方 app 提供 Claude 帳號登入，或替使用者走訂閱額度；但不禁止使用者用自己的訂閱登入原版的 Claude Code。所以 **Claude 訂閱只能經由 Claude Code 使用**：Claude 桌面版的 Code 分頁、Claudian，或終端機。
- [說明中心](https://support.claude.com/en/articles/15036540-use-the-claude-agent-sdk-with-your-claude-plan)：2026-06-15 起，Agent SDK、`claude -p` 與第三方 app 仍然算在訂閱額度裡。這條規定 2026 年改過好幾次（[The Register](https://www.theregister.com/software/2026/02/20/anthropic-clarifies-ban-on-third-party-tool-access-to-claude/5014546)、[VentureBeat](https://venturebeat.com/technology/anthropic-reinstates-openclaw-and-third-party-agent-usage-on-claude-subscriptions-with-a-catch)）。

### 1-5 額度

- 一次製卡用掉方案多少額度，兩家都沒公布，要實測（§5）。API 直連一次約 2 萬 token 送出、3 千收回；代理會多輪讀檔，用量更多。
- OpenAI 說 Codex 包含在所有 ChatGPT 方案（連 Free、Go 都有），額度依方案不同（說明中心原頁 Claude 讀不到，來自搜尋摘要，請 Codex 核對）。

## 2. 重新評估：從「家長最省事」出發

### 2-1 家長依自己的訂閱，最省事的用法

| 家長的訂閱 | 最省事的用法 | 要另外裝什麼 | 要碰終端機嗎 |
|---|---|---|---|
| ChatGPT Plus／Pro | Cards 裡按「用 ChatGPT 登入」，之後每次按一下 | 不用 | 不用 |
| ChatGPT Free／Go | Codex 桌面版或 Claudian 照請求檔做（§3-2，Free、Go 的 Codex 額度待核對）；或複製貼上 | Codex 桌面版（用 Claudian 再加 Claudian） | 不用 |
| Claude Pro／Max | Claude 桌面版的 Code 分頁照請求檔做；想留在 Obsidian 裡就用 Claudian | Claude 桌面版；Claudian 要另外裝 Claude Code | 桌面版不用；Claudian 要一次 |
| Claude Free | 複製貼上到 claude.ai | 不用 | 不用 |
| 都沒有 | 複製貼上到 ChatGPT 或 Gemini 的免費網頁版 | 不用 | 不用 |

### 2-2 四種接法比較

| | ChatGPT 帳號登入 | 代理照請求檔做（Claudian、Codex 或 Claude 桌面版） | 複製貼上 | API 金鑰（現在的 D-085） |
|---|---|---|---|---|
| 第一次設定 | 按登入，瀏覽器同意 | 裝代理的 app 並登入；Claudian 另外裝 | 不用 | 申請 OpenAI 平台帳號、付款開通、開資料分享、建金鑰、貼上 |
| 每次製卡 | 按一下 | 按一下產生請求 → 在代理裡貼一句、送出 | 複製提示 → 開對話 → 附教材 → 複製結果 → 貼回 | 按一下 |
| 教材裡的圖 | 外掛送 | 代理自己讀 | 家長自己附 | 外掛送 |
| 額外費用 | 0 | 0 | 0 | Terra 一學期約 4 美元；GPT-6.1 Sol xhigh 約 15 美元（照第一輪 S2 一節約 0.25 美元粗估） |
| 結果穩不穩 | 穩：外掛決定送什麼 | 中：代理可能多讀、多做 | 看家長貼了什麼 | 穩 |
| 會不會動到別的檔 | 不會 | 會：代理能寫檔、跑指令 | 不會 | 不會 |
| 誰能用 | Plus、Pro | 有 Codex（各方案）或 Claude Pro 以上 | 所有人 | 願意申請 API 的人 |
| 規定 | OpenAI 官方開放，預覽版 | Codex 穩；Claude 一年改好幾次 | 穩 | 穩 |

### 2-3 判斷

- **使用者對**：API 才是家長最大的摩擦。D-085 的首選要另外申請 OpenAI 平台帳號、付款、開資料分享、建金鑰，對已經付了 ChatGPT 訂閱的家長，等於再付一次又多做五步。
- **最省事的不是 Claudian，是 ChatGPT 帳號登入**：家長不用裝任何東西，Cards 照樣自己組請求、送圖、收結果，和 API 直連的程式幾乎一樣，只是 token 換成登入拿到的。
- **Claudian 的位置**：Claude 訂閱者（Claude 不開放第三方登入，只能經由 Claude Code）、Codex Free／Go 的使用者，以及想在 Obsidian 裡直接跟 AI 對話、修改卡組的家長。它不必是必要條件：只要請求寫成檔，Claudian、Codex 桌面版、Claude 桌面版都能做。

## 3. 💡 提案：訂閱優先

### 3-1 v1 的 AI 接法

1. **用 ChatGPT 登入（預設）**：設定頁一個按鈕。製卡、加深、錯題分析、補記憶錨點都走它。
2. **請求檔（給代理）與複製貼上（給所有人）**：同一份請求，可以寫成檔交給代理，也可以複製到剪貼簿貼進任何 AI 對話。
3. **API 金鑰移出 v1**：Gemini 免費入門、OpenRouter 的預設選單也一起移出。之後要加回很容易：OpenAI 的 API 金鑰和登入拿到的 token 都是同一種 bearer token，打同一個 Responses API。

### 3-2 請求檔 → 輸出檔（給代理）

1. 外掛照常組好請求：四層規則、年級、教材連結、已有目標、熟練程度，和 ChatGPT 登入送出的完全一樣（「程式確認、AI 提案」不變，D-114）。
2. 按「交給 AI 代理」：外掛把請求寫成一個檔，把一句話複製到剪貼簿，例如「照 [[請求檔]] 做，結果寫到 [[輸出檔]]，不要改其他檔」。
3. 代理讀請求和它連到的教材與圖，只寫輸出檔；卡組、複習紀錄、教材庫都由外掛寫。
4. 外掛收到輸出檔（檔案變動通知，D-110），走「貼回結果」同一段程式：語法檢查（D-089）、配 ID、存快照（D-042）、寫入草稿卡組，再清掉請求檔與輸出檔。

不寫任何 Claudian 專用的程式。請求檔放哪、檔名、輸出檔開頭寫模型名稱等細節，在 AI 製卡模組寫規格時定。

### 3-3 ChatGPT 登入的做法（細節寫規格時定）

- 只在電腦版：製卡本來就在電腦上做（D-019）。
- 回呼開在 `127.0.0.1`，打開系統瀏覽器登入；token 與 host ID 只存在這台電腦，不寫進 vault，和 D-039 對 API 金鑰的要求相同（外掛的 `data.json` 在 vault 裡，會經 iCloud 同步）。
- 模型從帳號可用的清單選，預設用 [ai-models.md](../docs/ai-models.md) 推薦的那一個。
- 額度用完照 D-072「說清楚」：告訴家長是方案的額度用完了、什麼時候恢復，並提供「改用複製貼上」。
- 錯題照片直接送，不進 vault（D-088 不變）。

**條件**（都通過才改；沒過就照原決定）：

- **G1 資格與條款**：Essence Cards 符合自助資格；條款沒有擋家長替孩子製卡這種用途。repo 要不要加授權，由使用者決定（§7）。
- **G2 額度**：Plus 用方案裡的強模型做一次製卡，不會用掉 5 小時額度的一大塊；一學期約 60 次加上加深與錯題撐得住。

## 5. 和第二輪設計（整合版）的關係

G2、G3 正好可以在第二輪量到，所以建議第二輪這樣改：

- **R0～R3 改用 ChatGPT 方案額度跑**：同一個 GPT-6.1 Sol xhigh、同一個 Responses API，只是 token 換成使用者登入拿到的。這就是 v1 要用的接法，量到的就是家長會遇到的。S0（現行做法）與 S1（Opus 錨點）照原本用 API。
- **多記三件事**：每次請求用掉的方案額度與是否被擋（G2）；圖、推理強度、長輸出有沒有被拒（G3）；S0 換算成 API 一學期的費用，當成對照。
- **退路**：方案額度設不了 xhigh、常被擋或截斷，就退回原本的 API，並記下原因。
- **分工**：Codex 在 T4 的小程式加上 ChatGPT 登入（`127.0.0.1` 回呼，token 存在 repo 以外）；使用者在瀏覽器登入一次。使用者的 ChatGPT 是 Plus 才有代表性，要確認。
- **費用**：OpenRouter 只剩 S0、S1，5 美元限額比較不會擋。

R0～R3 的內容、盲評與評分口徑都不變。

## 6. Capture 與 Mindboard（簡述，之後再展開）

- **Capture**：ChatGPT 登入可以送圖片與檔案，轉錄也能用訂閱，省下的錢比 Cards 多（轉錄最吃 token）。但轉錄最吃額度，Plus 撐不撐得住，開工時再量；影片、語音不支援，那部分到時候另外找。兩個外掛各登入一次同一個 ChatGPT 帳號（D-072 的「推薦同一家」照舊）。
- **Mindboard**（心智圖外掛，D-056）：價值在挖空回想與記憶狀態配色（D-060），都是程式的事。AI 能幫的是從章節樹產生節點文字，同樣用 ChatGPT 登入或請求檔。做 Mindboard 時再談。

## 7. 代價與風險

1. **預覽版可能改規則**：OpenAI 可能改成要申請，或改額度。退路是請求檔與複製貼上一直都在，API 金鑰也能很快加回（同一種請求）。
2. **只有 Plus、Pro 能一鍵**：Free、Go 與 Claude 訂閱者要走請求檔或複製貼上。
3. **授權**：repo 是公開的，但沒有 LICENSE 檔，嚴格說不是開源。現在符合「在本機執行的個人專案」；發布給其他家長前，要不要加開源授權由使用者決定（和 D-003 公開範圍有關）。
4. **條款**：OpenAI 的 Sign in with ChatGPT 條款 Claude 讀不到（403），請 Codex 核對未成年、教育用途與資料的規定。
5. **只有 OpenAI 能一鍵**：D-007 不指定供應商仍然成立（其他家走請求檔與複製貼上），但最順的路只有 OpenAI。Anthropic 開放第三方登入時再加。
6. **代理的風險只在選用的路**：Claudian 預設自動放行、能跑指令，Obsidian 也[無法限制外掛的權限](https://obsidian.md/help/plugin-security)。請求檔寫明只寫輸出檔、建議 `manual` 模式、外掛只認輸出檔；複習紀錄只追加（D-115），出事用 Git 救回。
7. **隱私**：學生資料送到 OpenAI 或 Anthropic，和 API 直連一樣；訂閱方案的訓練設定由家長自己決定（D-055 可以接受）。

## 8. Claude 的建議（提案，待 Codex 回應、使用者決定）

1. **訂閱優先**：v1 預設「用 ChatGPT 登入」；請求檔與複製貼上給其他人（§3）。
2. **API 金鑰移出 v1**（G1～G4 都過才改；D-039、D-059、D-072、D-085 照 §4 修改，並更新 architecture §6、ai-models.md）。
3. **Claudian**：不當必要條件，當 Claude 訂閱者、Codex Free／Go 使用者與想在 Obsidian 裡對話的家長的選用入口；使用說明書（D-048）寫一段。
4. **第二輪照 §5 改**，和整合版一起請使用者確認。
5. Capture、Mindboard 開工時再評估，沿用同一套接法。

**沒有採用**：

- **Claudian 當所有人的主要接法**：ChatGPT 訂閱者要多裝一個外掛、每次多一步，卻沒有多得到什麼；Claude 訂閱者還是要另外裝 Claude Code。
- **Cards 自己啟動 Codex 或 Claude Code**（`codex exec`、`claude -p`）：ChatGPT 這邊被登入取代；Claude 這邊家長仍要先裝 Claude Code，偵測路徑與追 CLI 改版的工作 Claudian 已經在做。等 Claude 訂閱者真的多、請求檔不夠順再做。
- **讓代理直接寫卡組**：沒有快照、沒有配 ID，可能改到已啟用的卡（D-042、D-110）。
- **保留 API 金鑰當 v1 的預設**：家長要多做五步、再付一次錢，和使用者「最輕鬆、最簡單」的原則相反。
