- 觸發條件：本篇出處寫 `CO2 的性質`，材料中有同名標題；之後新增同學期、同科目的 `CO2` 單元。`2 擴散現象` 也有同樣問題，而且這正是 D-080 的段落標題例子（`docs/decisions.md:1629`）。
- 預期／提案結果：原本的段落引用應維持原意；照提案，新增另一篇卡組後，它會變成跨單元引用，目標歸屬、目錄數字及之後的考試比對都可能改變。

- 建議：先定位置、標題與單元引用的優先序，以及歧義時能明確表達意圖的寫法。「對到單元」只能證明候選存在，不能證明作者原意。補上新增、刪除同名單元前後的案例。

### F2｜P2｜屬性與出處的分隔規則尚未形成一致契約

位置：`tasks/entry-and-catalog.md:185`、`:191`。

- 觸發條件：`單元: 2-1　水溶液` 使用全形空白；出處寫同樣文字再接 `p.20`。
- 預期／實際：應能明確判斷兩者是否引用同一單元。已重現目前屬性把整段 `2-1　水溶液` 當編號，出處卻拆成單元 `2-1`、位置標題 `水溶液 p.20`。
- 影響：「其他編號可精確引用」還缺少分隔、跳脫或拒絕條件。直接改用所有空白切割，也會改變既有單元鍵。
- 仍待定義：`小五上 p.15`／只有 `小五上` 時，未寫單元是沿用原卡組編號，還是保留文字？`L1-2`、`2-`、全形數字要作其他編號，還是提示？大小寫與前導零已明定保留，這部分清楚。
- 建議：補成固定輸入／預期結果表；不必擴大接受範圍，但必須明定讀法與提示，並保留原文。

### F3｜P2｜「只改解析」不足以保證與舊版相容

位置：`tasks/entry-and-catalog.md:199`、`docs/syntax.md:53`。

- 觸發條件：新規格開始使用 `A1 p.20`、小寫 `l1 p.20` 或 `Starter p.20` 作跨單元引用，但另一台仍使用舊版。
- 預期／實際：新舊裝置應保有相同含義，或由最低版本標記阻止誤讀。已重現舊版把這些全部當段落標題；材料恰有同名標題時，會連到本篇材料，而非新規格指定的單元。
- 影響：不只是連結暫時不能點，還可能連到另一個位置。任務目前未交代開始寫新用法的版本與條件。
- 建議：區分「修正既有解析缺陷」與「開始使用新增／改義寫法」。後者須依 §0-1 說明最低讀取版本及兩段發布條件；不是要求所有舊卡組一律加標記。

### F4｜P2｜自然排序缺少平手規則，無法保證輸入打亂後結果相同

位置：`tasks/entry-and-catalog.md:189`、`:206`。

- 觸發條件：同時存在 `L01`／`L1`，或 `2-01`／`2-1`；它們依規格是不同單元。
- 預期／可能結果：索引順序不受 `state.decks()` 輸入順序影響；只使用自然比較時，平手可能保留輸入順序。
- 證據：規格缺口為靜態推斷；另已重現 Node 的 `Intl.Collator('en', { numeric: true })` 對上述編號比較為零，交換輸入就交換排序結果。這不是尚未實作的 catalog 已有 bug。
- 建議：指定自然比較平手時按原編號排序，其他文字與未知學期也定相同的固定規則；補反向輸入驗收。
